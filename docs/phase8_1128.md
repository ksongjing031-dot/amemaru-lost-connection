## 画面の整理

### ステータス画面（K）

前の画面は、1列に「レベル・経験値・基本ステータス7つ・補助の能力4つ・所持金・ボタン」を詰めていて、ツリーポイントの札が見出しに
重なり、数が右に寄りすぎ、補助の能力の名前と数がくっついていました。**横に広げて2列**にしました。

| 左の列 | 右の列 |
| --- | --- |
| レベルの結晶（ポイントが残っていれば光る）・レベル・ツリーポイント | 基本ステータス（HP・MP・攻撃・魔力・防御・素早さ・会心） |
| 経験値の数とバー・次のレベルまで（最大なら「経験値は結晶の欠片に」） | 補助の能力（会心ダメージ・回復量・クールダウン短縮・ロスト耐性） |
| 所持金と「渡す」 | |
| 職業（印・名前・役割）・上位職（昇格済みか、何日目・何レベルから）・覚醒（◆目覚めた／◇まだ） | |

- 下のボタン（スキルツリー（J）・アクセサリー・図鑑・閉じる）は同じ幅でそろえ、右上に「称号」。
- 文字は列の幅で切ります（「…」）。名前は左、数は右にそろえ、1行おきにうすい帯。
- マウスを乗せると説明：ツリーポイント（スキルツリーで節を取ったり段階を上げたりするのに使う）・補助の能力（装備とアクセサリーで
  上がる）・覚醒（全部の覚醒とレベル）。
- 小さい画面では、画面の大きさに合わせて縮みます。

### ほかの画面【補完】

- **スキルツリー**：名前の下の小さな説明（流派・アクティブ・連携など）が切れていたので、2行まで折り返します。説明の行の
  「。」が枠の外にはみ出していたのは、日本語の折り返しの「行頭禁則」を、ぶら下げ（前の行の終わりに出す）から**追い出し**
  （前の文字といっしょに次の行へ送る）に変えて直しました。この折り返しはどの画面でも使うので、ほかの画面のはみ出しも直ります。
- **アクセサリーの画面**：付けている物の合計が1行に入らず「…」で切れていたので、入るだけ並べて「ほか N」とし、マウスを乗せると
  全部を見せます。
- **装備の説明文**：「今の装備と比べて」の行が1つずつで縦に長かったので、2つずつ1行にまとめました。

## スキルツリーの奥義を「？？？」に

奥義（各職業の2つ。上位職だけが覚えられる）は、**開く条件がそろうまで**、次のように隠します。

- 木の節：印を出さず、暗い枠に「？」だけ（形からも分からないように）
- マウスを乗せたとき：名前は「？？？」、「奥義」、取れない理由（Lv60から・上位職から・となりの節を先に取る）、
  「開く条件がそろうと、名前と効き目が分かります」
- 右の説明：名前「？？？」、流派の奥義、「まだ取れない奥義です。取れるようになるまで、名前も効き目も分かりません。」、
  **開く条件**（Lvになる（今のLv）・上位職になる・となりの節を取る。そろったものは緑の◆、まだのものは◇）と、
  奥義は2つから1つを選ぶことの説明

開く条件は、**レベル・上位職・となりの節**の3つです【補完】。ツリーポイントが足りないだけのときは、条件はそろっているので見せます
（ポイントを貯めるか決めるため）。覚えた奥義はいつも見せます。

## パチンコとスロットの動き【補完】

どれも**見せ方だけ**で、当たりと払い出しはサーバーのとおりです。

### パチンコ

- **図柄**：止まる瞬間に小さくはねて白く光り、カチッと鳴る。リーチで揃った2つは脈を打つように大きくなり、うしろが光る
- **リーチ**：「リーチ！」が大きく飛びこんで、少し行き過ぎて落ち着く（はじめは震える）。スーパー以上は真ん中へ向かう集中線が回り、
  スペシャルは画面が小さく揺れる
- **カットイン**：斜めの帯が行き過ぎるように飛びこみ、止まって、速く抜ける。帯のうしろに流れる線、文字の左に結晶の印、入る瞬間に
  帯の色で光る
- **役物**：盤面の上にしまってある結晶の飾りが、強いリーチ（スーパー以上・カットインが赤以上）と大当たりで、液晶の上のふちまで
  落ちてはずむ（ゴトンという音）。落ちている間は光の筋が回る
- **保留**：1つ進むと左へすべる。**保留変化**：色のついた保留は、半分の確かさで、はじめは低い色で見せ、しばらくしてから本当の色に
  変わる（はじける光と輪と音）。回っている保留（当該）も、低い色で見せていたら回っている間に変わる。最後の色は、いつもサーバーが
  決めた色（期待のしかたは前と同じ）
- **大当たり**：画面が白く光って揺れ、紙吹雪・光の輪・星が散り、短いファンファーレ。「大当たり」の文字が1文字ずつ波打つ
- **ラウンド**：「ROUND n / m」が左から飛びこみ、1カウントごとに「+15」が浮かぶ（アタッカーに火花）。終わりの払い出しは0から
  数え上げ、確変に入るときは紙吹雪。確変・時短などの知らせの帯は、開くように出る
- **ランプ**：盤面のふちのランプの光り方を、待ち（ゆっくり息をする）・回転（追いかけ）・リーチ（白と台の色が速く）・
  大リーチ（赤い点滅が回る）・大当たり（虹と白の点滅）で変える

### スロット

- **リール**：回っている間は、図柄のうしろに残像が流れ、光の線が走る。止まる瞬間に小さくはねる
- **レバー**：たたかれて下がり、ばねで少し行き過ぎてから戻る。**止めボタン**：押すと少しへこんで暗くなる
- **告知ランプ**：光った瞬間に光の輪と星が散り、1秒ほど光の筋が回る（虹のときは虹の星）
- **ボーナス・AT**：はじまりは画面が白く光り、帯が右から飛びこみ、文字が1文字ずつ波打つ。紙吹雪（BIG は虹・REG は青・AT は金）。
  終わりは払い出しを0から数え上げる
- **払い出し**：揃った段（中段）が光って脈を打ち、メダルが弧を描いて受け皿へ落ちる。クレジットの数は、落ちるたびに1枚ずつ増えて見える
- **筐体**：両わきのランプ（待ち：ゆっくり上下・回転：追いかけ・ランプが光っている間：明るく脈・ボーナスとAT：虹の波）

## ボスの全員を狙う技【補完】

前は、どのボスも一番ヘイトの高い人（たいていナイト）ばかりを狙うので、ほかの人は遠くから一方的に攻撃できました。どのボスにも、
戦っている**全員**を狙う技を2つ足しました（`enemy/boss/PartyAttacks.java`。どのボスにも共通の動きで、ボスごとの強さ・間・形は定義の
`volley`・`nova`。`tools/datagen/add_party_attacks.py`）。

- **一斉の印**（volley）：戦っている全員の足もとに、同時に赤い円（半径2.4〜2.8）。1.5〜1.6秒で打つ。0.9秒ずつ遅れて、そのとき立っている
  所にまた円が出る（1〜3階は2回、4〜8階は3回。第3段階と怒ったときは1回多い）。止まって攻撃し続けていると当たる
- **大技**（nova）：部屋のほぼ全体を打つ大きな技。ボスごとに、次の形を順に使う
  - **ボスのまわり**：ボスのまわりの大きな赤い円（半径13〜15）。円の外まで走って離れる
  - **ボスのそばの金の円**：部屋じゅうがうすい赤に光り、外から内へ輪が寄ってくる。安全なのは、ボスの足もとの金の円（半径7）の中だけ。
    遠くから攻めている人も、寄らないといけない
  - **部屋の金の円**：部屋じゅうがうすい赤に光り、部屋に金の円が3つ（5人より多いと4つ）出る。金の円の中だけが安全。いちばん近い円へ
    逃げこむ
  - 逃げこむ形は、部屋の広さに合わせて予兆を長くする（3.7〜5.6秒。ひとりで戦っているときは、さらに1秒）。打たれた人の所には、
    ボスの色の小さな一撃が出る
- 最初は戦いが始まってから一斉の印が14〜16秒、大技が30〜34秒。そのあとは一斉の印が22〜24秒ごと、大技が42〜48秒ごと（第3段階は0.8倍。
  人数と怒りで短くなる）。一度に出すのは1つだけ
- 強さは、各ボスの固有のギミックをしくじったときの一撃より弱く（11月27日の決まり）、ふつうの強い技と同じくらい

  思い出してひざをつく・鏡の守りが割れている・静寂の帳（印が見えない）と帳が破れて動けない間
- 初めて出たときに、戦い方の手がかり（左上）が出る。ボスのHPの帯の下に、技の名前と「ボスから離れろ」「金の円へ」が出る。
  ボスはその間もほかの技を出すが、名前は全員を狙う技のまま（ほかの技の名前で消さない）
