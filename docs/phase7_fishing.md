# Phase 7：街を育てる（その2：釣り）

Phase 7 は Phase 0-B 13章の「**釣り、カジノ（右クリックでGUIを開いて使う）、寄付と共同事業、コネクション量と輝き段階**」です。4つに分けて作ります。

| 分け方 | 中身 |
| --- | --- |
| その1 | コネクション量（CP）と大結晶の輝き段階。交流の常設の仕組み（[`phase7_connection.md`](phase7_connection.md)） |
| **その2（この文書）** | 釣り（糸の張りのミニゲーム・魚40種・魚図鑑・ポッカ爺の釣り具屋・記憶魚・湖の主・釣り大会） |
| その3 | カジノ（右クリックでGUI・カジノナイト） |
| その4 | 寄付と共同事業（寄付の目標と輝き段階の両方で完成し、施設が変わる） |

その2で作ったものの中心は次のとおりです。

- **かかる・釣り上げる**（Phase 0-A 15章「浮きが沈んだら合わせ、そのあと数秒間『糸の張り』のゲージを、切れないように保つ」）：ふつうの釣り竿で投げ、浮きが沈んだときに右クリックで合わせると魚がかかります（バニラの釣りの品は出ません）。かかった魚は、**釣り場**（釣り堀・湖畔の釣り場・そのほかの水）と**今の章**で決まります。そのあと画面の真ん中の下に「糸の張り」のゲージが出ます。**右クリックを押している間は巻いて張りが上がり、離すとゆるみます**。魚は波のように引き、ときどき強く引きます。張りが**帯の中**にあるほど「寄せ」が進み、いっぱいになると釣り上げます。張りがいちばん上に届くと**糸が切れ**、下に落ちたままだと**逃げられます**。
- **魚40種**（15章「魚図鑑：全40種【提案】。章ごとに新しい魚が増える」）：第1章は川魚、第2章は一部が凍った釣り堀の氷下の魚、第3章は温かい湧き水の魚、第4章は空を映す水面の「空魚」。章ごとに★1〜3の魚と**記憶魚**（★4）が1種、それと**湖の主「記憶の主」**（★5）。
- **魚図鑑**：釣った魚の**いちばん大きいの・釣った数・初めて釣った日**と、ポッカ爺のひとこと。まだの魚は「？？？」。
- **ポッカ爺の釣り具屋**（7章「釣り堀：釣りのミニゲーム、魚図鑑、魚の売却」）：釣り堀の主人ポッカ爺に話しかけて開きます。タブは**魚図鑑・魚を売る・留め糸と交換・釣り大会**。竿を持っていない人には、竿を貸します。
- **使い道**（15章「売却、料理屋の材料、厳選素材『留め糸』との交換」）：売る（**大物は1.3倍**）と、**★1〜3の魚を点に換えて、10点で留め糸1本**。料理屋の材料は、料理屋（共同事業③）を作る**その4**で。
- **記憶魚**（15章）：まれにかかり、**古代の人々の短い記憶が記録帳に入ります**（記録帳の「塔の外」）。4つそろうと称号「記憶を釣り上げた者」。
- **湖の主「記憶の主」**（15章・22章）：湖畔の釣り場だけにいる、いちばんまれな魚。**サーバーで最初に釣った人**を覚え、限定称号「最初の大物」と、全員への知らせ・冒険日誌。ユニーク装備（23章）は Phase 8 で。
- **釣り大会**（15章「夜の催し：制限時間内の大物・珍しい魚を競う。湖畔の釣り場の完成後は会場が広がる」）：管理者が始めます（`/amemaru admin event start fishing_tournament`）。**10分**、始まる前に**30秒**の合図。会場で釣った一匹ごとに点がつき、**その人のいちばんの一匹**で競います。画面の上の真ん中に残り時間と順位。終わると上位3人に賞金と留め糸、冒険日誌に残ります。
- **CP**（13章）：**ほかの人の近くで釣る**（娯楽 1）・**魚図鑑に新しく登録**（娯楽 5）・**釣り大会に参加**（娯楽 20）。
- **称号**（22章）：釣り見習い → 釣り名人 → 湖を知る者（魚図鑑の25／60／100%。湖を知る者は「釣りのゲージ（帯）が少し広い」）・記憶を釣り上げた者・最初の大物（限定）。称号の定義は Phase 6 で入れてあり、その2で数え始めました。

## 2. このPhaseで決めた細かいこと（【補完】）

設計書に書いていない所は、次のように決めました。変えたいときは教えてください。魚の表は `data/amemaru/amemaru/fish/`（`tools/datagen/build_fishing.py` から書き出す）、釣りの決まり（ミニゲーム・釣り場・確率・大物・留め糸・大会）は `fishing_rules/default.json` で変えられます。

### 魚の表

- 魚の名前・大きさ・値段・手ごたえ（ミニゲームの難しさ）・ポッカ爺のひとことは【補完】です。絵は `tools/artgen/make_fish.py` で描きました（形19種。小さい魚は群れで描く）。
- 数は**第1〜3章が10種ずつ、第4章が9種、それと湖の主で全40種**です。湖の主は、湖畔の釣り場ができた日（共同事業①。第1章の4日目のころ）から釣れるので、第1章の魚として図鑑の最後に並べます。
- ★の割合：★1が60・★2が30・★3が10（同じ★の魚で分ける）。**今の章の魚は1.5倍**かかりやすく、前の章の魚もかかります。先の章の魚はかかりません。
- **記憶魚**は、釣り堀と湖で**2%**（今の章までの記憶魚から）。**湖の主**は湖で**0.2%**。川・水路・塔の中の水では、記憶魚と湖の主と、釣り堀・湖だけの魚はかかりません。
- 大きさは小さいのが多めです。**大きさの割合が90%以上**（範囲の上の1割）の魚は**大物**：アイテムに大きさ・釣った人・日が書かれ、売ると1.3倍です（ほかの魚と重ならない）。ふつうの魚は大きさを書かず、重ねて持てます（図鑑には大きさが残る）。湖の主は、いつも大物です。

### 釣り場

| 釣り場 | どこ |
| --- | --- |
| 釣り堀（pond） | 西区の釣り堀（中央広場の真ん中から x −96〜−59・z 22〜68） |
| 湖畔の釣り場（lake） | 城壁の南西の水門の外の湖（x −132〜−95・z 54〜92）。**湖畔の釣り場ができるまで（物語の印 `amemaru:project/lakeside`）は「そのほかの水」**。共同事業①（その4）で印が付く |
| そのほかの水（river） | 上のほかの水すべて（街の水路・塔の中の水など） |

### ミニゲーム

- 帯（よい所）の広さ・魚の引きの強さと速さ・寄せがいっぱいになるまでの時間は、魚の**手ごたえ**（0〜1）で変わります（巻く速さ・ゆるむ速さは同じ）。手で遊ぶ見立て（反応の遅れ0.25秒前後・見まちがい）で、**★1〜3と記憶魚は9割以上釣れ（2.5〜8秒）、湖の主は4割ほど（14秒ほど）**にしました。`python3 tools/datagen/build_fishing.py --sim` で確かめられます。
- 長くても20秒で逃げられます。ミニゲームの間は、右クリックで竿を投げ直しません。
- 称号「湖を知る者」の効果は「**帯が20%広い**」です（Phase 0-A 22章の効果の提案「釣りのゲージ」）。
- 釣り上げたかは、遊んでいる人の画面で決めます。サーバーは、**いちばん早く勝てる時間より早い「勝った」**と、時間を過ぎた知らせを数えません（13章の不正対策）。**CPは、ミニゲームに勝ったときだけ**数えます（管理者のコマンドで釣ったことにしたときは数えない）。

### 釣り具屋（ポッカ爺）

- ポッカ爺は西区の釣り堀の東の店（カウンターの中）にいます。会話：「魚図鑑を見せて」「魚を売りたい・換えたい」「ほかにも聞きたい」（釣りのこつ・竿を貸して）「またね」。
- 画面は、開いてから**30分のうちで、開いた所から10ブロック以内**で使えます。
- **魚を売る**：持ち物の魚を1か所ずつ、または「まとめて売る」（**記憶魚と湖の主は、まちがえて売らないよう除く**。1か所ずつなら売れる）。値段は魚ごとの値（★1が18〜26ノット・★2が55〜90・★3が180〜320・記憶魚が500・湖の主が5,000）。
- **留め糸と交換**：★1〜3の**ふつうの魚**（大物は除く）を、★1は1点・★2は2点・★3は5点に換え、**10点で留め糸1本**。端数の点は残ります。
- **竿を貸す**：竿を持っていない人に、ただで「ポッカの貸し竿」（ふつうの釣り竿）を渡します（返さなくてよい）。
- **フリマ**：魚も出品できます（初期相場は魚の値）。

### 釣り大会

- 始めるのは管理者（`event start fishing_tournament [分]`）。長さは10分、始まる前の合図は30秒（`fishing_rules` の `tournament`）。開くときに全員のチャットで知らせ、始まるときと終わるときに画面の真ん中に出します。その間は、画面の上の真ん中に**残り時間（始まるまでの時間）・1位・自分の順位と点**を出します。
- **会場**は釣り堀。湖畔の釣り場ができていれば湖も（始めたときに決める）。会場の外で釣った魚は数えません。
- 一匹の点は「**★の倍率 ×（50 + 50 × 大きさの割合）**」。★の倍率は ★1が1・★2が2・★3が4・記憶魚が6・湖の主が20。**その人のいちばんの一匹**で順位を決め、同じ点なら先に釣った人が上です。
- 賞品は1位 3,000ノットと留め糸3本・2位 2,000ノットと2本・3位 1,000ノットと1本。いない人には次に入ったときに渡します。会場で1匹でも釣った人に、釣り大会に参加のCP（20）。1位は冒険日誌に残ります。
- `event stop fishing_tournament` で、その時点の順位で終えます（賞品も出る）。何も渡さずに取りやめるときは `fishing tournament cancel`。

### そのほか

- **記憶魚の記憶**は、古代記録と同じ記録帳に「塔の外」として入ります（エルネストのひとことつき）。記録の収集率（称号「記録の拾い手」→「記録の読み手」→「歴史の語り部」）は、塔の中の30の記録で数えます。
- 「ほかの人の近くで釣る」（13章「1匹ごとに1」）は、16ブロック以内に、竿を投げている・ミニゲームの最中・30秒以内に釣った人がいるときに数えます（回数の上限はなく、娯楽の1日の上限150のうち）。
- config（`amemaru-server.toml` の `[fishing]`）の `enabled` をオフにすると、バニラの釣りのままになります。

## 4. 確かめ方

### 1人で

1. 西区の釣り堀の東の店で、ポッカ爺（麦わら帽子の白いひげのおじいさん）に話しかけると、「おう、いらっしゃい。魚は、待てる人のとこに来るんだなぁ」と出ること。「ほかにも聞きたい」→「竿を貸して」で釣り竿がもらえること。
2. 釣り堀に竿を投げ、浮きが沈んだら右クリック。「かかった！」と出て、画面の真ん中の下に「糸の張り」のゲージが出て、右クリックを押すと張りが上がり、離すと下がること。帯の中に保つと「寄せ」が進み、釣り上げるとチャットに「○○ を釣り上げた！（△cm）」、初めての魚なら「魚図鑑に ○○ を登録した」と、画面の下に「コネクション +5（娯楽：魚図鑑に新しく登録）」が出ること。巻きすぎると「糸が切れた」、ゆるめすぎると「逃げられた」になること。
3. ポッカ爺の「魚図鑑を見せて」で、釣った魚にいちばん大きいの・数・日・ひとことが出て、まだの魚が「？？？」であること。「魚を売る」で売ると、ノットが増えること。「留め糸と交換」で10点ごとに留め糸が増えること。
4. `/amemaru admin fishing catch @s amemaru:memory_dawn` で、記録帳の「塔の外」に記憶が入ること。`/amemaru admin fishing lake true` のあと、湖で釣ると湖の魚がかかること。`/amemaru admin fishing catch @s amemaru:memory_lord` で、全員に「【湖の主】…が、湖の主「記憶の主」を釣り上げた！」と出て、限定称号「最初の大物」がつくこと。
5. `/amemaru admin fishing dex @s fill` で、称号「釣り見習い」「釣り名人」「湖を知る者」がつくこと。

### 2人以上で

1. 2人で近くで釣ると、釣り上げたときに「ほかの人の近くで釣る」のCPが入ること。
2. `/amemaru admin event start fishing_tournament 3` で、全員に大会の知らせが出て、30秒後に「はじめ！」。釣り堀で釣ると画面の上の順位が変わり、3分たつと上位3人の発表と賞品、冒険日誌への記録、参加した人へのCP（20）が出ること。会場の外で釣った魚が数えられないこと。
