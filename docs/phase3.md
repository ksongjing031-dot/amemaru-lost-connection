# Phase 3：敵・ドロップ・装備・工房・アクセサリー

Phase 0-B 13章の「Phase 3で作るもの」（敵、ドロップ、レアドロップ、装備とレアリティ、工房、武器・防具の3D表示、アクセサリー枠とランダムステータス）を作りました。確認の目安は「**敵を倒すとレア装備が出て、3Dで見える。アクセサリーの数値が抽選される**」です。

作ったものの中心は次のとおりです。

- **1階の雑魚4種**（ツノモフ・石くれ兵・結晶蜂・欠け牙の狼。Phase 0-A 9章）。GeckoLibのモデルと動き、技の前の**予兆**（地面の帯・円・構えの光）、**敵視の表**（ヘイト）と挑発、離れすぎたら戻る仕組み。
- **ドロップ**は倒した人ごとに抽選し、**その人にしか見えず、その人しか拾えない**。レアドロップは**光の柱・本人の画面の知らせ・3%以下ならサーバー全体に告知**、図鑑に記録（Phase 0-A 20章【確定】）。
- **装備**：レアリティ6段（ユニークは虹色の文字）、数値の**抽選（70〜100%）と品質★**、**強化（+10まで、失敗なし）**と光り方、**耐久と修理**、レア装備の**固有の特殊効果**。説明文に、数値・幅・割合・品質・今の装備との比較（Phase 0-A 21章【確定】）。
- **工房**（武器・防具・装飾の作業台）と**生産職3つ**（武器職人・防具職人・装飾師）、熟練度と「大成功」、作り手の名前（「〇〇作」）。
- **3Dの武器**（Javaのモデル5本＋GeckoLibの動く杖）と**防具2式**（GeckoLib。ナイトの重鎧・ウィザードの法衣）。
- **アクセサリー**（Curios API）：5つの枠（11日目から6つ）、メインとサブ1〜4個の抽選、品質★、**完璧なアクセサリー**の演出と告知、体に表示（枠ごとにオン・オフ）、専用の画面。
- **結晶果**（7種）、**章ごとのレベルの上限**とあふれた経験値の**結晶の欠片**、**追いつき補正**、**素早さ**の効き目（移動・攻撃の速さ・回避）、**図鑑**。

## 3. できること

### 敵（1階の雑魚4種）

設計の元は Phase 0-A 9章の1階（緑の始まり・草原）です。数値と動きは `enemies/*.json` で変えられます（9章の設計書）。

| 敵 | Lv | HP | 攻撃 | 動き |
| --- | --- | --- | --- | --- |
| ツノモフ | 2 | 140 | 16 | ふだんはおとなしく、自分からは襲わない。一匹を叩くと、12ブロック内の仲間が一斉に向かってくる（群れの反撃） |
| 石くれ兵 | 4 | 320 | 28 | 決まった道を巡回する。正面120°・12ブロックで気づき、鐘の音で16ブロック内の仲間を呼ぶ。腕を振り上げて地面ごと叩きつける（足もとに赤い円） |
| 結晶蜂 | 3 | 110 | 20 | 7ブロックほど離れた高さに浮き、体の結晶が光ってから結晶の針を撃つ（よけられる） |
| 欠け牙の狼 | 5 | 260 | 26 | ロストを初めて見せる敵（白く欠けた体から光の粒）。止まって地面をにらむと、地面に赤い帯が出て、その上をまっすぐ突進する |

- **予兆**：技の前に、地面の帯（突進）・円（叩きつけ）・体の光（構え）が出ます。構えの間は向きを変えないので、見てからよけられます。仲間を呼ぶときは頭の上に「！」。
- **名前とHP**：24ブロック以内の敵の頭の上に「名前 Lv」とHPのバー。
- **敵視（ヘイト）**：敵は、自分にダメージを多く与えた人を狙います。ナイトの「呼び声」などで挑発すると、挑発した人が表の一番上になり、狙われます。敵はプレイヤーだけを狙います。
- **戻る**：生まれた場所から28ブロック以上離れると、追うのをやめて走って戻り、HPが満タンになります（戻る間は攻撃が当たらない）。
- **HP**：このModの敵のHPは独自の値で、バニラの体力はその割合を映すだけです。凍結・よろめき・防御崩しなど、Phase 2のスキルの状態はそのまま効きます。
- 倒れると、倒れる動きのあと1.5秒で消えます。バニラの経験値のオーブは出しません。

### ドロップとレアドロップ

- **一人ずつ**：敵に攻撃を当てた人（挑発した人も）が、それぞれ自分のドロップを抽選します（Phase 0-A 20章「参加者が一人ずつ個別に抽選」【確定】）。倒れた場所から48ブロックより遠い人は受け取れません。
- **その人だけ**：ドロップは持ち主にしか見えず、持ち主しか拾えません（ほかの人の画面には描かれない）。
- **経験値**：敵の経験値を、受け取る人の数で均等に分けます（パーティの人数のボーナスはPhase 4）。
- **レアドロップ**：敵ごとの確率（`enemies/*.json`）× config の倍率。出ると、本人の画面に「レアドロップ！」の知らせと音、ドロップからレアリティの色の**光の柱**。その品の確率が3%以下ならサーバー全体のチャットに「【レアドロップ】〇〇が△△から□□を手に入れた！（0.80%）」（20章【確定】。告知と表示の確率は、configの倍率と天井をかける前の、敵の定義の確率【補完】）。
- **天井**：天井のある敵（ボス）は、レアが出なかったたびに確率が元の+10%ずつ上がり、出たら戻ります（20章）。1階の雑魚には天井はありません（ボスはPhase 5）。
- **図鑑**：倒した数と、その敵から手に入れた品を記録します（20章【確定】）。
- **アクセサリーも落ちる**：1階の雑魚は、低い確率でアクセサリーを落とします（21章「敵やボスのドロップでも手に入る」【確定】）。

### 装備

- **レアリティ**：コモン（白）・アンコモン（緑）・レア（青）・エピック（紫）・レジェンダリー（橙）・ユニーク（虹色。文字の色が変わり続ける）。エピック以上は手に持つと光の粒、レジェンダリーはいつも粒が出ます（20章）。
- **数値の抽選**：数値は「定義の数値 × レアリティの倍率 × 抽選の割合（70〜100%）× 強化の倍率」。割合はステータスごとに抽選して品に記録します（データパックで定義の数値を変えると、持っている品にも効く）。
- **品質★**：割合の平均で★1〜5（60%未満・60〜・70〜・80〜・90%以上）。★2以上は持ち物のアイコンの右下に★。
- **強化**：+0〜+10、失敗なし（20章）。+1ごとに数値+4%。+4・+7・+10で光り方が一段ずつ増え（アイコンのきらめき・手に持ったときの光）、名前の後ろに「+7」。素材は苔鉄（段の数）と、+4から結晶の欠片。強化はその系統の生産職だけができます。
- **耐久**：攻撃が当たる・スキルを使うと武器が1、敵の攻撃を受けると防具と盾が1ずつ減ります。0になると「壊れた」になり、数値と特殊効果が効かなくなります（品はなくならない）。工房で修理します。見習い装備は壊れません。
- **必要レベルと職業**：届かない・合わない装備は、持てても数値が効きません（説明文に赤い字）。
- **両手剣**を持つと、もう片方の手の盾は効きません。
- **取引の決まり**（20章【提案】）：見習い装備は取引できない。レア装備は「一度装備すると取引できない」で、装備した瞬間に本人専用になります（印は品に付けておき、取引の仕組みはPhase 6）。
- **説明文**：レアリティ・種類・シリーズ・品質、ステータスごとの「数値（幅）割合」、強化、特殊効果、必要レベル、耐久、大成功・作り手・レアドロップ、取引、そして**今の装備との比較**（上がる・下がる）。

### 工房と生産職

- 工房の作業台（武器・防具・装飾）は、クリエイティブの「AMEMARU: LOST CONNECTION」のタブにあります（壊れない。コネリアの工房街に置くのはPhase 5）。右クリックで画面が開きます。装備は「AMEMARU：装備」、素材と結晶果は「AMEMARU：素材」のタブです。
- **生産職**：武器職人（武器）・防具職人（防具と盾）・装飾師（アクセサリー）。一人が持てるのは戦闘職1つと生産職1つ（19章【確定】）。工房の画面の「〇〇になる」で選びます。**生産職はいつでも無料で変えられ、熟練度は職業ごとに別**（19章）。
- **作る**：その工房の生産職だけが作れます。熟練度がレシピの熟練度以上で、素材がそろっていること（サーバーで確かめる）。作った品は抽選され、説明文に「〇〇作」（19章）。
- **熟練度**：1〜10。作るたびに経験がたまり、章ごとに上限が開きます（第1章は3まで）。
- **大成功**：熟練度が上がると出やすくなります。装備は抽選の割合が+10%（品質が一段上がる）、アクセサリーはサブが一つ多くつきます（19章・21章）。
- **強化**：その系統の生産職だけ。**修理**：誰でもできますが、その系統の生産職でない人は素材が2倍です。
- 作業台から8ブロック以上離れると、画面が閉じます。

### 3Dの武器と防具

- **武器**：古代石の剣・大剣・杖、見張りの石刃、欠け牙の大剣は、手に持つと立体（持ち物では絵のアイコン）。見習いの盾と同じ形の古代石の盾も立体です。
- **蜂晶の杖**はGeckoLibで描き、先の結晶が浮いて回り、光ります。攻撃・スキルのたびに結晶がふくらんで回ります（`use` の動き）。
- **防具**：古代石の重鎧（兜・胴鎧・脚甲・鉄靴。ナイト）と、古代石の法衣（頭巾・法衣・下衣・旅靴。ウィザード）。GeckoLibで描き、光る部分は暗い所でも光ります。
- 強化値に応じて、手に持った武器と防具のアイコンがきらめきます（+4・+7・+10）。

### アクセサリー

- **枠**（21章）：指輪2（攻撃か魔力。素材で決まる「闘環」「智環」）・首飾り（HP）・腕輪（防御）・お守り（MP・素早さ・会心・回復量・ロスト耐性のどれか）・留め具（会心ダメージかクールダウン短縮。**11日目に開く**）。
- **開き方**：ステータス画面の「アクセサリー」、または持ち物の画面の「装身具」ボタン。左に指輪2つと留め具、右に首飾り・腕輪・お守り、真ん中に自分の姿。姿の下の切りかえ（2つずつ2段）で、首飾り・腕輪・お守り・留め具を体に表示するかを選びます。上に、付けている分の数値の合計。
- **抽選**：メインは「その章の上限 × 70〜100%」。サブは1個30%・2個40%・3個25%・4個5%、メインやほかのサブと重ならず、数値は「上限の半分〜上限」（21章）。第1章の品は、表の数値に×0.4（%のステータスは×0.6）。
- **品質**：メインを含むすべての割合の平均で★1〜5。★4はアイコンがうっすら光り、★5は虹色にきらめきます（21章）。
- **完璧なアクセサリー**：サブ4つで、すべての割合が95%以上。手に入れた瞬間に本人の画面で特別な知らせ、サーバー全体に告知、称号「完璧の結晶」を預かります（21章【確定】。称号の一覧はPhase 6）。
- **体に表示**：首飾り（胸元）・腕輪（右の手首）・お守り（腰）。まわりの人にも見え、枠ごとに表示を消せます。指輪は小さすぎるので表示しません（21章）。
- 強化・振り直し・固定・分解（厳選）はPhase 6です。
- Curios の標準の画面とボタンは隠し、Curios の「G」キー（Curios の画面を開くキー）は初めて起動したときに1回だけ外します（スキルのキーGと重ならないように）。

### 手で確かめること

jar の入れ方は [README](../README.md) にあります。**サーバーとクライアントの両方に GeckoLib と Curios の jar も入れます**（クライアントには playerAnimator も）。ワールドは、チートを許可して新しく作ってください。

1. **準備**：`/amemaru admin level set @s 12`、`/amemaru admin job set @s amemaru:knight`。サバイバルにして（`/gamemode survival`）、平らな草原で始める。
2. **敵を呼ぶ**：`/amemaru admin enemy spawn amemaru:tsunomofu 3`。角のある毛玉が3匹、草を食むようにゆっくり歩く。頭の上に「ツノモフ Lv2」とHPのバー。近づいても襲ってこない。

3. **予兆**：`/amemaru admin enemy spawn amemaru:ishikure_soldier`。少し離れて正面に立つと、鐘の音と頭の上の「！」、腕を上げて仲間を呼ぶ。近づくと腕を振り上げ、足もとに赤い円が広がる（0.9秒）。円の外へ出るとよけられる。
   - `/amemaru admin enemy spawn amemaru:kakekiba_wolf`：白く欠けた体から光の粒。5〜12ブロック離れると、止まって身を低くし、こちらへ向かって地面に赤い帯（1.2秒）。帯の外へよけると、狼は帯の上を走り抜ける。

## 7. 世界観・物語の追加【補完】

物語の向き（ストーリー）を変えるものではありません。Phase 0-Aの名前（敵・素材・アクセサリー・シリーズ）はそのままで、説明を足しました。気になるところがあれば直します。

- **古代石と苔鉄**：1階の草原に埋もれた古代の道標と同じ、灰青色の石。苔鉄は、苔に覆われたまま錆びずに残った古代の鉄。古代石シリーズは、この二つを工房で鍛え直した装備。
- **石くれ兵**：古代の見張り。決まった道を、決まった時刻に巡回し続けている。胸の奥の小さな核（石くれの核）は、まだかすかに灯っている。鐘の音は、古い見張りの合図。
- **結晶蜂**：結晶の体を持つ小さな古代の機械。大結晶の欠片を集めて運んでいたらしい。
- **欠け牙の狼**：体の一部が白く抜け落ちた狼。抜けた所からは、白い光の粒（ロスト）がこぼれ続けている。プレイヤーが初めて見るロスト。
- **見張りの石刃**：石くれ兵の腕から削り出された刃。刃に、見張りへの古い命令の文字が光る。
- **蜂晶の杖**：結晶蜂の腹の結晶を据えた杖。結晶は持ち主の魔力に合わせて回り、魔法が当たると、かけらが針になって刺さる。
- **欠け牙の大剣**：欠け牙の狼の、白く欠けた牙を刃に埋めた両手剣。欠けた牙は「抜け落ちかけたもの」を見分け、弱った相手ほど深く届く。
- **結晶果**：大結晶の根元にだけ実る果実。大結晶の力がほんの少し宿っていて、食べた人の体に糸のように結びつく（だから、ほかの人には渡せない）。
- **残響の欠片**：古代の魔力の響きが残った結晶のかけら（21章）。装飾師は、これでアクセサリーに眠る響きを揺り起こす。
- **工房の作業台**：コネリアの工房街の職人たちが使う台。武器の台には金床、防具の台には板金、装飾の台には小さな結晶が並ぶ。
- **生産職の説明**：武器職人は「糸のように細い魔力の筋を金属に通して、持ち主の手になじませる」、防具職人は「古い守り手の鎧の継ぎ目を読み、着る人の動きに合わせて仕立て直す」、装飾師は「結晶に残った響きを聞き分け、石と金属に結び留める」。
- **完璧なアクセサリーの称号**：「完璧の結晶」（22章の称号の一覧に足す案）。
- **図鑑**：ギルドの記録係が、冒険者の話をもとにつけている魔物の記録、という形にしました（記録係のNPCはPhase 6）。

## 8. 差し替えてほしい素材（モデルを作る人向けの手順書）

今のモデル・絵・動きはすべて仮です。**同じファイル名・同じボーンの名前・同じアニメーションの名前**で作れば、コードを変えずに差し替えられます（Phase 0-B 12章）。今の仮の素材は、次のコマンドで作り直せます。

```
python3 tools/artgen/make_phase3_models.py src/main/resources/assets/amemaru   # GeckoLibのモデル・動き・絵
python3 tools/artgen/make_phase3_art.py src/main/resources/assets/amemaru      # アイコン・Javaのモデル・作業台・演出
```

### 共通の決まり

- Blockbench 4系と「GeckoLib Animation Utils」プラグインを使います（Phase 0-B 1章）。GeckoLibのモデルは、プロジェクトの種類を「GeckoLib Animated Model」にし、書き出しで `.geo.json` と `.animation.json` を出します。
- **前（顔）は北（−Z）**に向けて作ります。1ブロック＝16ピクセル。
- テクスチャの大きさは2の累乗です。大きさを変えたら、Blockbenchの「Project」の設定で同じ大きさにしてから書き出します（`.geo.json` の `texture_width`・`texture_height` に入る）。
- **光る部分**：元の絵と同じ大きさの `<名前>_glowmask.png` を作り、光らせたい画素だけを、**光らせたい色で**描きます（ほかは透明）。暗い所でも、その画素がその色で明るく見えます（同じ形をもう一度、この絵で描き重ねる。バニラのクモの目と同じやり方）。GeckoLibの標準のやり方（光る画素を元の絵から抜き取る）は、GitHub Actions の写真で光る所が黒く抜けたため使っていません。いらなければファイルを消してかまいません（消すと光らないだけで、モデルはふつうに描かれます）。
- アニメーションの名前は `animation.<ファイル名>.<動き>`（英字の小文字とアンダーバー）。ボーンの名前は自由ですが、下の表の名前で作ると、今の仮の動きをそのまま参考にできます。

## 10. 気になる点（ご判断ください）

ストーリーの向きに関わる、新しくご判断いただきたい点はありません。次の2つは【補完】で決めたので、違えば教えてください（どちらもデータで変えられます）。
