# スキルツリー（11月24日に作り直し）

11月24日に、いただいた理想の絵（星座のようにつながった節・金のふちのスキル・右のステータスの枠・左下の六角のスキル枠）と、
次のご指示をもとに作り直しました。

> スキルツリー少し改変したいです　理想の見た目を送ります
> ステータスもスキルツリーで一緒に振る形にしてすべてのスキルが取れるではなくビルドによって変化するようにしたいです
> それによってもっとたくさんのスキルがあってもいいですね（モンクだと回復できるパンチやパッシブとは別で一定時間火力上げる自身のバフなど
> アーチャーだと跳弾する矢など他の役職でも色々追加する）

数値と形はすべて【補完】です。強すぎ・弱すぎ・取りにくいなどは、数をお知らせください（下の「直し方」ですぐに変えられます）。

## 決めたこと

| ご指示 | 決めたこと |
| --- | --- |
| ステータスもスキルツリーで一緒に振る | ステータスの振り分け（レベルごとの3ポイント）をなくし、スキルツリーの「ステータスの節」で上げる。ポイントは1種類（ツリーポイント） |
| すべてのスキルが取れるではなく、ビルドによって変化する | 節は、となりの節が取れているときだけ取れる（まん中の下の「職業の核」から道をのばす）。ツリーをすべて取るのに約360ポイント、Lv100 で 218 ポイント（6割ほど）。どの道を進むかで、使えるスキルとステータスが変わる |
| もっとたくさんのスキル | 6職業に5つずつ、計30のアクティブスキルを足した（下の表）。モンク「回生拳」（打つとHPが戻る）・「気炎」（自分の火力を上げるバフ「力の高まり」）。アーチャーの「跳ね矢」（敵から敵へ跳ねる矢）は Lv20 から Lv10 に早めた |
| 理想の見た目 | 星座の画面（下の「画面」） |

## ポイント

| | 決めたこと |
| --- | --- |
| もらえる数 | レベルが1上がるごとに2。5の倍数のレベルでさらに1（Lv10で20、Lv30で64、Lv60で130、Lv100で218） |
| 使い道 | スキルの段階（1段1・2段1・3段2・4段2・5段3。第5段は上位職から）と、ステータスの節（1つ1ポイント） |
| 職業の最初のスキル | 2つ。1段目は無料（ポイントに数えない） |
| やり直し | 「忘れ水」と「白紙の誓約書」は、どちらもツリーをすべて戻す（取った節・覚えたスキル。最初のスキルは1段目で残る）。転職したときも同じ |
| 前のデータ | ログインのとき、振っていたステータスと覚えたスキルをすべて戻し、ポイントにして返す（知らせが出る） |

レベルで自動で上がる分は、1レベルにつき HP18・MP4・攻撃0.9・魔力0.9・防御0.45。そのほかは、ツリーのステータスの節で上げる。

## ツリーの形（skill_trees/<職業>.json。tools/datagen/build_skill_trees.py）

- まん中の下に**職業の核**（最初から取れている）。左上と右上へ、2つの流派の枝がのびる。流派の最初のスキルは核のとなり
- スキルは段（row）ごとに外の輪へ。流派の中は4つの列（足したスキル・主なアクティブ・2つ目のアクティブ・パッシブ）
- スキルとスキルの間に、**ステータスの節**（小さな丸）を数珠のように置く。体力・MP・攻撃・魔力・防御・素早さ・会心。
  内側ほど小さく（体力 20・24・28、攻撃 2・2・3 など）
- 流派の2段目と4段目の外側に、**名のある大きな節**（%で上がる。例：ナイトの「城塞の心得」防御+8%・HP+4%）。1・3・5段目では
  列どうしを横につなぎ、2・4段目では2つの流派を**橋**でつなぐ（橋のまん中も大きな節）。流派をまたぐビルドは橋を渡って作る
- **奥義**は流派の先端（Lv60・上位職から。2つから1つ）

| 職業 | 節 | うちステータスの節 | スキル | つながり | すべて取るポイント |
| --- | --- | --- | --- | --- | --- |
| ナイト・ウィザード・ヒーラー | 107 | 73 | 33 | 122 | 362 |
| アーチャー・ローグ・モンク | 105 | 71 | 33 | 120 | 360 |

## スキルの段階と解放

| | 決めたこと |
| --- | --- |
| 段階 | 最大5段（前は3段）。第5段は上位職から。1段ごとの伸びは前の半分（5段目＝前の3段目） |
| 解放のレベル | 段（row）ごとに Lv1・5・10・15・21・26。奥義と上位職は Lv60 |
| 近接職の消費MP | 覚えられるレベルが高いほど増える倍率（1レベル+5%）は、Lv30 までで数える（奥義は前と同じ2.45倍） |

## 画面（Jキー）

- 左の広い場所に、星座のスキルツリー。**ドラッグで動かし、ホイールで拡大・縮小**。右上の「全体」で木の全体、「核へ」で核のまわり
- 金のふちの大きな丸＝スキル（取れるものは青く光る。段階は下の小さな印。上位職からの段階は橙）。小さな丸＝ステータスの節
  （印の形と色で、上がるステータスがわかる：♥体力・雫MP・剣攻撃・星魔力・盾防御・羽素早さ・光会心）。中くらいの丸＝名のある大きな節
- 取った節どうしの線は金色、取った節から出る線は青
- 節を**クリックで選び**、右の「取る」で取る（同じ節をダブルクリックしても取れる）。取れないときは、ボタンに理由（「となりの節を先に取る」など）
- 右の枠：「節の説明」（スキルは段階のつまみ1〜5で、その段階の数値と効果を見る）と「ステータス」（今のステータスと、ツリーで上がった分を金色で）
- 左下に、スキル枠 R・G・V・Z・X・C（アクティブスキルを選んで枠をクリックで入れる・右クリックで空にする）

絵：textures/gui/skill_tree.png（tools/artgen/make_tree_art.py）。

## 直し方

- ツリーの形・節の値：tools/datagen/build_skill_trees.py の ROW_RADIUS・BEADS・STAT_VALUES など → `python3 tools/datagen/build_skill_trees.py`
  （`--render フォルダ` で見本の絵）
- ポイントの数：growth/default.json の points（skill_per_level・skill_bonus_every・skill_bonus）
- 段階のポイント・伸び：tools/datagen/jobs/common.py の RANK_COSTS・RANK_STEP → `python3 tools/datagen/build_jobs.py`
- 強さの目安：`python3 tools/balance/estimate.py`（ツリーのポイントの55%をステータスの節に使う人で計算）
