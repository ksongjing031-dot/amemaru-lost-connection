# 11月24日のバランスの調節（Phase 8 その2の前）

11月24日に、2階まで遊んでいただいたうえでの改善点をいただきました。3階を作る前に、1〜2階の強さを直しました。

## いただいた改善点と、直したこと

| ご指示 | 直したこと |
| --- | --- |
| 時間が掛からない（二人で30分程度。今のままでは一日どころかすぐに終わってしまう） | 雑魚・名のある魔物・ボスを強くし、2階の封印の門に「名のある魔物を2体とも倒した印」を足した。下の表の目安で、2人で2階に2時間ほど【補完】 |
| 全体的なバランス調節が必要（かなりプレイヤーが一方的） | 1〜2階の敵のHPと攻撃を上げ、防具を弱くした（下の表） |
| キツネの移動速度を少し下げる | 葉影ギツネの速さ 0.36→0.30、回り込みの速さ 1.5倍→1.3倍。葉隠れの長 0.40→0.33、1.6倍→1.4倍 |
| 雑魚モンスターの攻撃力や体力を上げる | 1階は HP 約4倍・攻撃 約1.5倍、2階は HP 約5倍・攻撃 約1.6倍（下の表） |
| 2層のボスの攻撃がわかりづらい（エフェクトをもっと出すなどで対策） | 技の名前をボスのHPの帯の下に出し、予兆を長く濃くし、技ごとの演出を足した（下の「ボスの攻撃を分かりやすく」） |
| 装備が強くて全然削れないので調節が必要 | 防具と盾の防御とHPを下げた（下の表）。古代石の重鎧と盾のナイトは、受けるダメージがおよそ2倍になる |

| ソロでは全然倒せない、パーティーで挑まないと絶対にクリアできないぐらいの難易度 | ボスのHPは、ひとりでも2人ぶん。どのボスにも「みんなで受ける一撃」（ひとりで受けると倒れる）を足した |

### みんなで受ける一撃

- どのボスも、ときどき（1階は42秒・2階は38秒ごと。最初は戦いが始まって20〜25秒）、参加者のひとりの足もとに**青い円**を出します。
  円の中には、真ん中へ寄る矢じりが回り、ボスのHPの帯の下に「▶ 大枝の振り下ろし ― 青い円に集まって、みんなで受けろ」と出ます。
  狙われた人には「あなたの足もとに青い円！」、ほかの人には「○○の足もとに青い円！」と画面の下に出ます。
- 3.2秒のあと、円の中の人みなで**最大HPの160%を分け合います**（防御・回避・盾は効かない。障壁・不屈・身代わりの鈴は効く）。
  ひとりで受けると倒れ、2人なら80%ずつ、3人なら53%ずつ、4人なら40%ずつ。円に誰もいなければ、狙われた人がひとりで受けます。
  怒ったあとは200%になります。
- 戦いで初めて出たときは、手がかり「青い円は『みんなで受ける重い一撃』……ひとりで受けると倒れる！」が出ます。
- ひとりでの確かめのときは、`/amemaru admin boss share safe` で、印と演出だけ（ダメージなし）にできます（`normal` で戻す。サーバーを止めると戻る）。

## ボスの攻撃を分かりやすく（2階を中心に）

- **技の名前**：ボスが技を出し始めると、ボスのHPの帯の下に「▶ 枝の薙ぎ払い（前の扇）」のように出し、下の細い帯で、当たるまでの残りを見せます。
  赤はよける技、青はみんなで受ける一撃。1階のボスにも出ます（薙ぎ払い・角の突き上げ・後ろ蹴り・突進・踏みつけ・大跳躍・根の牙・角笛）。
- **予兆**：地面の赤い印（扇・線・円）を濃くしました（どのボスも）。2階のボスは予兆を長くしました（薙ぎ払い 0.9→1.2秒、根の割れ目 1.2→1.5秒、根の牢 1.4→1.8秒）。
- **演出**（2階のボス）
  - 枝の薙ぎ払い：振りかぶるときに枝のきしむ音と羽ばたきの音。当たると、扇いっぱいに斬撃と散る葉
  - 根の割れ目：ためる間、線の上で土がふるえ、地鳴りの音。当たると、線の上に根（丸太の粒）が高く突き上がる
  - 根の牢：ためる間、円の中で根がうごめく。当たると円のふちに根の柱が立ち、捕まった人のまわりに、動けない間ずっと根の檻が見える
  - 迷い灯を呼ぶ：頭の上に「！」
  - 森の灯りを吸い込む：古樹のまわりから黒い霧が広がる
  - 初めての薙ぎ払いと根の牢で、手がかり（よけ方）を出す
- **封印の門の知らせ**：2階の封印の門で「石柱を起動しよう（0/0）」と出ていたのを直しました。足りないものに合わせて「迷いの森をすべてほどこう（1/3）」「この階の名のある魔物を、すべて倒そう（1/2）」と出ます。

## 2階の封印の門

3つの迷いの森をすべて結ぶ（みんなで同じ。その日のうち）のに加えて、白い木立の「葉隠れの長」と管の谷の「苔衣の樹皮兵長」を
2体とも倒した人（人ごと。日が変わっても消えない）だけが通れるようにしました（`floors/floor2.json` の `seal_requires`：
`lost_woods+guardians`）【補完】。名のある魔物は、倒した人と近くのパーティの人に印がつきます。

## 調節のしかた

- サーバーの設定（`serverconfig/amemaru-server.toml`）の `enemyHpMultiplier`・`enemyAttackMultiplier` で、このModの敵（ボスも）
  すべてのHPと攻撃に倍率をかけられます（1.0 が上の表のまま）。
- 敵ごとの数は `data/amemaru/amemaru/enemies/<敵>.json`、ボスの人数の補正と怒るまでの時間は `floors/floor<階>.json` の `boss_room`。
- 管理者のコマンド：`/amemaru admin boss share safe|normal`（みんなで受ける一撃のダメージ）・
  `/amemaru admin floor guardians <階> done|reset <人>`（名のある魔物を倒した印）。

## 自動テスト

- `BalanceGameTests`：雑魚と名のある魔物の強さの下限（2回目の調節に合わせて下げた）・葉影ギツネの速さ／ボスはひとりでも2人ぶんのHP・みんなで受ける一撃はひとりで
  受けると倒れ、2人なら倒れない・予兆は3秒以上・2人ぶんのHPの下限・怒るまで15分以上／古代石の重鎧と盾の合計
- `ForestGameTests`：2階の封印は、迷いの森を3つ結んでも、名のある魔物を2体とも倒すまで開かない（知らせは「名のある魔物」）
