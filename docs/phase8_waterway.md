## 設計【補完】

### 広さと区画

- 480×480（1階の約1.6倍）、高さ64。天井のある地下。歩ける所は、上の通路（高さ26）と下の水路（高さ14）の2つの層
- 区画は8つ

| 区画 | 中身 |
| --- | --- |
| 入口の船着き場 | 戻りの円・道しるべの石 |
| 大水路 | 真ん中の広い水路と両岸の通路・橋。中継の灯1・水路管理局（古代記録の掲示板） |
| 西の貯水槽 | 柱の並ぶ広い貯水槽。澱みスライム。西の水門の操作室 |
| 東の水車の間 | 大きな水車が回る。水路掃除機兵。東の水門の操作室 |
| 沈んだ区画 | 水に沈んだ部屋の並び。水門で水を引くと歩ける。牙ナマズ |
| ネズミの巣穴 | 細い抜け道。水門ネズミの群れ。近道 |
| 白い流れ | 水が白い空白に消える所（ロストの侵食） |
| 大水門 | ボスの部屋 |

### ギミック：二か所の水門を同時に

- 離れた2つの操作室に「水門のハンドル」が1つずつ。片方を回すと、3秒の間だけ回ったまま（「向こうの水門を待っている…3」）。
  その間にもう片方も回すと、水門が動いて水の流れが変わる（その日のうち、みんなの分）。片方だけでは、戻ってしまう
- 水門は3組：①西と東（沈んだ区画の水を引く → 下の層へ）②沈んだ区画の奥の2か所（白い流れへの道）③大水門の前の2か所（ボスの部屋の封印）
- ひとりでは回せない（ふたつの部屋が離れている）。パーティで、声をかけ合って回す

### 封印の門

`seal_requires`：`floodgates+guardians`（3組の水門をすべて動かす（みんなの分）＋名のある魔物をすべて倒した印（人ごと））

### 敵（数値は 11月24日の強さに合わせる）

| 敵 | 動き |
| --- | --- |
| 水路掃除機兵 | 硬い。正面は装甲で、前から受けるダメージを半分にする（後ろか横から）。ブラシの薙ぎ払いと、水の噴射（線。押し出す） |
| 澱みスライム | 倒すと小さいスライム2匹に分かれる。当たると、ねばって少し遅くなる |
| 牙ナマズ | 水の中にいる。水辺に人が来ると、跳ねて噛みつき、水に戻る。水の中では受けるダメージ半分 |
| 水門ネズミ | 5〜6匹の群れ。速い。1匹は弱い |
| 名のある魔物（3体） | 監督機兵（西の貯水槽）・主ナマズ（沈んだ区画）・ネズミの親分（ネズミの巣穴） |

### ボス：大水門の番人ハイドラム

- 大水門を守る、石と青銅の大きな番人。片腕が水の大砲。胸に炉心（水の中にあるときは、ほとんど効かない）
- 部屋は水に沈んでいる。部屋の東西の2つの排水のハンドルを、2人で同時に回すと、水が引いて炉心が出る（25秒。この間は2倍のダメージ）
- 技：水の大砲（長い線）・水の薙ぎ払い（扇）・渦（足もとの円。引き寄せる）・みんなで受ける一撃（大放流）
- ひとりでも2人ぶんのHP【補完】。2人で16分・4人で13分ほど。怒るまで25分
