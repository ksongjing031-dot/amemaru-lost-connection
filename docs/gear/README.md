## 作り方の決まり

- 武器：手に持つと3D（Java版のモデル。22.5度刻み）、持ち物の枠・額縁・地面はドット絵。盾は枠でも3D。
- 【11月23日に決定】持ち物の絵は32×32（「のっぺりしている。デザインや色合いを細かくして質を上げる」のご指示）。品ごとのスクリプトが
  16×16の形を作り、`tools/artgen/enhance_icons.py` が32×32にする（2倍にして、色のかたまりに丸みの陰影・色相をずらした色の段・
  材質ごとの描き込み（金属の光の筋・石のまだら・木目・布の目・結晶の面ときらめき・液のグラデーション）・となりの色を暗くしたふちの線）。
  品ごとのスクリプトを動かしたら、続けて `enhance_icons.py` を動かす（16×16に戻った絵だけ作り直す）。細い絵（剣・杖・弓など）は、
  形を崩さないようにそのまま2倍にしてから描き込む。
- 【11月23日】工房の作業台は `tools/artgen/make_workbenches.py`（2倍の細かさで組んで塗り、ブロックの大きさに戻す。128×128の絵）。
- 【11月23日に決定】籠手は両手にはめ、双短剣は両手に1本ずつ持つ（アイテムは利き手の1つ。もう片方の手が空いていれば、同じ武器を
  描く。`client/render/TwinWeapons.java`・`TwinHandLayer.java`）。籠手のモデルは「腕の座標」で作る（`make_gear_phase6.py`）。
- 剣・大剣を手に持ったときの大きさと片刃の向きは、`tools/artgen/weapons.py` の `hold_display` で決める（剣は1.35倍・大剣は1.7倍。片刃は刃をモデルの +x に作り、持つと刃が前を向くように `edge_forward` で回す）。くわしくは [hold.md](hold.md)。
- 防具・体に表示するアクセサリー・動く武器：GeckoLib（箱のUV）。防具のボーンの名前は `armorHead` など、GeckoLib の決まりどおり。
- 光る部品：Java版は部品ごとの `forge_data`（明るさ15）、GeckoLib は `<絵>_glowmask.png`。
- 形・色・持ち方・確認画像は、すべて `tools/artgen/` のプログラムから作る（手で絵を描き足さない）。作り直すときは、品ごとの `make_gear_*.py` を動かす。
