# デザインの記録帳（武器・防具・装備）

新しい品を作るたびに、下の7つの軸を1行ずつ書き足します。新しい品は、**直近の3つの品と、少なくとも4つの軸で違う**ものにします（毎回同じような形・色にならないように）。
「光る青い結晶に金の縁」のような便利な定番は、使った回数を数え、続けて使いません。

| 軸 | 例 |
| --- | --- |
| 形の骨格 | 縦長・頭が重い・輪・二股・鉤・左右非対称・中が空いた枠・門 |
| 形のくせ | 角ばった・段々・曲線・有機的・結晶的・欠けた・組み積み |
| 主な材質 | 鋼・青銅・骨・石・木・結晶・布・革・毛皮・貝 |
| 色 | 暖色・寒色・無彩色（主色は前の品と変える） |
| 作られ方 | 鍛えた・削り出した・育った・縛った・はめ込んだ・継ぎ接ぎ・組み立てた機械 |
| 見せ場の位置 | 先端・中央・根元・肩・背中・腰・裏 |
| 特別な要素 | 発光・浮遊・回転・揺れる飾り・鎖・房・札・刻印・流れる水 |
