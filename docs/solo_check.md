# ひとりで確かめる：1〜8階のギミックとボスの仕掛け（11月26日）

11月26日のご指示「ボス戦までのギミックをソロでテストできるようにして動作確認できるように。おなじくボス戦でのギミックの確認も」で作った、
ひとりで1〜8階を確かめるための手引きです。何人かで同時に動かす仕掛けは、**ひとり確認モード**を入れると、ひとりでも動かせます【補完】。
仕掛けの決まり（何を・どの順に・どこで）は変えず、「何秒のうちに」と「何人で」だけをゆるめます。

ふだんの遊び（2人以上・本番のサーバー）では、モードを切ってください（サーバーを止めても切れます。入れたままにはなりません）。

**11月27日から**：その階（ボス戦なら戦い）にほかの挑戦者がいないときは、モードを入れなくても、下の表の「時間」の決まりが自動で
ひとり用になります（ご指示「推奨レベルよりもかなり高めの時はソロでも攻略できるように」。[`docs/phase8_1127.md`](phase8_1127.md)）。
モードは、練習用の人形を仲間に数えるため（薄氷・接続判定・切断判定）と、2人以上いてもひとり用の時間で確かめるために使います。

## はじめに（共通の準備）

1. 確かめ用のワールドで、階を建てて開く：`/amemaru admin map build floor <階>`・`/amemaru admin floor unlock <階>`
2. ひとり確認モードを入れる：`/amemaru admin solo on`（今の様子は `/amemaru admin solo`、切るのは `/amemaru admin solo off`）。
   入れると、全員のチャットに「［ひとり確認モード］…」と出ます（入っている間にログインした人にも出ます）
3. ボス戦は**アドベンチャーかサバイバル**で（クリエイティブ・スペクテイターでは戦いに入りません）
4. 倒れないようにする：`/amemaru admin debug guard @s on`（HPが1より減らない。切るのは `off`）。HPとMPを戻す：
   `/amemaru admin debug vitals @s 100 100`
5. 強さ：`/amemaru admin level set @s 40`・`/amemaru admin job set @s amemaru:knight` など

よく使うコマンド：

| コマンド | すること |
| --- | --- |
| `/amemaru admin solo reset <階>` | その階の仕掛けを朝の形に戻し、自分の石柱・名のある魔物・合言葉の印・宝箱も戻し、ボスを出し直す（**はじめから確かめ直す**） |
| `/amemaru admin solo ready <階>` | その階のボスの封印の条件（石柱・迷いの森・水門・壁画・氷像・光の迷路・合言葉・鐘・名のある魔物）を自分の分まで満たし、ボスの部屋の門の前へ移る（**ボス戦だけ確かめる**） |
| `/amemaru admin floor tp <階> <所>` | 移る。所：`enter`（門や円から入ったときと同じ道。字幕や場面も流れる）・`entrance`・`boss`・`pillar1`〜・`woods_<森>`・`valve_<水門>_1`/`_2`・`waypoint1`〜 |
| `/amemaru admin boss skill <階> <技>` | 戦いの間に、ボスにその技（ギミック）を出させる |
| `/amemaru admin boss hp <階> <%>` | 戦っているボスのHPを、最大HPの何%にするか（段階・追いこんだときの演出と曲） |
| `/amemaru admin dummy` | 目の前（3ブロック先）に練習用の人形を置く。モードの間は**仲間の代わり**に数える |

## ひとり確認モードで変わること

| 階 | 仕掛け | ふだん | ひとり確認モード |
| --- | --- | --- | --- |
| 2階 | 迷いの森のこだま | 鐘を鳴らして4秒で返る（鐘から12〜14ブロック離れた人だけ方角が分かる） | 10秒で返る（鳴らしてから離れる間がある。離れないと「聞き分けられない」のはそのまま） |
| 3階 | 水門のハンドル（2つ） | 3秒のうちに両方 | 120秒のうちに両方（片方を回して、もう片方の部屋へ走る） |
| 3階 | ボスの部屋の排水のハンドル（東と西） | 3秒のうちに両方 | 30秒のうちに両方 |
| 5階 | 接続判定（6ブロックのうちに味方がいないと大ダメージ） | ひとりなら判定しない | ひとりでも判定する。人形がそばにいれば「味方がいる」 |
| 5階 | 切断判定（4ブロックのうちに人がいると大ダメージ） | 2人以上のときだけ出る | ひとりでも出る。人形がそばにいれば「近すぎる」 |
| 8階 | 入江の鐘・湖の鐘（順番に鳴らしきるまで） | 90秒・240秒 | 2倍（180秒・480秒） |
| 8階 | 薄氷（2人が3ブロックのうちに乗ると、ひび → 割れる） | ひとりなら割れない | 人形をそばに置けば割れる（人形がなければ、ひとりでは割れないまま） |
| 8階 | 静寂の帳（違う2つの鳴り石を鳴らすと破れる） | 3秒のうちに2つ・帳は20秒 | 30秒のうちに2つ・帳は40秒 |
| レイドのボス | みんなで受ける一撃（円の中の人数で分ける） | 人数で分ける | 円の中の人形も人数に数える（人形は受けない）。1〜8階のボスは使わない |

ほかの仕掛けは、はじめからひとりでも動かせるので、モードでは変えません（1階の仕掛け石は「1人でも走れば間に合う」12秒のまま、など）。

## ひとりでは確かめられないこと（2人以上で）

モードでも、ほかの人の画面や、パーティの仲間に届くことは確かめられません。2人以上のときに見てください。

- パーティの仲間の分も数える（石柱・群れの長・名のある魔物）・仲間に今日の歌が届く（8階の歌の碑）・合言葉をパーティの全員でそろえる（7階）
- 写し身と仲間の見分け（7階。名前の「？？？」の色・HPバーの動き）・パーティの欄が消える（8階の静寂・断線）
- 人数でボスのHPと攻め方が変わる・結び台に戦う人の数だけ乗る（5階）・接続判定と切断判定を本当の仲間で
- ボス戦の曲は、戦いの参加者だけに流れる（部屋の外の人には流れない）

## 自動テスト

`SoloModeGameTests`（組 `solo_mode`。モードはサーバーじゅうの切りかえなので、ほかのテストと同時に動かさない）：モードを切っている間は
水門・排水・鐘の時間がふだんのまま、人形を数えない。入れると時間が延び、人形のそばで薄氷にひびが入り、ひとりで4秒あけて水門の
2つのハンドルを回すと開き、帳の間に5秒あけて違う鳴り石を鳴らすと破れる。切ると、ふだんに戻る。
