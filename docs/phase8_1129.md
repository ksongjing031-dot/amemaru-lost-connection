| AMEMARU：素材 | 素材（敵の落とし物・鉱石・結晶など）と魚 |
| AMEMARU：使用アイテム | 回復薬・マナ水・香草茶・キャンディー・料理・結晶果・道具（帰還の羽・修理の道具・灯り・毒消しなど）・忘却の水・白紙の誓約書・転職の証・市場の手帳・記録帳・NPCゆかりの小物。後ろに、物語と仕掛けの品（騎士団の遺品・ハロルドの認識票・湖底の祠の石板・祈願の札・名前の札・女王の書簡） |

## キャンディー【補完】

食べると3分、ステータスが1つ上がる飴です。右クリックですぐ食べます（回復薬と同じで、食べる間の動きは待たない）。

| キャンディー | 上がるもの | 包み紙 |
| --- | --- | --- |
| 剛力キャンディー | 攻撃 +8% | 赤 |
| 叡智キャンディー | 魔力 +8% | 紫 |
| 鉄壁キャンディー | 防御 +10% | 灰 |
| 疾風キャンディー | 素早さ +10% | 緑 |
| 鋭眼キャンディー | 会心 +4% | 金 |
| 活力キャンディー | 最大HP +8% | 桃 |
| 慈愛キャンディー | 回復量 +8% | 淡い桃 |

- 上がるのは一度に1つです。新しく食べると入れかわります（同じキャンディーなら、3分がはじめから）
- 料理屋の料理の力（こちらも1つ）とは別に重なります
- 食べると、画面の右上と持ち物の画面に、上がっているステータスの印（包み紙の色の飴）と残りの時間が出ます。切れるとチャットで知らせます
- 満タンでも食べられます。ダウンの間は食べられません。食べたあと2秒は、ほかのキャンディーも食べられません（押しっぱなしで続けて
  食べてしまわないように）
- 牛乳を飲むと消えます（ほかの状態と同じ）
- パン屋で1つ150ノット（買い取りは60ノット。相場の基準は120。`tools/datagen/build_shops.py`）。あわせて、9階の素材・アクセサリー・
  レアの相場の基準も、このスクリプトに足しました（前は9階の素材が表になく、スクリプトが止まっていました）
- 数を変えるとき：`data/amemaru/amemaru/consumables/candy_*.json` の `buff`（`stat`・`mode`（`percent` か `flat`）・`amount`・
  `seconds`）。消耗品の定義に `buff` を足したので、回復薬に `buff` を書けば「戻して、しばらく上げる」品も作れます

## 硬直の音

CI で、硬直がかかってから消えて3秒たつまでに、プレイヤーのまわりで鳴った音をすべて書き出して調べました（`client/CiSoundLog`。
CI の写真を撮るときだけ動く）。硬直が消える瞬間そのものには、音は鳴っていませんでした。かわりに、次の2つが見つかりました。

- **氷の魔法の「傷つく声」**：ウィザードの氷柱の音（`skill.wizard.icicle`）が、バニラの「プレイヤーが凍えて傷つく声」
  （`entity.player.hurt_freeze`）でした。さらに、氷の魔法6つ（氷柱・氷礫・凍てつく波動・氷結陣・氷華の檻・絶対零度）に重ねる音
  （11月24日に足した「氷」の型）にも同じ声が入っていて、放ったあと、硬直で止まっている間に、自分が凍えて傷ついたような声がしていました。
  氷柱はトライデントを投げる音（高め）に、重ねる音は氷の澄んだ音（アメジストを叩く音）にかえました
  （`assets/amemaru/sounds.json`・`tools/datagen/build_skill_sounds.py` → `skill_sounds/wizard.json`）
- **「ブッ」の連打**：スキルのキーを押しっぱなしにすると、OSのキーの繰り返しが届き、そのたびにスキルを使おうとして、クールダウン中・
  詠唱中の「使えない」の音（低い「ブッ」）が鳴り続けていました。押した瞬間の1回だけ使うようにし（`client/SkillInput`）、
  「使えない」の音は0.5秒に1回まで、少し小さくしました（手元とサーバーの両方。`SkillService.failSound`）

硬直そのもの（足が止まる長さ・強さ）は変えていません。
