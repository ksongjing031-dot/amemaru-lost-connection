# Phase 7：街を育てる（その3：カジノ）

Phase 7 は Phase 0-B 13章の「**釣り、カジノ（右クリックでGUIを開いて使う。【11月22日に決定】）、寄付と共同事業、コネクション量と輝き段階**」です。4つに分けて作ります。

| 分け方 | 中身 |
| --- | --- |
| その1 | コネクション量（CP）と大結晶の輝き段階。交流の常設の仕組み（[`phase7_connection.md`](phase7_connection.md)） |
| その2 | 釣り（[`phase7_fishing.md`](phase7_fishing.md)） |
| **その3（この文書）** | カジノ「遊戯館ラッキーノット」（ルーレット・ハイ＆ロー・魚レース・両替・景品・カジノナイト・支配人ジゼル） |
| その4 | 寄付と共同事業（寄付の目標と輝き段階の両方で完成し、施設が変わる） |

その3で作ったものの中心は次のとおりです。

- **右クリックで画面が開く**（Phase 0-B 13章【11月22日に決定】）：カジノの中の**ルーレットの卓**・**カードの卓**（ハイ＆ロー）・**2階の魚レースの走路**・**両替の窓口**（入口の間の北）・**景品の交換所**（南）を右クリックすると、カジノの画面がその遊び・窓口のタブで開きます。大広間のルーレットの東に立つ**支配人ジゼル**の会話からも開けます。
- **開場は3日目から**（Phase 0-A 11章「3日目：カジノ開場（ルーレット）」）。それより前に右クリックすると「まだ開場していません」と出ます。
- **チップ**（15章「ゲーム内通貨のみ。チップの購入には1日の上限を設ける」）：両替の窓口のタブで、**ノットでチップを買う（1枚10ノット、1日500枚まで。毎日4時に戻る）**・**チップをノットに戻す**（同じ値。上限なし）。賭けるのはチップだけです。
- **卓**（15章「4人以上の卓で遊ぶとCP」）：だれかが卓の画面を開くと、**賭ける時間（25秒）→ 回る・めくる・走る（6秒）→ 結果（5秒）**をくり返します。卓を囲む人は**同じ勝負**に賭け、右に卓の人と賭けた数、これまでの結果が出ます。**4人以上が賭けた勝負**は、賭けた人それぞれに娯楽のCP（1）。
- **ルーレット**（15章「最初はルーレット（0が一つの形式）」）：0〜36の37の目。一点（36倍が戻る）・赤／黒・奇数／偶数・1〜18／19〜36（2倍）・ダズン・列（3倍）。0 は外の賭けすべての外れで、これが胴元の取り分（2.7%。20章「胴元の取り分約3%」）。回すときにジゼルの口ぐせ「さあ、運命の輪を回しましょう」。
- **ハイ＆ロー**（共同事業②のあと。7章「カードの新ゲーム」）：今のカード（A〜K）より、次のカードが上（ハイ）か下（ロー）かに賭けます。倍率は当たる見込みから3%を引いた数（今が7ならハイ・ローとも×2.10、Aならハイ×1.05）。同じ数は外れ。次の勝負は、めくったカードが今のカードになります。
- **魚レース**（共同事業⑥のあと。7章「釣った魚を走らせて賭ける」）：4つの走路を魚が走り、勝つ魚に賭けます。**持っている魚を出せます**（だれかが賭ける前まで。1回の勝負に1人1匹。魚はなくならない）。空いた走路は館の魚。★が高く、大きい魚ほど少し速く、その日の調子で大きく変わります。倍率は何度も走らせた見込みから3%を引いた数。出した魚が勝つと、出した人にチップ20枚。
- **景品**（15章「見た目の品、称号、留め糸など、強さに直結しない物」）：留め糸・ラッキーノットの旗・飾りの絵・楽の円盤・見た目の服と冠（守りも強さもない）・称号「ラッキーノットの常連」「金の結び目」。
- **カジノナイト**（15章「不定期（運営が開催）。4人以上の卓に配当ボーナス。生放送に合わせて」）：管理者が `/amemaru admin event start casino_night [分]` で始めます。**4人以上が賭けた勝負は、勝ったチップが10%増えます**。カジノナイトに賭けた人に、釣り大会・カジノナイトに参加のCP（20。1夜に1回）。
- **称号**（22章）：「大当たり！」（ルーレットの一点賭けを当てる）・「運命の女神に笑われた」（ルーレットで10回続けて外す）。Phase 6 で定義を入れてあり、その3で数え始めました。

## 2. このPhaseで決めた細かいこと（【補完】）

設計書に書いていない所は、次のように決めました。変えたいときは教えてください。数は `data/amemaru/amemaru/casino/default.json` で変えられます。

### チップと両替

- 1枚10ノット。1日に買えるのは500枚（5,000ノット）まで。日は CP と同じく毎日4時に切り替わります。
- チップはノットに戻せます（同じ値）。館の取り分は、遊びの中の取り分（ルーレットの0・ハイ＆ローと魚レースの3%）だけです。
- 1回の賭けは1〜100枚、1回の勝負で1人が賭けられるのは合計300枚まで。

### 卓の流れ

- 卓は、ルーレット1つ・カードの卓2つ（ハイ＆ロー。南の側廊の2つの卓）・魚レース1つ。
- 賭けたチップは賭けたときに減り、外れたらそのまま、当たれば倍率の分が戻ります（端数は切り捨て）。賭ける時間のうちは「取り消す」で戻せます。
- 画面を閉じても、賭けた勝負は最後まで数えます。賭ける時間のうちにログアウトしたら賭けは戻り、回っている間にログアウトしたら、その場で払います。
- 画面を開いた所から24ブロック（`watch_range`）離れると、卓を離れたことになります（もう一度右クリック）。
- 「4人以上の卓」は、その勝負に**賭けた人**が4人以上のとき。

### ハイ＆ローと魚レース

- ハイ＆ローのカードは毎回まぜなおす（A〜K が同じ見込み）。倍率は 0.97 × 13 ÷ 当たりの数（100分の1で切り捨て）。当たりがない賭け（A でロー・K でハイ）はできません。
- 魚レースの速さ：★1の小さい魚を1として、★が1つ上がるごとに+4%、大きさの割合で最大+6%。その日の調子（±18%）と、1歩ごとのゆらぎで決まります。倍率は1,500回走らせた見込みから（10分の1で切り捨て、×30まで。勝つ見込みがとても高いときだけ、取り分を残すため×1.1より下になる）。
- 魚を出せるのは、**だれかが賭ける前まで**（出したあとに倍率を決めなおすため）。出した魚は、大物ならその大きさで、ふつうの魚は真ん中の大きさで走ります。

### そのほか

- ジゼルは大広間のルーレットの東（西を向く）。会話：「ルーレットで遊ぶ」「チップを両替したい」「遊び方を聞く」「またね」。噂の話（ノアの目撃情報）は物語の Phase 8 で。
- カジノナイトの長さは決めずに始めると60分。勝ったチップのおまけは、勝った分（戻ったチップから賭けたチップを引いた数）の10%。
- config（`amemaru-server.toml` の `[casino]`）の `enabled` をオフにすると、右クリックで画面が開かなくなります。

## 4. 確かめ方

### 1人で

1. `/amemaru admin day set 3` のあと、カジノ（市場通りの東）の大広間で、ルーレットの東に紫のドレスのジゼルが立っていること。話しかけると「ようこそ、ラッキーノットへ。さあ、運命の輪を回しましょう」。
2. 入口の間の北の両替の窓口を右クリックすると、カジノの画面の「両替」が開くこと。「100枚買う」でチップが増え、ノットが減ること。500枚で「今日はもうチップを買えません」になること。「全部戻す」でノットに戻ること。
3. ルーレットの卓を右クリックすると「ルーレット」が開き、「賭けの時間 あと○秒」が数えられること。盤のマスを押すと、選んだ枚数がそのマスに賭けられ（マスが紫の枠で囲まれる）、時間が来ると帯が回って止まり、当たればチャットに「当たり！」とチップが戻ること。一点賭けを当てると称号「大当たり！」。
4. 景品の交換所を右クリックすると「景品」が開き、チップで留め糸・旗・見た目の服・称号と取りかえられること。見た目の帽子を頭に着けても、守りが増えないこと。
5. `/amemaru admin casino unlock highlow true` のあと、南の側廊のカードの卓で「ハイ＆ロー」が、`casino unlock fishrace true` のあと、2階の宴の間の走路で「魚レース」が遊べること。魚レースで「この魚を出す」を押すと、持っている魚が走路に出ること。

### 2人以上で

1. 4人で同じ卓に賭けると、結果のあとに娯楽のCP（1）が入ること（画面の右の「賭けた人 4／4」が光る）。3人では入らないこと。
2. `/amemaru admin event start casino_night 10` で全員の画面にカジノナイトが出て、4人以上の卓で勝つと「カジノナイトのおまけ」がチャットに出ること。参加のCP（20）が1夜に1回入ること。

### 自動の確かめ（GameTest と CIの写真）

- `CasinoGameTests`：決まり（右クリックの所・景品・見た目の品に守りがない）／ルーレットの決まり（37の目・どの賭けも 36/37・0は外の賭けの外れ）／両替（1日の上限と4時の切り替え・ノットに戻す・景品と称号）／ルーレットの卓（4人で賭けて払う・4人以上の卓のCP・「大当たり！」・カジノナイトのおまけと参加のCP・10回続けて外す）／ハイ＆ロー（印の前は遊べない・倍率・同じ数は外れ）／魚レース（見込みと倍率・魚を出す・賭けのあとは出せない・払い戻し）。
- CIの写真：`phase7c_hall`（大広間のルーレットとジゼル）・`phase7c_dialogue`・`phase7c_roulette`（ルーレットの卓の右クリックで開いた画面）・`phase7c_roulette_bets`・`phase7c_roulette_spin`・`phase7c_roulette_result`・`phase7c_cashier`・`phase7c_prizes`・`phase7c_highlow`・`phase7c_highlow_result`・`phase7c_fishrace`・`phase7c_fishrace_run`・`phase7c_fishrace_result`・`phase7c_night`。
