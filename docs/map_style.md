# マップの建物の様式と見本：コネリアの冒険者ギルド・武器工房・防具工房

コネリアの**冒険者ギルド**を、建築の文書の「PHASE 1：冒険者ギルド」の設計（役割・部屋・寸法・平面図・動線・外観・内装・まわり・
建てられるかの確かめ・10点の評価）どおりに組み立て、構造物ファイルにしました。
**武器工房**と**防具工房**も、同じ手順で「PHASE 2：武器工房」「PHASE 3：防具工房」の設計どおりに組み立てました（このページの後ろの節）。
11月17日に作った見本（48×48×40、正面は南）は、この設計に置き換えました。様式（材料・層・屋根・飾り）は見本のものを引き継ぎ、
建築の文書の「都市のルール」に合わせて直しています。これから作るコネリアの建物も、この様式に合わせます。

設計の詳しいこと（平面図・断面・部屋ごとの家具の理由・確かめの結果）は、建築の文書の「PHASE 1：冒険者ギルド」「PHASE 2：武器工房」「PHASE 3：防具工房」のタブにあります。

### 工房の地区の違い（武器工房）

ギルドの様式からの違いは次のとおりです。

- 足もとは、古代の白い石ではなく、道から1段上げた磨いた安山岩の帯（+1）。古代の石は、奥の古代炉のまわりだけ。
- 屋根は黒い瓦（深層岩タイル）。都市の決まりの、屋根の2種類目。妻の縁と破風板はギルドと同じダークオーク。
- 火を扱う所（炉の間）は軒まで石の塊にし、住まいとの間に土台から棟までの石の防火の壁を立てる。
- 煙突は深層岩レンガ。炉の煙は干し草の上の焚き火で高く、台所の煙は干し草なしで低く。
- 2階の窓は雨戸をつけず、花箱だけ（柱の間の漆喰を見せる）。
- 旗は赤に黒の斜めの十字と白い縁（交わる剣）【提案】。看板は吊り看板と、その下の額縁の剣。
- 額縁と防具立て（もの）で、武器を掛ける・立てかける・梁から吊るす。

### 工房の地区の違い（防具工房）

武器工房と同じ工房の地区の決まり（安山岩の帯・黒い瓦・雨戸なしの2階の窓）に、次を足しています。

- 三角の壁を通りに向け（妻入り）、2階を正面へ1つ張り出して持ち送りで受ける。向かいの武器工房（平入り）と顔を分ける。
- 環状路との角の建物なので、西の屋根に小さな妻（幅5、2：1）を出し、通りと環状路の両方に顔を向ける（都市のルール⑥）。
- 1階の窓は飾り窓2つだけ。鎧を着せた防具立てを窓のすぐ内側に置き、入口の両脇の端の帯にも門番の甲冑を立てる。
- 旗は灰に赤い十字。正面の壁に模様入りの盾（額縁）を4つ。吊り看板の下にも店の盾。
- 小さな炉の煙突は屋根の東の面から出し、干し草を敷かない（低い煙。武器工房の高い煙と見分ける）。
- 西の壁の外に、低い石の塀で囲んだ半屋外の作業場。壁ぎわの半分に片流れの屋根（黒い瓦、濃い木の柱と梁）。
- 店の型紙の壁は、章が進むと額縁に型紙が1枚ずつ増える（`build_armor.py` の `PATTERNS` と `patterns_world`）。

### 飾りの守りの自動テスト（GameTest）

`gametest/MapDisplayGameTests.java` の4本です。ギルド・武器工房・防具工房の構造物に入っている額縁（1・30・27）と防具立て（0・2・9）を、保存されたデータのまま空のテストの場所に作り、サバイバルとアドベンチャーの偽のプレイヤーで、1つずつ「左クリック・素手で右クリック・物を持って右クリック・投げた物・爆発」を試します。中身・向き・装備が1つも変わらず、手に何も来ず、アイテムが1つも落ちなければ合格です。もう1本は、固定していないふつうの額縁と防具立てなら、アドベンチャーでも中身が取れることを確かめます（守りが要る理由で、テストのやり方が正しいことの確かめでもあります）。

建物そのものは置きません（クライアントの世界でも同じテストを出現地点のそばで回し、その上でスキルの写真を撮るため）。額縁か防具立てのある建物を足したら、このファイルにテストを1つ足します。

### 設計データで確かめていること

`build_guild.py` を書き直したら、次を確かめています（結果は建築の文書の「建てられるかの確かめ」）。

- 使っているブロックの状態がすべて 1.20.1 にあること
- 地面とつながらない（浮いた）ブロックがないこと
- 扉の上下がそろい、前と後ろに立てること
- 入口から、すべての部屋・屋根裏・鐘の間・外階段の上へ、跳ばずに歩いて行けること
- 建物の中に、暗くて敵が湧ける所がないこと

`build_weapon.py` では、これに加えて次を確かめています（結果は建築の文書の「PHASE 2：武器工房」の12章）。

- 表の扉だけを使う客は、カウンターの内側・材料の部屋・炉の間・2階に入れないこと
- 吊る灯りの上・置く灯りの下にブロックがあること。旗と看板が壁に掛かり、中身（文字・模様）があること
- 額縁と防具立ての置き場所があいていて、額縁の後ろ（上向きなら下、下向きなら上）にブロックがあること
- 12日目の古代炉の形の範囲に、額縁などのものがないこと

`build_armor.py` でも同じことを確かめています（結果は建築の文書の「PHASE 3：防具工房」の12章）。客がカウンターの内側・工房・
作業場・2階に入れないこと、作業場の地面に暗くて敵が湧ける所がないことも見ます。

### 手で確かめること

1. クリエイティブのワールドで、平らな所に立つ（構造物は、立った所から東へ36、南へ41ブロック広がります）。

4. 中を歩く：入口 → 受付 → 大階段で2階 → 表の露台。塔のらせん階段で屋根裏と鐘の間へ。北の外階段で2階のギルドマスター室へ。

## 6. 世界観の追加【補完】

- 本館は、もとは結晶騎士団の詰所です。15年前に騎士団が冒険者ギルドに改組されたとき、建物はそのまま引き継がれました【補完】。
- 北西の塔は、騎士団の見張りの塔でした。もとの騎士団長の部屋（今のギルドマスター室）から、塔の階段へ直接出られます【補完】。
- 塔の鐘は、騎士団の時代には遠征の出発と帰還を知らせていました。第七次塔遠征の後は、塔の新しい階層が開いた日にだけ鳴らします【補完】。（階層が開いたときに街じゅうで鐘の音を鳴らす演出は【提案】です。）
- ギルドマスター室には、第七次塔遠征で戦死した騎士団の11人をしのぶ台があり、ろうそくが11本ともっています【補完】。
- 受付のカウンターの南の端が、塔で拾った素材の買い取りと、依頼の品の受け渡しの窓口です【補完】。
- 北の外階段は、2階のギルドマスター室へ直接上がる階段です。夜遅く北門から帰った遠征隊が、ガルドに報告するために使います【補完】。
- 武器工房のカウンターの後ろの見せ棚には、ドランの「とっておき」の名品（鉄の剣・ダイヤの剣・鉄の斧）を掛けています【補完】。
- 武器工房は火を扱うので、地面には木や花を植えず、緑は2階の花箱とポーチの植木鉢だけです【補完】。
- 14日目の「二人打ち」は、古代炉の前の金床で行います。20日目にドランが支援隊の修理を指揮するのは、炉の前と作業庭です【補完】。
- 防具工房の西の飾り窓の甲冑は、ベルタが最後に打った騎士団の鎧です。店の西の壁には、騎士団の古い旗（青と白）を掛けています【補完】。
- 入口の要石は、騎士団の時代の紋の石です【補完】。入口の両脇の門番の甲冑は【提案】です。

## 7. 差し替えてほしい素材

ありません（すべてバニラのブロックです）。材料を変えたいときは、`tools/mapgen/build_guild.py` の始めの `Palette(...)`（漆喰・柱・縁・屋根）と、
材料の関数（`gray_stone`・`white_stone`・`paving`）を変えて、スクリプトを動かし直せば、構造物ファイルが作り直されます。
武器工房は `tools/mapgen/build_weapon.py` の `Palette(...)` と、材料の関数（`gray_stone`・`ancient_stone`・`apron_paving`・`alley`・`yard_ground`・`forge_floor`）です。
防具工房は `tools/mapgen/build_armor.py` の `Palette(...)`、材料の関数（`gray_stone`・`apron_paving`・`alley`・`yard_ground`）と、店の色（`SHOP_BANNER`・`SHOP_SHIELD`）です。

## 8. 変えたいところがあれば

様式（色・屋根の急さ・飾りの多さ）や、ギルドの形（塔の高さ・破風の大きさ・張り出しの場所など）、武器工房の形（アーチの大きさ・煙突の高さ・作業庭など）で
変えたいところがあれば、教えてください。
決めた様式で、Phase 5のコネリアの区画（中央広場・商店街・教会・工房・倉庫・塔の門など）を作ります。
