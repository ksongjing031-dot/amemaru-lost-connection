# マップの建物の様式と見本：コネリアの冒険者ギルド

コネリアの**冒険者ギルド**を、建築の文書の「PHASE 1：冒険者ギルド」の設計（役割・部屋・寸法・平面図・動線・外観・内装・まわり・
建てられるかの確かめ・10点の評価）どおりに組み立て、構造物ファイルにしました。
11月17日に作った見本（48×48×40、正面は南）は、この設計に置き換えました。様式（材料・層・屋根・飾り）は見本のものを引き継ぎ、
建築の文書の「都市のルール」に合わせて直しています。これから作るコネリアの建物も、この様式に合わせます。

設計の詳しいこと（平面図・断面・部屋ごとの家具の理由・確かめの結果）は、建築の文書の「PHASE 1：冒険者ギルド」のタブにあります。

## 1. 作ったもの

| 大きさ | 建物 33×25。床の高さ（道から）は1階 +2・2階 +9・屋根裏 +14・鐘の間 +24。本館の棟 +27、正面の破風の棟 +23、塔の先 +34 |

建物の部分：

- **本館**：1階は灰色の石（足もとは古代の白い石の帯）、2階は木組みと漆喰。正面の南と、塔と破風の間の2階は1つ外へ張り出す。
  屋根は南北に棟が通る1：1の赤い瓦。正面に屋根の窓1つ、裏に2つ。南の妻は張り出し、外に暖炉の煙突。
- **正面の破風**：入口の上。古代の白い石の**玄関ポーチ**（幅7のアーチ）の上に、屋根のある**表の露台**。頂に飾りの小塔。
- **塔**（北西の角、9×9）：騎士団の見張りの塔。中はらせん階段（2階・屋根裏・鐘の間へ）。上に**鐘の間**（北・南・西に開口）と緑青の銅の四角すい。
- **北の外階段**：2階のギルドマスター室の扉へ直接上がる。上の踊り場は4本の石の柱で受け、小さな屋根がある。
- **小広場**：古代の白い石畳、ランタン灯2本、長椅子、花の帯。
- **中**：1階は受付（絨毯の軸の先）・依頼の掲示板・待合・談話の場（暖炉）・酒場・台所・大階段・塔の地図の壁。
  2階は作戦室・ギルドマスター室・休憩室・事務室・資料室と、吹き抜けを囲む回廊。屋根裏は物置とリリアの部屋【提案】。

## 4. ゲーム内での確認

### 自動で確かめていること（GitHub Actions）

クライアントの起動の後、今までの写真に続けて、空の高い所（y=200）に草の広場を敷いてギルドを置き、観戦モードで次の6枚を撮ります
（撮る所は `build_guild.py` の `VIEWS` と同じ）。

| 写真 | 向き |
| --- | --- |
| `map_guild_front` | 正面（西）から |
| `map_guild_left` | 左前（北西）から。塔と北の妻、北の外階段 |
| `map_guild_right` | 右前（南西）から。張り出しと南の妻、煙突 |
| `map_guild_close` | 入口の近く。ポーチ、表の露台、正面の破風 |
| `map_guild_aerial` | 上から。屋根の交わりと屋根の窓 |
| `map_guild_back` | 裏（北東）から。裏口、台所の煙突、裏の屋根の窓 |

### 設計データで確かめていること

`build_guild.py` を書き直したら、次を確かめています（結果は建築の文書の「建てられるかの確かめ」）。

- 使っているブロックの状態がすべて 1.20.1 にあること
- 地面とつながらない（浮いた）ブロックがないこと
- 扉の上下がそろい、前と後ろに立てること
- 入口から、すべての部屋・屋根裏・鐘の間・外階段の上へ、跳ばずに歩いて行けること
- 建物の中に、暗くて敵が湧ける所がないこと

### 手で確かめること

1. クリエイティブのワールドで、平らな所に立つ（構造物は、立った所から東へ36、南へ41ブロック広がります）。
2. `/place template amemaru:map/conelia/guild_hall ~ ~-1 ~` で置く（地面の草の層が、足もとの地面に重なります）。
3. 西に回って正面を見る。`/time set night` にすると、灯りが目立ちます。
4. 中を歩く：入口 → 受付 → 大階段で2階 → 表の露台。塔のらせん階段で屋根裏と鐘の間へ。北の外階段で2階のギルドマスター室へ。

## 5. 既知の問題と、これからやること

| 内容 | 予定 |
| --- | --- |
| 構造物の範囲（36×41）は、建物の敷地より北へ5・南へ2・東へ3広い（北の外階段・妻の縁・裏の段）。置くと、その範囲の中は片づく | 地図を組むとき（Phase 0-B の `map build`）は、隣の区画より先に置くか、空気を置かない設定で置く |
| 個人倉庫の受付棟（PHASE 6）がまだない。受付棟への扉の外は、今は外へ降りる2段 | 受付棟を作るときに段を外し、受付棟の床につなぐ。受付棟の屋根は、本館の軒（+13〜+14）の下に収める |
| ギルドの地下の個人倉庫（保管庫）がまだない | PHASE 6 で、地下の区画として別の構造物にする |
| NPC（リリア・ガルド・酒場の主人）は構造物に入っていない | 立つ所（受付・ギルドマスター室の机・酒場のカウンターの裏）は決めてある。Phase 5 でコネリアを作るときに置く |
| ギルドマスター室の古い団長の剣は、まだ飾っていない | 額（エンティティ）で飾るので、Phase 5 で置く |

## 6. 世界観の追加【補完】

- 本館は、もとは結晶騎士団の詰所です。15年前に騎士団が冒険者ギルドに改組されたとき、建物はそのまま引き継がれました【補完】。
- 北西の塔は、騎士団の見張りの塔でした。もとの騎士団長の部屋（今のギルドマスター室）から、塔の階段へ直接出られます【補完】。
- 塔の鐘は、騎士団の時代には遠征の出発と帰還を知らせていました。第七次塔遠征の後は、塔の新しい階層が開いた日にだけ鳴らします【補完】。（階層が開いたときに街じゅうで鐘の音を鳴らす演出は【提案】です。）
- ギルドマスター室には、第七次塔遠征で戦死した騎士団の11人をしのぶ台があり、ろうそくが11本ともっています【補完】。
- 受付のカウンターの南の端が、塔で拾った素材の買い取りと、依頼の品の受け渡しの窓口です【補完】。
- 北の外階段は、2階のギルドマスター室へ直接上がる階段です。夜遅く北門から帰った遠征隊が、ガルドに報告するために使います【補完】。

## 7. 差し替えてほしい素材

ありません（すべてバニラのブロックです）。材料を変えたいときは、`tools/mapgen/build_guild.py` の始めの `Palette(...)`（漆喰・柱・縁・屋根）と、
材料の関数（`gray_stone`・`white_stone`・`paving`）を変えて、スクリプトを動かし直せば、構造物ファイルが作り直されます。

## 8. 変えたいところがあれば

様式（色・屋根の急さ・飾りの多さ）や、ギルドの形（塔の高さ・破風の大きさ・張り出しの場所など）で変えたいところがあれば、教えてください。
決めた様式で、Phase 5のコネリアの区画（中央広場・商店街・教会・工房・倉庫・塔の門など）を作ります。
