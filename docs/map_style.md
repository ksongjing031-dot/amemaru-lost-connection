# マップの建物の様式と見本：コネリアの冒険者ギルド・武器工房・防具工房・装飾工房・商店街・個人倉庫・フリーマーケット・結びの教会・釣り堀・カジノ・塔の入口

コネリアの**冒険者ギルド**を、建築の文書の「PHASE 1：冒険者ギルド」の設計（役割・部屋・寸法・平面図・動線・外観・内装・まわり・
建てられるかの確かめ・10点の評価）どおりに組み立て、構造物ファイルにしました。
**武器工房**・**防具工房**・**装飾工房**・**商店街**・**個人倉庫**・**フリーマーケット**・**結びの教会**・**釣り堀**・**カジノ**・**塔の入口**も、同じ手順で「PHASE 2：武器工房」「PHASE 3：防具工房」「PHASE 4：装飾工房」「PHASE 5：商店街」「PHASE 6：個人倉庫」「PHASE 7：フリーマーケット」「PHASE 8：結びの教会」「PHASE 9：釣り堀」「PHASE 10：カジノ」「PHASE 11：塔の入口」の設計どおりに組み立てました（このページの後ろの節）。
11月17日に作った見本（48×48×40、正面は南）は、この設計に置き換えました。様式（材料・層・屋根・飾り）は見本のものを引き継ぎ、
建築の文書の「都市のルール」に合わせて直しています。これから作るコネリアの建物も、この様式に合わせます。

設計の詳しいこと（平面図・断面・部屋ごとの家具の理由・確かめの結果）は、建築の文書の「PHASE 1：冒険者ギルド」「PHASE 2：武器工房」「PHASE 3：防具工房」「PHASE 4：装飾工房」「PHASE 5：商店街」「PHASE 6：個人倉庫」「PHASE 7：フリーマーケット」「PHASE 8：結びの教会」「PHASE 9：釣り堀」「PHASE 10：カジノ」「PHASE 11：塔の入口」のタブにあります。

建物の部分：

- **本館**：1階は灰色の石（足もとは古代の白い石の帯）、2階は木組みと漆喰。正面の南と、塔と破風の間の2階は1つ外へ張り出す。
  屋根は南北に棟が通る1：1の赤い瓦。正面に屋根の窓1つ、裏に2つ。南の妻は張り出し、外に暖炉の煙突。
- **正面の破風**：入口の上。古代の白い石の**玄関ポーチ**（幅7のアーチ）の上に、屋根のある**表の露台**。頂に飾りの小塔。
- **塔**（北西の角、9×9）：騎士団の見張りの塔。中はらせん階段（2階・屋根裏・鐘の間へ）。上に**鐘の間**（北・南・西に開口）と緑青の銅の四角すい。開口の下の段には濃い木の柵の手すり（11月21日の街全体の通しの確かめで足した。開口から屋根へ下りると、跳ばずには戻れなかった）。
- **北の外階段**：2階のギルドマスター室の扉へ直接上がる。上の踊り場は4本の石の柱で受け、小さな屋根がある。
- **小広場**：古代の白い石畳、ランタン灯2本、長椅子、花の帯。
- **まわりの灯り**：北西の庭（塔の道の側。小広場の2本と同じ両腕）と、南の植え込みの帯（環状路の側。片腕）に再建のランタン灯を1本ずつ（11月21日に足した。この2か所の地面が、暗くて湧ける所だった。南の1本は、環状路を作るときの灯りの並びの1本目）。
- **中**：1階は受付（絨毯の軸の先）・依頼の掲示板・待合・談話の場（暖炉）・酒場・台所・大階段・塔の地図の壁。
  2階は作戦室・ギルドマスター室・休憩室・事務室・資料室と、吹き抜けを囲む回廊。屋根裏は物置とリリアの部屋【提案】。

### 工房の地区の違い（武器工房）

ギルドの様式からの違いは次のとおりです。

- 足もとは、古代の白い石ではなく、道から1段上げた磨いた安山岩の帯（+1）。古代の石は、奥の古代炉のまわりだけ。
- 屋根は黒い瓦（深層岩タイル）。都市の決まりの、屋根の2種類目。妻の縁と破風板はギルドと同じダークオーク。
- 火を扱う所（炉の間）は軒まで石の塊にし、住まいとの間に土台から棟までの石の防火の壁を立てる。
- 煙突は深層岩レンガ。炉の煙は干し草の上の焚き火で高く、台所の煙は干し草なしで低く。
- 2階の窓は雨戸をつけず、花箱だけ（柱の間の漆喰を見せる）。
- 旗は赤に黒の斜めの十字と白い縁（交わる剣）【提案】。看板は吊り看板と、その下の額縁の剣。
- 額縁と防具立て（もの）で、武器を掛ける・立てかける・梁から吊るす。

### 工房の地区の違い（防具工房）

武器工房と同じ工房の地区の決まり（安山岩の帯・黒い瓦・雨戸なしの2階の窓）に、次を足しています。

- 三角の壁を通りに向け（妻入り）、2階を正面へ1つ張り出して持ち送りで受ける。向かいの武器工房（平入り）と顔を分ける。
- 環状路との角の建物なので、西の屋根に小さな妻（幅5、2：1）を出し、通りと環状路の両方に顔を向ける（都市のルール⑥）。
- 1階の窓は飾り窓2つだけ。鎧を着せた防具立てを窓のすぐ内側に置き、入口の両脇の端の帯にも門番の甲冑を立てる。
- 旗は灰に赤い十字。正面の壁に模様入りの盾（額縁）を4つ。吊り看板の下にも店の盾。
- 小さな炉の煙突は屋根の東の面から出し、干し草を敷かない（低い煙。武器工房の高い煙と見分ける）。
- 西の壁の外に、低い石の塀で囲んだ半屋外の作業場。壁ぎわの半分に片流れの屋根（黒い瓦、濃い木の柱と梁）。
- 店の型紙の壁は、章が進むと額縁に型紙が1枚ずつ増える（`build_armor.py` の `PATTERNS` と `patterns_world`）。

### 装飾工房の違い

工房通りにあっても火を使わない店なので、屋根と足もとはギルドと同じ街の基本の形にして、次を足しています。

- 屋根は赤い瓦（1：1）。工房通りに平入りにし、入口の上に小さな妻（幅4、2：1）を立てる。角の建物なので、2階を西（中央広場の側）へ張り出して妻を広場に向ける。
- 足もとは道から1段で、腰石（いちばん下の段）は古代の白い石（磨いた閃緑岩）。入口の両脇の付け柱と、アーチの窓の角・窓台・要石は石英（古代の細工）。角は磨いた安山岩と石レンガを交互に。
- 正面の西に出窓（ショーウィンドウ）。腰は石英レンガ、ガラスは3面、小屋根だけ緑青の銅（都市のルール⑥の例外）。中に晶洞の切り口の飾り。
- 入口の上に、旗と同じ水色と白の市松の日よけ（濃い木の跳ね上げ戸の台に敷物）。旗は水色に白い菱形と白い縁、吊り看板の下にアメジストの欠片。
- 中は、入口から水色の床の軸の先に、原石の上のガラスのカウンターと、奥の宝石の額縁の棚。カウンターの真上に吊り灯り（都市のルール⑦で装飾工房に許した大きな吊り灯り）。
- 煙突は寝室の暖炉の1本だけ（石レンガ、2×1）。火を使わないので、地面にも花を植える。
- 奥の額縁の棚の真ん中の上は「留め具の枠」。第3章で額縁に留め具が入る（`build_accessory.py` の `CLASP_SHOWN` と `clasp_world`）。

### 商店街の違い

ギルドと同じ街の基本の様式（灰色の石の1階、木組みと漆喰の2階、赤い瓦）で、店を4つの型の組み替えにしています。

- 型：A 平入り2階（張り出し）、B 妻入り2階、C 妻入り3階（張り出し）、D 角の平入り2階（妻を横の道に向け、横にも入口と吊り看板）。同じ向きが4つ続かないように並べ、3階建ては2軒だけ。
- どの店も、吊り看板の下に品の額縁、窓台を広げた店先のカウンターに品（額縁・ブロック）、入口に1段の踏み段。2階の窓に花箱、店の色の旗（白い縁）。
- 中は、前が売り場（左右の壁ぎわに2段の樽の戸棚。樽のふたと上の壁に品の額縁）、高さ1.5のカウンター（端は柵の門）、奥が仕事場（店ごとの道具）と、カウンターの後ろから上る階段。2階は住まい（3階建ては2階が仕事部屋、3階が寝室）。

遊戯館「ラッキーノット」は、冒険者と旅人が集まる社交場です（Phase 0-A）。街と同じ材料（1階は灰色の石、2階は木組みと漆喰、
土台は古代の白い石）に、カジノだけの黒い瓦と金の縁、紫と黄と黒の布、たくさんの灯りを足しました（都市のルール③「カジノは布と灯りで色を出し、窓のガラスは色なし」、⑥「黒で引き締め、金の縁と布で華やかにする」）。

- 正面（参考画像 casino_02）：左右対称。真ん中の入口の間（幅8）だけを石にし、急な切妻（2：1、棟 +24）を通りへ向けていちばん高くする。破風に大看板（「遊戯館／ラッキーノット」「さあ、運命の輪を回しましょう」）と「運命の輪」の丸窓（真ん中は金の軸）。1階は古代の白い石のアーチの入口（幅4、上の角を丸める。両開きの濃い木の扉、脇と上のガラス、金の要石）、2階は支配人室から出る表の露台（白い石英の柱2本、閃緑岩の手すり、角の灯り）。両端の角に、2階から上の小塔（4×4、木組みと漆喰、石の持ち送りで受ける。四角すいの屋根の頂に旗）。
- 屋根：黒い瓦（深層岩タイル）。前の棟・奥の棟は 1：1 の寄棟、大広間は 1：1 の切妻（北と南に破風）、真ん中の帯は 2：1 の切妻で前から後ろまで通る（入口からVIPルームへの軸を、いちばん高い屋根で見せる）。軒の下の縁と破風板は金色（なめらかな砂岩）、破風の縁（屋根より1段高い所）は黒（磨いた深層岩）で、金は細い線にする。
- 窓：1階は幅3の上の角を丸めたアーチの窓（要石は模様入りの石レンガ）、2階は木組みの柱の間に2つずつ組の窓（参考画像 casino_02）。正面の1階の窓の上に紫と黄のしまの日よけ（羊毛。都市のルール③の「羊毛は日よけと布だけ」）。
- 中の色（参考画像 casino_01）：大広間の柱は濃い木の丸太に金の帯（模様入りの砂岩）と、身廊の側に赤い布（旗）。ルーレットのまわりの床に白い輪と金の輪、真上に大きな吊り灯。赤は壁一面にせず、絨毯（入口からの軸）と布で、金は砂岩の帯と灯りの色で出す。金のブロックは地下の金庫の3つだけ（③の「金ブロックは1施設に数個まで」）。
- 旗：カジノの色は紫と黄、黒（⑦）。紫の地に黄の菱形、黒の飾り縁、白い縁。3枚（両端の小塔の頂と、南の面の南門から見える所）。品は金のリンゴ（入口の吊り看板の下の額）。
- 灯り：前の小広場に再建のランタン灯（両腕）2本、露台の下と柱の上の灯り、北の路地・南の小道・東の通路の壁のランタンとランタン灯。中は大広間の大きな吊り灯（外の輪 6×6・内の輪 4×4、ランタン16・ろうそく）と、梁から吊る灯り、宴の間の陸梁から吊る灯り。天井から吊る大きな灯りは、カジノとギルドの広間と装飾工房だけ（⑦）。
- 地下（秘密の階）：VIPルームの本棚の扉から下りる。噂の間は古代の白い石の壁と魂のランタン（青い灯）、初代の金庫は石英レンガの壁で、閉じた鉄の扉と鉄格子の窓からのぞく。働く人の階段の下の酒と道具の地下室は、土台の鉄格子の小窓で、地下があると外から分かる（③）。
- 入れ物：樽と、瓶の見せ物（醸造台の形。酒場の棚とVIPルームの2つ）は鍵つき（`Lock`「amemaru:casino_lock」）。瓶の見せ物には水の瓶を入れてある（中身がないと、置いたあとに瓶の形が消える）。チェスト・かまどは置かない。書見台は「ラッキーノットのきまり」（入口の間）・「両替の帳面」・「勘定の帳面」・「噂の帳面」。
- 育つ前・育った後（都市のルール⑩）：共同事業②のあとに `casino_highlow.nbt` を重ねると、南の側廊の2つのカードの卓の布（白い絨毯）が緑の布に変わり、鎖の仕切りが外れ、卓にカードとチップ（額縁）が置かれ、札が「ハイ＆ロー」に変わる。共同事業⑥のあとに `casino_fishrace.nbt` を重ねると、2階の宴の間の真ん中に、魚を走らせる水の走路（4本、長さ9。出発の印は赤・黄・緑・水色のろうそく、ゴールは金の壁）ができる。

### 塔の入口の違い

塔の入口は、古代の中継都市の「塔の門」です（Phase 0-A：古代の転移門。塔の基部の各階層へ通じる。門番バルド）。街の家々の材料
（灰色の石・木組み・漆喰）は使わず、すべて古代の層（白い石・石英・緑青の銅）で作りました（都市のルール③⑥）。

- 正面（参考画像 tower_02）：左右の塔＋真ん中の大きなアーチ＋落とし格子。塔の高さ（屋根の先 +36）は門の壁（胸壁の凸 +17）の約2倍、塔の窓（矢狭間と遮光ガラス）は縦一列。アーチは幅9・高さ11で、扉の大きさで全体の大きさを感じさせる。門の扉は付けず、落とし格子を上げてある（夜も開いている【補完】）。左右の塔は胴（9×9）の上に一回り細い上の段（7×7）を載せ、緑青の銅の四角すい（2：1）の屋根を石英の軒でかぶせる（参考画像 tower_01 の「基部・胴・冠」）。広間は緑青の銅の寄棟（1：1。幅31）、両翼は広間の壁に掛ける片流れ（1：1。教会の側廊と同じ）で、屋根はどれも都市のルール⑥の勾配。
- 紋章（⑦：看板はなし、門の上に模様入りの石で古代の紋章）：アーチの上の板（+16〜+28）に、9×9 の「結界の紋」（円＝模様入りの石英、四角＝石英の柱、十字＝緑青の銅、真ん中＝結晶（シーランタン）、地は磨いた安山岩）。街の形（円・四角・十字）と同じ紋です。旗は白の地に青緑のひし形・白い円・青緑の十字と縁（⑦の白と青緑）で、門の壁と広間の南の壁に2枚ずつ。
- 塔の基部（参考画像 tower_01）：広い丸い基部を3つの帯に分け、上の帯ほど2ずつ内へ下げる（段になった帯。段の上は石英の水切りの階段）。下の帯は石英のレンガ、中の帯は方解石、上の帯は石英のレンガで、門の棟（まだらの白い石）と分ける。付け柱（石英の柱）を8ごと（x ±4・±12・±20）に下から上まで通し、柱の間に縦一列の遮光ガラスの窓、+44 に結晶の灯り、+45〜+47 に冠（持ち送りと模様入りの帯）。
- 広間（④の天井16。教会の礼拝堂と並ぶ2つだけの大きな高さ）：古代の白い柱（3×3 の石英の柱、+11 に青緑の帯、模様入りの柱頭）を東西16・南北8の柱割りで4本（③の「8か12の大きな柱割り」）。奥の塔の壁に転移門：外の輪は緑青の銅、内の輪は模様入りの石英で、十字の向きに結晶の灯り。輪は塔の壁から1つ出て、3段上がった台の奥に立つ。輪の内は塔の壁の中へ4つのくぼみで、奥に封じられた塔の大扉（緑青の銅の2枚の扉、合わせ目は暗いプリズマリン、縁は模様入りの石英）。台の床に転移の円（模様入りの石英の輪と、青緑の真ん中）。
- 塔の灯り（広間の東の壁）：磨いた安山岩の板に、4段×5本のろうそく（下から第1章＝黄緑、第2章＝空色、第3章＝橙、第4章＝白。Phase 0-A の章の色から）。ひらいた階だけ灯る（いまは1階だけ。灯すのは Mod の側。11月20日に決定）。左に章の札、上に「塔の灯り」、右下に「次にひらく階（管理者の予告）」の札。前に門番バルドの書見台。
- 灯り（⑦）：広場は古代の結晶灯（塔の道の帯の両脇は、入口の対のあと12ごとに互い違い。広場の両脇にも）と、石柱の頂の結晶の灯り。門の前は鉄の腕木のランタン、歩廊は胸壁の上のランタン、広間は天井から鎖で吊るランタン（大きな吊り灯は置かない）、らせん階段は芯のくぼみのランタン。転移門の輪・紋章の真ん中・基部の冠は、夜も光る結晶（シーランタン）。
- 広場（⑤）：白い石畳。真ん中の帯（x −5〜5）は塔の道の続き（縁は石英のレンガ、8ごとに模様入りの石英）。段は全幅の階段の列で、どこでも跳ばずに上がれる。両脇の石柱は細い尖塔（模様入りの台、石英の柱、4方へ開く柱頭、結晶の灯り、青緑の笠）で、塔へ向かって 5・7・9・11 と高くなる（参考画像 tower_01 の「中央へ向かって高くなる細い尖塔の列」）。
- 入れ物：樽は鍵つき（`Lock`「amemaru:tower_lock」）。チェスト・かまど・醸造台は置かない。書見台は「入塔の記録」（受付）・「塔の門の心得」（バルドの書見台）・「踏破の記録」（踏破の記録の間）。
- 育つ前・育った後（⑩）：1週目の共同の目標（古代石5,000個。Phase 0-A）のあとに `tower_plaza_monument.nbt` を重ねると、広場の西の「記念碑の場所」（石英のレンガの縁の四角）に、古代石の碑（苔むした石と模様入りの石のレンガ、上に紫水晶の結晶）と碑文の看板が立つ。

様式（色・屋根の急さ・飾りの多さ）や、ギルドの形（塔の高さ・破風の大きさ・張り出しの場所など）、武器工房の形（アーチの大きさ・煙突の高さ・作業庭など）、装飾工房の形（出窓・日よけ・吊り灯り・留め具の枠など）、商店街の形（店の型の並び・店の品・渡り廊下・露店など）、個人倉庫の形（荷揚げの梁・落とし格子・小部屋の数・保管庫の棚・地下2層など）、フリーマーケットの形（露店の型と色・区画の並び・泉・灯りの綱・休み場など）、結びの教会の形（鐘楼の高さ・窓の色・入口の切妻・療養所の部屋・記憶の庭など）、釣り堀の形（池の形・桟橋の長さ・店の大きさ・水門・湖など）、カジノの形（正面の破風と小塔・屋根の金の縁・ルーレットの卓・吊り灯・VIPルーム・地下の秘密の階・寄付で足す遊びの場所など）、塔の入口の形（左右の塔と門のアーチ・紋章・広間の柱・転移門の輪・塔の灯り・塔の基部の帯・広場の石柱など）で
変えたいところがあれば、教えてください。
