# マップの建物の様式と見本：コネリアの冒険者ギルド本館

「建築はもっと凝ったものにしたい」というご指示と見本の画像（11月17日）を受けて、建物の作り方（様式）を決め、
見本として**コネリアの冒険者ギルド本館**を作りました。画像を写したのではなく、同じ様式で、ギルドのために新しく組み立てた建物です。
これから作るコネリアの建物（商店街・教会・工房・倉庫など）も、この様式に合わせます。

前に作ったコネリア中央広場の見本（簡単な家）は、この様式で作り直します（Phase 5）。

## 1. 作ったもの

| 項目 | 内容 |
| --- | --- |
| 構造物ファイル | `src/main/resources/data/amemaru/structures/map/conelia/guild_hall.nbt`（48×48×40ブロック。置いた範囲の中は片づく） |
| 置き方（今） | `/place template amemaru:map/conelia/guild_hall <x> <y> <z>`（正面は南。y は地面の高さ。建物は x と z の大きい方へ広がる） |
| 置き方（Phase 5から） | `/amemaru admin map build conelia`（コネリアの区画の一つとして、決まった位置に置く） |
| 作り直し | `python3 tools/mapgen/build_guild.py`（設計データのスクリプト。`--render <フォルダ>` で見本の絵も描く。`tools/mapgen/README.md`） |
| 高さ | 1階 5段・2階 5段・軒まで13段・棟30段・尖塔の先47段 |

建物の部分：

- **西棟**：正面に大きな切妻（十字の桟の大窓・雨戸のついた窓・梁の上の小窓）。角に、持ち送りで張り出した**小塔**（尖った屋根と灯り）。西の斜面に、窓の屋根（ドーマー）2つ。
- **塔**（正面の真ん中）：1階は入口の石のアーチ（奥に扉、両脇に灯り）。2階に大窓と花箱。屋根の上に丸い窓と小窓、**鐘の部屋**（鐘を吊ってある）、4隅の小さな尖りと灯り、細い**尖塔**。
- **本館**：正面の右に2つ目の切妻（十字の窓）と、**しま模様の日よけ**（1階の窓口の上）。東に切妻と**外階段**（2階の戸口へ）。裏の斜面にドーマー2つ、煙突2本（焚き火で煙が出る）。
- **前庭**：石畳の道、街灯2本、花壇。
- 飾りの小塔（先に灯り）は15か所、吊るした灯りは19か所。

## 2. 様式の決まり

| 部分 | 決まり | おもなブロック |
| --- | --- | --- |
| 1階 | 石の壁に、上の角を丸めたアーチの窓（ガラスは2つ奥）。壁の1つ外に木の柱。アーチに灯りを吊る | 石レンガ（ひび・苔・安山岩を少し混ぜる）、皮をはいだトウヒの丸太、磨いた安山岩 |
| 1階と2階の間 | 太い梁と、その外に持ち送り（逆さの階段）を並べ、2階を1つ外へ張り出す | 皮をはいだトウヒの丸太、トウヒの階段 |
| 2階 | 木組み（柱は4ブロックごと）と白い漆喰。柱の間は、上の角を丸めた白い面の真ん中に細い窓、下に花箱。ところどころの柱に腕木と灯り | 方解石（漆喰）、ツツジの葉（花の咲いたもの・咲いていないもの） |
| 切妻 | 2階よりさらに1つ外へ張り出し、下に持ち送り。十字の桟の大窓・雨戸のついた窓・横の梁 | ダークオークの丸太と板（桟） |
| 屋根 | 急な屋根（横に1進むと2上がる）。2段ごとに外へ出た筋で、重ねた瓦に見せる。切妻の縁は、屋根より1段高い濃い木の縁と、その外の破風板。軒の先は外へ反らせる | レンガ・レンガの階段、ダークオーク |
| 屋根の交わり | 2つの屋根が交わる所は、低い方を高い方の下に隠して谷にする（設計データの道具が決める） | |
| 飾りの小塔 | 切妻の頂・ドーマー・塔の角・尖塔の先に、レンガの塀を重ねた細い尖り。途中に灰色の輪、上に灯り、さらに上に細い棒 | レンガ・安山岩・磨いた深層岩の塀、ランタン、エンドロッド |
| 色 | 白（漆喰）・明るい茶（柱）・濃い茶（縁）・赤（屋根）・灰（1階の石）の5色に、葉の緑と灯りの橙を足す | |

## 4. ゲーム内での確認

### 自動で確かめていること（GitHub Actions）

クライアントの起動の後、今までの写真に続けて、空の高い所（y=200）に草の広場を敷いてギルドを置き、観戦モードで次の6枚を撮ります。

| 写真 | 向き |
| --- | --- |
| `map_guild_front` | 正面（南）から |
| `map_guild_left` | 左前（南西）から。西棟の小塔と切妻 |
| `map_guild_right` | 右前（南東）から。塔・2つ目の切妻・日よけ・外階段 |
| `map_guild_close` | 入口の近く。1階のアーチと灯り、2階の花箱 |
| `map_guild_aerial` | 上から。屋根の交わりとドーマー |
| `map_guild_back` | 裏（北東）から |

### 手で確かめること

1. クリエイティブのワールドで、平らな所に立つ（建物は、立った所から東へ48、南へ40ブロック広がります）。
2. `/place template amemaru:map/conelia/guild_hall ~ ~-1 ~` で置く（地面の草の層が、足もとの地面に重なります）。
3. 南に回って、屋根・塔・飾りの小塔・日よけ・花箱を見る。`/time set night` にすると、灯りが目立ちます。
4. 中に入れることを確かめる：塔の入口・西の戸口・裏口・本館の左の戸口から1階へ、東の外階段から2階へ。

## 5. 既知の問題と、これからやること

| 内容 | 予定 |
| --- | --- |
| 中は床と壁だけ（受付・依頼の掲示板・ギルドマスターの部屋などの家具はない） | Phase 5でコネリアを作るときに、NPCの位置と合わせて入れる |
| ギルドの地下の個人倉庫（Phase 0-A の設定）がまだない | 地下の区画として、Phase 5でこの建物の下に置く |
| 1階と2階をつなぐ中の階段、塔の鐘の部屋へ上がる階段がない（外階段で2階へは上がれる） | 内装と一緒に入れる |
| 置く所の地面の高さと、草の層（48×40）を合わせる必要がある | Phase 5の `map build` が、階層のJSONの位置に合わせて置く |

## 6. 世界観の追加【補完】

- 本館は、もとは結晶騎士団の詰所です。15年前に騎士団が冒険者ギルドに改組されたとき、建物はそのまま引き継がれました【補完】。
- 西棟の角の小塔は、騎士団の見張り台でした【補完】。
- 塔の鐘は、騎士団の時代には遠征の出発と帰還を知らせていました。第七次塔遠征の後は、塔の新しい階層が開いた日にだけ鳴らします【補完】。（階層が開いたときに街じゅうで鐘の音を鳴らす演出は【提案】です。）
- しま模様の日よけの窓口は、塔で拾った素材の買い取りと、依頼の品の受け渡しの窓口です。受付のリリアは、塔の入口の奥の広間にいます【補完】。
- 東の外階段は、2階のギルドマスターの部屋へ直接上がる階段です。夜遅く帰った遠征隊が、ガルドに報告するために使います【補完】。

## 7. 差し替えてほしい素材

ありません（すべてバニラのブロックです）。材料を変えたいときは、`tools/mapgen/build_guild.py` の始めの `Palette(...)`（漆喰・柱・縁・屋根）と、
`mapgen/facade.py` の文字の意味を変えて、スクリプトを動かし直せば、構造物ファイルが作り直されます。

## 8. 変えたいところがあれば

様式（色・屋根の急さ・飾りの多さ）や、ギルドの形（塔の高さ・小塔の位置・日よけの場所など）で変えたいところがあれば、教えてください。
決めた様式で、Phase 5のコネリアの区画（中央広場・商店街・教会・工房・倉庫・塔の門など）を作ります。
