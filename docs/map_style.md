# マップの建物の様式と見本：コネリアの冒険者ギルド・武器工房・防具工房・装飾工房・商店街

コネリアの**冒険者ギルド**を、建築の文書の「PHASE 1：冒険者ギルド」の設計（役割・部屋・寸法・平面図・動線・外観・内装・まわり・
建てられるかの確かめ・10点の評価）どおりに組み立て、構造物ファイルにしました。
**武器工房**・**防具工房**・**装飾工房**・**商店街**も、同じ手順で「PHASE 2：武器工房」「PHASE 3：防具工房」「PHASE 4：装飾工房」「PHASE 5：商店街」の設計どおりに組み立てました（このページの後ろの節）。
11月17日に作った見本（48×48×40、正面は南）は、この設計に置き換えました。様式（材料・層・屋根・飾り）は見本のものを引き継ぎ、
建築の文書の「都市のルール」に合わせて直しています。これから作るコネリアの建物も、この様式に合わせます。

設計の詳しいこと（平面図・断面・部屋ごとの家具の理由・確かめの結果）は、建築の文書の「PHASE 1：冒険者ギルド」「PHASE 2：武器工房」「PHASE 3：防具工房」「PHASE 4：装飾工房」「PHASE 5：商店街」のタブにあります。

### 工房の地区の違い（武器工房）

ギルドの様式からの違いは次のとおりです。

- 足もとは、古代の白い石ではなく、道から1段上げた磨いた安山岩の帯（+1）。古代の石は、奥の古代炉のまわりだけ。
- 屋根は黒い瓦（深層岩タイル）。都市の決まりの、屋根の2種類目。妻の縁と破風板はギルドと同じダークオーク。
- 火を扱う所（炉の間）は軒まで石の塊にし、住まいとの間に土台から棟までの石の防火の壁を立てる。
- 煙突は深層岩レンガ。炉の煙は干し草の上の焚き火で高く、台所の煙は干し草なしで低く。
- 2階の窓は雨戸をつけず、花箱だけ（柱の間の漆喰を見せる）。
- 旗は赤に黒の斜めの十字と白い縁（交わる剣）【提案】。看板は吊り看板と、その下の額縁の剣。
- 額縁と防具立て（もの）で、武器を掛ける・立てかける・梁から吊るす。

### 工房の地区の違い（防具工房）

武器工房と同じ工房の地区の決まり（安山岩の帯・黒い瓦・雨戸なしの2階の窓）に、次を足しています。

- 三角の壁を通りに向け（妻入り）、2階を正面へ1つ張り出して持ち送りで受ける。向かいの武器工房（平入り）と顔を分ける。
- 環状路との角の建物なので、西の屋根に小さな妻（幅5、2：1）を出し、通りと環状路の両方に顔を向ける（都市のルール⑥）。
- 1階の窓は飾り窓2つだけ。鎧を着せた防具立てを窓のすぐ内側に置き、入口の両脇の端の帯にも門番の甲冑を立てる。
- 旗は灰に赤い十字。正面の壁に模様入りの盾（額縁）を4つ。吊り看板の下にも店の盾。
- 小さな炉の煙突は屋根の東の面から出し、干し草を敷かない（低い煙。武器工房の高い煙と見分ける）。
- 西の壁の外に、低い石の塀で囲んだ半屋外の作業場。壁ぎわの半分に片流れの屋根（黒い瓦、濃い木の柱と梁）。
- 店の型紙の壁は、章が進むと額縁に型紙が1枚ずつ増える（`build_armor.py` の `PATTERNS` と `patterns_world`）。

### 装飾工房の違い

工房通りにあっても火を使わない店なので、屋根と足もとはギルドと同じ街の基本の形にして、次を足しています。

- 屋根は赤い瓦（1：1）。工房通りに平入りにし、入口の上に小さな妻（幅4、2：1）を立てる。角の建物なので、2階を西（中央広場の側）へ張り出して妻を広場に向ける。
- 足もとは道から1段で、腰石（いちばん下の段）は古代の白い石（磨いた閃緑岩）。入口の両脇の付け柱と、アーチの窓の角・窓台・要石は石英（古代の細工）。角は磨いた安山岩と石レンガを交互に。
- 正面の西に出窓（ショーウィンドウ）。腰は石英レンガ、ガラスは3面、小屋根だけ緑青の銅（都市のルール⑥の例外）。中に晶洞の切り口の飾り。
- 入口の上に、旗と同じ水色と白の市松の日よけ（濃い木の跳ね上げ戸の台に敷物）。旗は水色に白い菱形と白い縁、吊り看板の下にアメジストの欠片。
- 中は、入口から水色の床の軸の先に、原石の上のガラスのカウンターと、奥の宝石の額縁の棚。カウンターの真上に吊り灯り（都市のルール⑦で装飾工房に許した大きな吊り灯り）。
- 煙突は寝室の暖炉の1本だけ（石レンガ、2×1）。火を使わないので、地面にも花を植える。
- 奥の額縁の棚の真ん中の上は「留め具の枠」。第3章で額縁に留め具が入る（`build_accessory.py` の `CLASP_SHOWN` と `clasp_world`）。

### 商店街の違い

ギルドと同じ街の基本の様式（灰色の石の1階、木組みと漆喰の2階、赤い瓦）で、店を4つの型の組み替えにしています。

- 型：A 平入り2階（張り出し）、B 妻入り2階、C 妻入り3階（張り出し）、D 角の平入り2階（妻を横の道に向け、横にも入口と吊り看板）。同じ向きが4つ続かないように並べ、3階建ては2軒だけ。
- どの店も、吊り看板の下に品の額縁、窓台を広げた店先のカウンターに品（額縁・ブロック）、入口に1段の踏み段。2階の窓に花箱、店の色の旗（白い縁）。
- 中は、前が売り場（左右の壁ぎわに2段の樽の戸棚。樽のふたと上の壁に品の額縁）、高さ1.5のカウンター（端は柵の門）、奥が仕事場（店ごとの道具）と、カウンターの後ろから上る階段。2階は住まい（3階建ては2階が仕事部屋、3階が寝室）。
- 戸棚は2段にして跳び乗れないようにし、カウンターへの踏み台にしない。カウンターの門の前（b=3）と入口の前はあける。
- マルタ・ポムの雑貨屋（中央広場の東の角）は、右の戸棚を「素材の買い取り」の台にし、2階にリリアも食べに来る食卓を置く【補完】。
- ペトラ・ポムの料理屋（中央広場の西の角）は2段の形：開く前は窓と表の入口・横の入口に板（裏口だけ使える）、中は改装の荷。寄付で開いたあとは、食堂（卓2つ）・カウンター・台所（燻製器・焚き火の鍋・水の大釜）と、中央広場の側の席（日よけ）。
- 通りの灯りは古代の結晶灯（`fixtures.crystal_lamp`。端の帯の内側の列に、左右互い違い）。裏通りの角と広場の側の帯の角は、壁のランタンと再建のランタン灯。
- フリーマーケット（PHASE 7）への通り抜け（z 75〜78）の上に、2階どうしを結ぶ渡り廊下（下の空き5、黄と橙のしまの旗、門の吊り看板）。
- 南門の前の小広場に露店2つと花壇、中央広場の側の帯に腰かけと花壇、環状路との交差点に案内板。
- 環状路との交差点は角切り（都市のルール⑤）：北の角の店（薬屋・布と仕立て）は1階の通りの側の角を2ブロック斜めに切り、上の2階を持ち送りで張り出して、角の下に灯りを吊るす。布と仕立ては左右を入れ替え、入口を交差点から遠い側に寄せる。南の角は、店の前の帯（2列）が角切りの広さを持つ。

### 飾りの守りの自動テスト（GameTest）

## 7. 差し替えてほしい素材

ありません（すべてバニラのブロックです）。材料を変えたいときは、`tools/mapgen/build_guild.py` の始めの `Palette(...)`（漆喰・柱・縁・屋根）と、
材料の関数（`gray_stone`・`white_stone`・`paving`）を変えて、スクリプトを動かし直せば、構造物ファイルが作り直されます。
武器工房は `tools/mapgen/build_weapon.py` の `Palette(...)` と、材料の関数（`gray_stone`・`ancient_stone`・`apron_paving`・`alley`・`yard_ground`・`forge_floor`）です。
防具工房は `tools/mapgen/build_armor.py` の `Palette(...)`、材料の関数（`gray_stone`・`apron_paving`・`alley`・`yard_ground`）と、店の色（`SHOP_BANNER`・`SHOP_SHIELD`）です。
装飾工房は `tools/mapgen/build_accessory.py` の `Palette(...)`、材料の関数（`gray_stone`・`ancient_paving`・`apron_paving`・`alley`・`yard_ground`）と、店の色（`SHOP_BANNER`）、
飾りの品（`GEM_WALL`・`VITRINE`・`CLASP_ITEM`）です。
商店街は `tools/mapgen/build_market.py` の `Palette(...)`、材料の関数（`gray_stone`・`ancient_paving`・`band_paving`・`alley_paving`）と、
店ごとの看板・色・品・床・寝台の色（`TRADES`）です。

## 8. 変えたいところがあれば

様式（色・屋根の急さ・飾りの多さ）や、ギルドの形（塔の高さ・破風の大きさ・張り出しの場所など）、武器工房の形（アーチの大きさ・煙突の高さ・作業庭など）、装飾工房の形（出窓・日よけ・吊り灯り・留め具の枠など）、商店街の形（店の型の並び・店の品・渡り廊下・露店など）で
変えたいところがあれば、教えてください。
決めた様式で、残りのコネリアの区画（個人倉庫・フリーマーケット・教会・カジノ・塔の門など）を作ります。
