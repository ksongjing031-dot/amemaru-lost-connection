# Phase 7：街を育てる（その1：コネクション量と大結晶の輝き）

Phase 7 は Phase 0-B 13章の「**釣り、カジノ（右クリックでGUIを開いて使う）、寄付と共同事業、コネクション量と輝き段階**」（動作確認の目安「CPがたまり、輝き段階と施設が変わる」）です。Phase 6 と同じく4つに分けて作ります。

| 分け方 | 中身 |
| --- | --- |
| **その1（この文書）** | コネクション量（CP）と大結晶の輝き段階。交流の常設の仕組み（結び札・はじめましてボーナス・今日の相棒・先導者） |
| その2 | 釣り（ミニゲーム・魚図鑑・釣り大会） |
| その3 | カジノ（右クリックでGUI・カジノナイト） |
| その4 | 寄付と共同事業（寄付の目標と輝き段階の両方で完成し、施設が変わる） |

その1で作ったものの中心は次のとおりです。

- **コネクション量（CP）**（Phase 0-A 13章）：みんなで何かをすると増える、サーバー全体の数。**7分野**（戦闘・生産・商売・交流・娯楽・街・物語）に分けて数え、**1人1日の上限は分野ごとに150、合計600**。日は**毎日4時**に切り替わります（進行日ではなく、決まった時刻。Phase 0-B 4.1）。行動ごとの量と「1日○回」「同じ相手は1日○回」は13章の表のとおりで、データパック（`connection_actions/`）で変えられます。いない人に届いたCP（フリマで売れた・手渡しした装備を相手が着た・結び札をもらった）は、次に入ったときに数えます。
- **大結晶の輝き段階**（13章）：サーバー全体の累計CPで、段階1〜10。しきい値は25人基準で、**直近3日の平均アクティブ人数 ÷ 25 倍**（0.4〜2.0倍）にします。段階10の後は、5,000CPごとに**加護の星**（最大5つ）。段階が上がると、全員の画面の真ん中に大結晶（リンク・コア）の一言が出て（段階が上がるほど、はっきりする。6章）、チャットに新しい効果が出ます。大結晶のまわりの光の粒は段階と星に合わせて増え、結界の柱の頭も光ります。
- **段階の効果**（全員・累積）：段階2「結界が塔前広場まで広がる」（今は広場のふちに光の幕。結界の範囲を使う襲撃は Phase 8）・段階3「ロスト耐性+3%」・段階4「経験値+3%」・段階5「襲撃時の結界の耐久+20%」（襲撃は Phase 8）・段階6「ダウン（蘇生待ち）の時間+5秒」・段階7「ロスト耐性+6%」・段階8「経験値+6%」・段階9「襲撃時の結界の耐久+40%」・段階10「結晶の加護・満」（最終決戦は Phase 9）。
- **大結晶の輝きの画面**：中央広場の大結晶の台の西にある**記憶の石**を右クリックすると開きます。左はサーバー全体（段階と星・次の段階までの帯・人数補正・いま効いていること・次の段階で効くこと）、右は「**今日のあなた**」（7分野の今日のCPと上限・合計・これまでの貢献・結び札の残り・今日の相棒・はじめましてボーナス）と「**みんなの貢献**」（分野ごとの合計と上位3人）。下の「記憶の再生」から、見逃したストーリーイベントの一覧へ（Phase 5 の記憶の石の役目）。
- **結び札（ありがとう）**（15章）：**縁帳**（ギルドの窓口の「縁」のタブ →「縁帳を開く」）の人ごとの「結び札」のボタンで贈ります。**1日3枚、同じ人へは1日1枚**。贈った人ともらった人に交流のCP（3と3）。もらった数は称号の数になります。
- **はじめましてボーナス**（15章）：その日に**初めてパーティを組んだ人**（縁帳に「組んだ」がなかった人）が今のパーティにいると、**経験値とドロップの判定が、その人数×10%上がります（最大+30%、1日5人まで）**。初めて組んだときに、お互いに交流のCP（10。1日5人まで）。
- **先導者**（14章・15章）：**途中参加者**（2日目から初めて来た人で、来てから3日のうち）や、**サーバーの中央値より10レベル以上低い人**と組むと、先導する側に交流のCP（15。1日3回）と、称号「先導者」の数。
- **今日の相棒**（15章）：毎日ログインしたときに、**まだ組んだことのない人を1人「今日の相棒」**として示します（いる人から先に。相手の相棒もまだなら、お互いを相棒にする）。**相棒と同じパーティで敵を10体倒す**と、ふたりにお礼（150ノットと交流のCP 10）。

## 2. このPhaseで決めた細かいこと（【補完】）

設計書に書いていない所は、次のように決めました。変えたいときは教えてください。行動の量と回数は `data/amemaru/amemaru/connection_actions/`、段階のしきい値・効果・大結晶の一言は `connection_rules/default.json`、そのほかの数は `amemaru-server.toml` の `[connection]` で変えられます。

### CPの数え方

| 行動（13章の表） | どこで数えるか【補完】 |
| --- | --- |
| パーティで敵を倒す（5体ごとに1） | 敵が倒れて経験値を受け取った人のうち、**2人以上のパーティ**にいる人（倒した人と、32ブロック以内の仲間）。5体に届かない分は次の日に持ちこす |
| 階層ボスを倒す（パーティ。20、同じボスは1日1回） | ボスを倒した人のうち、2人以上で倒したか、パーティにいる人 |
| 章ボスを倒す（50、同じボスは1日1回） | **5・10・15・20階**（各章の最後の階）のボスを倒した人（1人でも） |
| 連携技の成立（1、1日30回） | 連携技が成り立ったとき、加わった人それぞれ |
| 他人のための制作（依頼の完了・手渡し。15、同じ相手は1日3回） | **手渡し**：作り手とちがう人が、その装備を**初めて身に着けた**とき、作り手に（装備に印を付けて1度だけ） |
| 他人の装備の修理（5、同じ相手は1日3回） | 工房で修理した装備の**持ち主**（最後にその装備を使って耐久を減らした人）が、修理した人とちがうとき |
| 他人のアクセサリーの厳選依頼を完了（10、同じ相手は1日3回） | 依頼台の依頼が終わったとき、1回でも厳選した装飾師に |

| 途中参加者とパーティ（先導者。15、1日3回） | 先導する側に。**同じ相手は1日1回**。CPが上限で0でも、称号「先導者」の数は数える |
| 施設への寄付（100ノットごとに1、1日50） | 露店の区画を増やす寄付。共同事業の寄付は**その4** |

| ストーリークエスト（30） | 物語のクエストを終えたとき（物語のクエストは Phase 8 で増える） |

- 1人1日の上限（分野・合計）に届いたら、その日に一度だけチャットで知らせます。増えたときは、画面の下（アクションバー）に「コネクション +○（分野：行動）」。
- 自分を相手にした行動は数えません。

### 輝き段階と効果

- **一度灯った段階は消えません**（人数補正の倍率があとで上がって、しきい値が上がっても）。加護の星のしきい値（5,000ごと）にも、人数補正をかけます。
- 効果の「累積」は、**同じ種類は届いたいちばん上の段階の値**にします（ロスト耐性は段階3で+3%、段階7で+6%。合わせて+9%ではない）。
- 段階2の「結界が塔前広場まで広がる」：今の街は、敵がわかない決まり（湧きの決まり）なので、結界の範囲で変わることはまだありません。段階2から、塔前広場のふちに**立ちのぼる光の幕**を見せます。結界の範囲は、街の襲撃（Phase 8）で使います。
- 段階5・9（襲撃の結界の耐久）と段階10（最終決戦の加護）は、値だけ先に用意しました（`ConnectionService.barrierBonusPercent`・`finalBlessing`）。襲撃は Phase 8、最終決戦は Phase 9 で使います。
- 段階が上がると、物語の条件に使える印 `amemaru:connection/stage_<段階>` が付きます（ストーリーイベントの条件にできる）。
- 段階が上がったときの大結晶の一言（10個と、星が灯ったときの一言）は【補完】です（`connection_rules/default.json` の `voices`）。段階が上がるほど、言葉がはっきりします。
- 大結晶の光の粒は、大結晶から160ブロックまでの人に送ります（ふつうの光の粒は32ブロックまでしか見えないため）。

### 途中参加者と先導者

- **途中参加者**：オープニングを見る前に初めて入った日が2日目から後の人で、来てから3日のうち（14章の「途中参加・見逃し対策」）。この版より前から遊んでいる人は、1日目に来たことにします。
- **先導の相手**：途中参加者か、レベルが「サーバーの中央値 − 10」以下の人（15章。差の10は config `leadLevelGap`）。
- 14章の「双方に報酬とコネクション」：先導する側には先導者のCP、組まれた側には「初めての人とパーティ」のCPと、はじめましてボーナスが入ります。

### はじめましてボーナス

- 「初めて組む相手」は、**その日に初めてパーティを組んだ人**（縁帳に「組んだ」がなかった人）。次の日からは数えません。
- 1人ごとに **+10%**、**+30%まで**、1日に数えるのは **5人まで**（config `firstMeetStep`・`firstMeetMax`・`firstMeetDaily`）。
- 上がるのは、**敵を倒したときの経験値**と、**ふつうのドロップの回数・レアドロップの確率**です（クエストの報酬の経験値には付けません）。レアの告知は、これまでどおり定義の確率で決めます。
- 初めて組んだときに、チャットに「はじめまして！」と今のボーナスが出ます。大結晶の輝きの画面の「今日のあなた」にも出ます。

### 今日の相棒

- 選ぶのは、まだ組んだことのない人（縁帳に「組んだ」がない人）。順番は「いる人で、相棒がまだの人」→「いる人」→「最近（直近3日）来た人で、相棒がまだの人」→「最近来た人」。相手の相棒もまだなら、**お互いを相棒**にします。
- 入ったとき（その日の最初）と、つながったまま4時をまたいだときに決めます。だれもいなければ「まだいません」と出し、だれかが入ってきたら、もう一度探します。
- 依頼は「**相棒と同じパーティで、敵を10体倒す**」（ふたりとも経験値を受け取った敵を数える。1体につき1組1回）。終えると、ふたりに **150ノット** と交流のCP（10）。数と額は config（`partnerGoal`・`partnerKnots`）。
- 相棒が別の人を相棒にしている（一方通行の）ときも、一緒に依頼を終えれば、ふたりにお礼が入ります。

### そのほか

- **手渡しの印**：装備（`AmemaruGear` の作り手がある品）に `amemaru_handed` を付けて、2回目は数えません。**持ち主の印** `amemaru_owner` は、攻撃・スキル・敵の攻撃でその装備の耐久を減らした人です。
- **記憶の石**：Phase 5 では右クリックで「記憶の再生」の一覧が開きました。今は大結晶の輝きの画面が開き、下のボタンから「記憶の再生」へ行けます。

## 3. 管理者のコマンド（`/amemaru admin connection`）

| コマンド | すること |
| --- | --- |
| `connection` | サーバー全体（段階・星・累計・次の段階まで・人数補正・効いている効果・分野別の累計） |
| `connection add <CP>`・`set <CP>` | サーバー全体の累計に足す・決める（段階は下げない） |
| `connection stage <1〜10>` | 段階を決める（上げると順に知らせる。下げると累計もしきい値にそろえ、上の段階の印と星を消す） |
| `connection reset` | 段階・星・累計・貢献・今日の相棒を初めに戻す |
| `connection player <人>` | その人の今日の分野別CPと上限・これまでの合計・来た日（途中参加者か） |

## 4. 確かめ方

### 1人で

1. 中央広場の大結晶の台の西の**記憶の石**を右クリックすると、大結晶の輝きの画面が開くこと。「今日のあなた」「みんなの貢献」のタブが切りかわり、「記憶の再生」から見逃したイベントの一覧へ行けること。
2. `/amemaru admin connection award @s amemaru:story_quest 2` などで、画面の下に「コネクション +60（物語：ストーリークエスト）」が出て、画面の「今日のあなた」の物語が 60/150 になること。同じ分野で150を超えると止まり、チャットに一度だけ知らせが出ること。
3. `/amemaru admin connection stage 3` で、画面の真ん中に「輝き段階 3」と大結晶の一言が出て、チャットに「結界が塔前広場まで広がる」「ロスト耐性 +3%」が出ること。ステータス（K）のロスト耐性が3%上がること。夜に大結晶のまわりの光の粒が増え、塔前広場のふちに光の幕が立つこと。
4. 古代記録を見つける・デイリーを報告する・露店の区画に寄付すると、CPが増えること。
5. `/amemaru admin connection stage 6` のあと、ダウンの時間が5秒のびること。`stage 4` のあと、敵を倒したときの経験値が3%増えること。

### 2人以上で

1. 初めての人とパーティを組むと、お互いに「はじめまして！」と出て、交流のCPが10ずつ増えること。そのパーティで敵を倒すと、経験値が10%（初めての人が2人なら20%）増えること。前の日に組んだ人とは、次の日には増えないこと。
2. 縁帳の「結び札」のボタンで贈ると、贈った人ともらった人に交流のCPが3ずつ入り、同じ人へは1日1枚、1日3枚までになること。いない人に贈ると、次に入ったときに数えられること。
3. 入ったときに「今日の相棒は「○○」さん」と出ること（まだ組んだことのない人がいるとき）。相棒と同じパーティで敵を10体倒すと、ふたりに150ノットとCPが入ること。
4. `/amemaru admin level set <人> 1` などで、中央値より10レベル以上低い人と組むと、先導する側に交流のCP（15）が入ること。
5. 作った装備をほかの人に渡して、その人が身に着けると、作り手に生産のCP（15）が入ること。その人が使って耐久を減らした装備を、作り手（ほかの人）が工房で修理すると、修理した人に生産のCP（5）が入ること。
6. フリマで売れると売り手と買い手に、蘇生すると起こした人に、CPが入ること。
