## 3. できること

### HPとMP（Phase 0-A 19章の方式B）

- 独自のHPとMPで計算し、バニラのハートは隠して、ホットバーの上にHPとMPのバーを出します。
- 落下・溺れ・溶岩などでバニラの体力が減ると、減った割合（最大の体力に対する割合）を独自のHPから引きます。回復薬で増えたときも同じ割合で増えます。
- 自然回復は独自に行います（下の数値）。満腹度は減りません。
- HPが0になると、Phase 1ではバニラの死亡になります（Phase 4でダウン→蘇生→教会に置き換え）。

### レベルとステータス

- 次のレベルまでの経験値は「120 × 1.09 の（今のレベル）乗」です（Lv1→2は131、Lv10→11は284、Lv49→50は8,186。Lv50までの合計は97,687）。
- レベルが上がるごとにステータスポイント3、スキルポイント1。5の倍数のレベルではスキルポイントがさらに1。
- ステータス＝基礎＋レベルの伸び＋振り分け（＋Phase 2以降の装備と効果）。
- レベルが上がると、HPとMPが全快し、チャットに知らせが出ます。

### HUD（画面の下）

参考画像の並び（左にHP、右にMP、下に経験値、真ん中にレベル）をもとに、このModの「結晶と糸」をモチーフにした絵で作りました。

```
                 ▲ 結晶の冠
  ◀[  560/560  ]⬡[  190/190  ]▶     左：緑のHP　右：青のMP　中央の六角の結晶：レベル
  [============ 金の経験値 ============]
  [   藍色のホットバー（選んだスロットは水色のふち）   ]
```

- 枠は濃い藍色に水色の結晶のふち。HPとMPのバーは外側の端がとがり、中央の結晶に向かって光が流れるような色にしています。
- **減ったHPの残像**：HPが減ると、減った分が白く残ってから縮みます。回復したときは滑らかに増えます。
- **低HP**：HPが25%を切ると、HPのバーが赤くなり、枠が赤く点滅します。
- **ポイントの知らせ**：振り分けていないステータスポイントがあると、中央の結晶が水色に光り、レベルの数字が淡い金色になります。
- **レベルアップ**：結晶と経験値のバーが白く光ります。
- **ホットバー**も同じ絵にそろえました（アイテムの位置や、拾ったときの動きはバニラと同じ）。観戦モードのときだけバニラのものを使います。
- チャットは、HUDに重ならない高さに上げています。
- 隠すバニラの表示：ハート・防御・満腹度・経験値のバー・ホットバー（空気の泡や持ち物の名前は、HUDの上に出ます）。
- `config/amemaru-client.toml` で、大きさ（0.5〜2.0）と数字の表示を変えられます（大きさはバーと結晶にかかり、ホットバーはそのままです）。

### ステータス画面（Kキー）

- HUDと同じ「結晶と糸」のデザインです。左上の結晶にレベル、その横にレベル・スキルポイント・経験値のバー・次のレベルまでの経験値が出ます。
- 7つのステータス（色の印つき）と、補助の能力4つを見られます。
- 「＋」で1ポイント、Shiftを押しながらで10ポイント振り分けます。「閉じる」か、もう一度K、Escで閉じます。
- キーは「設定」→「操作設定」→「AMEMARU: LOST CONNECTION」で変えられます。

### 管理者のコマンド（OP・権限レベル2以上）

| コマンド | すること |
| --- | --- |
| `/amemaru admin level set <プレイヤー> <レベル>` | レベルを指定する（経験値は0に戻る） |
| `/amemaru admin level add <プレイヤー> <数>` | レベルを上げる |
| `/amemaru admin level exp <プレイヤー> <量>` | 経験値を与える（configの倍率はかけない） |
| `/amemaru admin level resetstats <プレイヤー>` | 振り分けを戻す |
| `/amemaru admin level info <プレイヤー>` | レベル・ポイント・HPとMP・ステータスを見る |
| `/amemaru admin debug vitals <プレイヤー> <HP%> <MP%>` | HPとMPを最大値の割合で入れる（確かめ用） |

実行した人と内容は、サーバーのログに残ります。

## 4. ゲーム内での動作確認の手順

### 自動で確かめていること（GitHub Actions）

プルリクエストにコードを上げるたびに、次の5つを自動で確かめています。どれかが失敗すると、Actionsの一覧に赤い×が付きます。

1. **ビルド**：Modの jar ができる。
2. **jarの中身**：mods.toml・言語ファイル・成長の定義・HUDの絵が入っている。
3. **自動テスト（GameTest）**：次の6つ。
   - 死んで復活しても、レベル・振り分けが残り、HPとMPが全快になる（11月16日に見つかった不具合のテスト）
   - 保存して読み直しても、レベル・経験値・振り分け・HPとMPが同じ
   - レベル10のステータスが、成長の定義どおり（HP 560・MP 190・攻撃 28 など）
   - HPに振り分けると、最大HPと今のHPが同じだけ増える
   - バニラの体力が減った・増えた割合が、HPに反映される
   - 経験値でレベルが上がり、最大レベルでは経験値がたまらない
4. **サーバーの起動**：開発用のサーバー（runServer）が最後まで起動し、成長の定義が問題なく読み込まれ、ゲームルールが合わせられる。このModのエラーがログに出ない。
5. **クライアントの起動と画面写真**：Forgeを入れたMinecraftに jar を入れて起動し、シングルプレイのワールドに入る。HUD（ふつう・HPが減った直後・HPが少ないとき）とステータス画面の写真を撮り、落ちずに終わる。写真は、Actionsの実行の「Artifacts」にある `screenshots-<番号>` から見られます。

### 手で確かめること

jarの受け取り方と入れ方は [README](../README.md) にあります。ワールドは、チートを許可して新しく作ってください。

1. **HUD**：ハートと満腹度の代わりに、緑のHPと青のMPのバー、真ん中の結晶にレベル「1」、その下に金の経験値のバー、藍色のホットバーが出る。HPは `200/200`、MPは `100/100`。
2. **レベル**：`/amemaru admin level set @s 10` を実行する。
   - チャットに「レベルが10に上がりました。ステータスポイント +27、スキルポイント +11（Kキーでステータス画面）」が出て、音が鳴る。
   - 結晶と経験値のバーが白く光り、HPは `560/560`、MPは `190/190` になる。振り分けていないポイントがあるので、結晶が水色に光り、レベルの数字が淡い金色になる。
3. **ステータス画面**：Kを押す。
   - 「レベル 10」「経験値 0 / 284」「スキルポイント 11」「残りポイント 27」と、攻撃 28・魔力 28・防御 14・素早さ 10・会心 5.0%・会心ダメージ 50.0% が出る。
   - HPの「＋」を押すと、HPが572になり（今のHPも同じだけ増える）、「（+1）」と「残りポイント 26」に変わる。HUDも572になる。
   - Shiftを押しながら攻撃の「＋」を押すと、攻撃が38、「（+10）」になる。
4. **経験値**：`/amemaru admin level exp @s 1000` を実行する。Lv10から3つ上がってLv13になり、ステータス画面は「経験値 68 / 368」。
5. **ダメージ**：サバイバルにして（`/gamemode survival`）、10ブロックほどの高さから落ちる。バニラの落下ダメージの割合だけ、HPのバーが減る（例：ハート3.5個分＝35%）。減った分が白く残ってから縮む。もう一度落ちてHPが25%を切ると、バーが赤くなり、枠が点滅する。
6. **自然回復**：攻撃を受けずに8秒たつと、HPが1秒に最大の2%ずつ戻る。`/amemaru admin debug vitals @s 50 10` で、HPが半分、MPが1割になり、MPは1秒に3%ずつ戻る。
7. **保存**：ワールドを出て入り直す。レベル・振り分け・HPとMPがそのまま残っている。
8. **死亡**：`/kill` で死んで復活すると、HPとMPは全快、レベルと振り分けはそのまま（11月16日に直した不具合。自動テストでも毎回確かめています）。
9. **確認と戻し**：`/amemaru admin level info @s` で値を確かめる。`/amemaru admin level resetstats @s` で振り分けが戻る。
10. **ゲームルール**：`/gamerule naturalRegeneration` が false、`/gamerule keepInventory` が true になっている。
11. **LAN（後回し）**：「LANに公開」して、もう一人が同じjarで入る。それぞれのHUDに自分の値が出て、片方のレベルを変えても、もう片方は変わらない。今は確かめられないため後回しにし、Phase 4（パーティ）の前にまとめて確かめます。

### データパックで数値を変える（任意）

`data/amemaru/amemaru/growth/default.json` と同じ場所に置いたデータパックで、成長の数値を上書きできます。ワールドの `datapacks` フォルダに入れて `/reload` すると、全員のステータスが計算し直されます。わざと数値をおかしくすると（例：`"max_level": 0`）、管理者のチャットに「データパックの読み込みで、1件の問題がありました」と、直す場所が出ます。

## 5-2. Phase 1の中で直した不具合

| 内容 | 原因と直し方 |
| --- | --- |
| `/kill` で死んで復活すると、レベルと振り分けが初期値に戻る | 死亡時、Forgeは古い体のデータの入り口を閉じてから、新しい体に写す処理（Clone）を呼ぶ。こちらでも入り口を閉じる登録をしていたため、写す処理で古いデータを読めなかった。登録をやめ、自動テスト（復活してもデータが残る）を足した |

Phase 0-Aに数値がなかったところを、次のとおり補いました。どれもデータパックかconfigで変えられ、Phase 9でまとめて調整します。
