# Phase 6：経済とまわりの仕組み（その2：職業とスキル）

Phase 6 の4つの分け方（`docs/phase6.md` の表）の2番目「**職業とスキル**」の分です。Phase 0-B 13章の「残りの職業」と、11月22日のご指示（新しい職業にもっと演出を・スキルとパッシブを増やして多様なビルドに・モンクのように複数のスキルを回すほどダメージが上がるコンボ）を合わせて作りました。

作ったものの中心は次のとおりです。

- **残りの4職業**（Phase 0-A 19章）：ヒーラー（回復・支援／鈴杖）・アーチャー（遠距離／弓）・ローグ（高火力・機動力／二刀の短剣）・モンク（格闘・連撃／籠手）。誓約の結晶で選べる戦闘職が6つになりました。上位職は鈴守・天弓・影結び・拳聖です。
- **スキルとパッシブを増やす**（11月22日に決定）：6職業すべて、流派ごとに**アクティブ8・パッシブ5**、奥義は2つの流派に1つずつ（上位職で、どちらか1つを選ぶ）。1職業で **アクティブ16・パッシブ10・奥義2 ＝ 28**。ナイトとウィザードには、アクティブ4つとパッシブ4つを足しました。スキルツリーは6段（Lv1・5・10・15・20・25）になり、奥義は上位職のLv30。
- **モンクの連撃**（11月22日のご指示）：スキルに【起】【継】【極】の型があり、【起】で連撃が始まり、違う【継】の技でつなぐほど連撃が重なり（最大5）、【極】の技で重ねた連撃を一気に使って大きなダメージを出します。同じ技を続けると切れ、3秒あくと消えます。
- **職業ごとの専用ゲージ**：アーチャーの「集中」（戦いの間に立ち止まるとたまり、矢を当ててもたまる）・ローグの「気配」（スキルを当てるたびに1つ、最大5）・モンクの「気」（続けて当てるほど多くたまり、当てないと減る）。ナイトの「誓気」はそのまま。
- **新しい状態**：毒（重なる・毎秒のダメージ・弾けさせる）・標（受けるダメージが上がる）・縫い止め（動けない）・戒め（攻撃が弱まる）・煙（攻撃が外れる）。味方への強化（加護の灯・守り・鋭い目・疾さ・結びの力・狙撃の構え・命の糸・身代わりの鈴・星の環・影分身・毒塗り・疾風の弓舞・影走り・天地流転・癒し続け・潜伏）。
- **武器**：鈴杖・弓・二刀の短剣・籠手の、見習い装備（ギルドが貸す）と古代石の装備（工房で作る）。**弓は左クリックで矢を射ます**（通常の攻撃の代わり）。防具は、ヒーラーは法衣、アーチャー・ローグ・モンクは新しい「古代石シリーズ（軽装）」。
- **演出**（11月22日のご指示「新しい職業にもっと演出を」）：4職業の全スキルの演出（光・鈴の音の輪・花びら・羽根・煙・毒の泡・斬撃の弧・打撃の光と気）、モーション75個、矢と針の見た目、状態の見た目。スキルのアイコン128個・職業の紋章・状態のアイコン。
- **画面**：スキルツリーは6段を上下に動かして見る（ホイールか▲▼）。詳細に【起】【継】【極】。HUD は気配を粒で、モンクは「連撃 3」と消えるまでの帯。職業選択は3ページ。戦闘の文字に「外れた」「連撃」「起き上がった！」「身代わりの鈴！」と毒のダメージ。

全スキルの一覧（段・効果・MP・クール・連携）は `docs/skills_table.md`（`tools/datagen/build_jobs.py` が書き出す）にあります。【新】の印が、11月22日に足したスキルです。

### 職業（【提案】）

| 職業 | 役割 | 武器 | 専用ゲージ | ステータスの伸び方 | 流派 | 上位職 |
| --- | --- | --- | --- | --- | --- | --- |
| ヒーラー | 回復・支援 | 鈴杖（片手） | なし（MPで戦う） | MP+40%・魔力+15%・防御+5%・攻撃−20% | 癒し・加護 | 鈴守 |
| アーチャー | 遠距離 | 弓（両手） | 集中（100） | 攻撃+15%・会心+3・素早さ+2・HP−10%・防御−10%・魔力−20% | 狙撃・速射 | 天弓 |
| ローグ | 高火力・機動力 | 二刀の短剣（両手） | 気配（5） | 攻撃+20%・素早さ+15%・会心+5・HP−10%・防御−15%・魔力−20% | 影・毒 | 影結び |

- 最初のスキル：ヒーラー「癒しの鈴・清めの鈴音」、アーチャー「標の矢・拡散矢」、ローグ「乱れ刃・毒刃」、モンク「連打・掌打」。
- 防具：ヒーラーは法衣（ウィザードと同じ）。アーチャー・ローグ・モンクは「古代石シリーズ（軽装）」（額当て・胴着・脚絆・短靴）。

### 専用ゲージ（【補完】）

| ゲージ | たまり方 | 減り方 |
| --- | --- | --- |
| 集中（アーチャー） | 戦いの間、立ち止まっていると毎秒6（静止集中で増える）。矢を当てると5 | 戦闘が終わると0 |
| 気配（ローグ） | スキルを当てると1回につき1、通常の攻撃を当てても1（最大5） | 戦闘が終わると0 |
| 気（モンク） | 当てると、前に当ててから2秒以内なら6、あいていれば3。連撃が重なるたびに5 | 3秒当てないでいると、毎秒15ずつ減る。戦闘が終わると0 |

### モンクの連撃（【補完】）

| 項目 | 決めたこと |
| --- | --- |
| 型 | 【起】（連打・掌打・百裂拳・縮地）・【継】（旋脚・流水の構え・崩拳・昇龍脚・気弾・転身投げ・気の渦）・【極】（発勁・破山撃・寸勁・轟拳・百烈・結） |
| 重なり方 | 【起】で1から（重なっていれば違う技なら+1）。違う【継】で+1。同じ技を続けると切れる（【起】なら1からやり直し）。最大5。3秒あくと消える |
| ダメージ | 重なった数1つにつき+6%（連撃の心得で増える）。【極】はさらに、使い切った数1つにつき+15% |
| 気 | 連撃が重なるたびに気+5 |
| パッシブ | 連撃の心得・極めの一撃（連撃5なら会心）・気の巡り（【極】でHPが戻る）・流れを読む（受け流し・回避の後は同じ技でもつながる） |
| 奥義 | 天地流転（8秒、どの向きの攻撃も受け流して打ち返し、打ち返すたびに連撃がつながる。その間は【極】でも連撃が消えない） |

ナイトの剛剣にも、似た仕組み「連ね斬り」（パッシブ。3秒以内に剛剣の違うスキルを続けて当てると、1つごとに+%。3つまで）を入れました。

### 新しい状態（【補完】）

| 状態 | 働き |
| --- | --- |
| 毒 | 重なる（技ごとの上限。しみる毒で増える。どれでも10まで）。毎秒「1つあたりのダメージ × 重なり」。弾けさせる技（毒爆など）で、重なりを使い切って大きなダメージ。毒の敵が倒れると、毒の連鎖で、まわりの敵に移る |
| 標 | プレイヤーから受けるダメージ +値%（強い方・長い方が残る） |
| 縫い止め | 動けない（ボスは時間が半分） |
| 戒め | その敵の攻撃 −値% |
| 煙 | その敵の攻撃が値%で外れる（「外れた」の文字） |
| 潜伏（ローグ） | 魔物が見失い、新しく狙われない。攻撃すると解ける（気配消しのとき） |

### 武器と弓の射撃（【補完】）

| 項目 | 決めたこと |
| --- | --- |
| 鈴杖 | 片手。魔力と、回復の強さ（heal_power） |
| 弓 | 両手。左クリックで矢を射る（攻撃のステータス×通常の攻撃の係数。速さ2.8・36ブロックまで。間隔は武器の攻撃の間隔で、8 tick より短くならない）。狙撃の構えのときは、次の矢3本が強くなる |
| 二刀の短剣 | 両手（1つのアイテムで2本）。手に見えるのは右の1本だけで、左の1本は持ち物の絵にだけ描いた【補完】 |
| 籠手 | 両手。握った手を包む形 |
| 見習い装備 | ギルドが貸す練習用（明るい木・黄土色の革・赤い結び紐・真鍮の札）。職業を選ぶともらえる（取引不可の印つき） |
| 古代石の装備 | 工房で作る（武器職人・防具職人）。相場の基準価格は材料×1.2（`build_shops.py`） |

### 画面（【補完】）

- スキルツリー：木は4段分が見え、ホイールか右の▲▼で上下に動かします。スキルを選ぶと、見える所まで動きます。詳細の2行目に【起】【継】【極】。
- HUD：気配は5つの粒、集中・気・誓気は帯。モンクは「連撃 3」と、消えるまでの残りの帯（5のときは光る）。

## 3. ゲームの中での使い方

1. 誓約の結晶に手を当てて、職業を選びます（左右の矢印で3ページ）。決まった日までは無料で変えられ、そのあとは誓約の証が要ります（Phase 2 のまま。画面の上に出ます）。
2. 選んだ職業の見習い装備がもらえます。武器を持つと、その職業のスキルが使えます。
3. ［J］でスキルツリー。Lv5・10・15・20・25 で新しい段が開きます（6段目まではホイールで下へ）。
4. アーチャーは弓を持って左クリックで矢を射ます。立ち止まって射ると集中がたまり、射抜きなどで集中を使います。
5. ローグはスキルを当てて気配をため、急所突き・影葬・毒爆などで使います。
6. モンクは連打（【起】）→旋脚（【継】）→発勁（【極】）のように、違う技をつないで連撃を重ねます。HUD の「連撃」の数が増えるほど強くなります。

## 6. 自動の確認

GameTest は 100 → **108**（CI の build で 108 すべて通ることを確かめました）。

テストの中の仮のプレイヤー（FakePlayer）は、ワールドのプレイヤーの一覧に入らないため、仲間への回復や、スキルを当てたときにたまるゲージは、その処理を直接呼んで確かめています。

| テスト | 確かめること |
| --- | --- |
| `skillDefinitionsAreValid`・`expandedSkillTrees` | 戦闘職6つ。どの職業もアクティブ16・パッシブ10・奥義2、流派ごとにアクティブ8・パッシブ5。段は0〜5。前提は同じ流派。全スキルの説明が作れる |
| `phase3DefinitionsLoad` | 装備の定義32・工房のレシピ25 |
| `healerHealsAndCleanses` | 癒しの鈴で自分のHPが戻る。仲間への回復（回復の処理を直接呼ぶ）。ほどきで鈍足が消える |
| `healerRevivesDowned` | 倒れた仲間を起こす処理（呼び戻し・大いなる呼び声が使う）で起き上がり、HPが戻る |
| `poisonStacksAndTicks` | 毒が重なり、上限で止まり、毎秒ダメージが入り、弾けさせると使い切る |
| `marksAndHindrances` | 標（強い方が残る）・戒め・煙・縫い止め |
| `stealthLosesTarget` | 潜伏で魔物が見失い、解くと戻る |
| `monkComboChains` | 【起】で1、違う【継】で2、同じ【継】で切れる、【極】で0。気がたまる |
| `roguePresenceGauge` | 乱れ刃に気配をためる働きがある。当てると1つずつたまり、外すとたまらない。最大5 |
| `archerFocusAndBasicShot` | 立ち止まると集中がたまる。左クリックで矢が飛び、間隔をあけずには射てない |

CI の写真（その2の分）：ヒーラー・アーチャー・ローグ・モンクのスキルとHUD、4職業のスキルツリー（奥義を選んだところ）、職業選択、古代石シリーズ（軽装）を着た正面。
