# Minecraftで確かめる：確かめ用のワールドと、街をまとめて建てるコマンド（11月21日）

今までの全部（Phase 1〜3、装備のデザイン、街の11施設）を、ゲームの中で見て回るための道具です。

確かめ用のブランチ `check/ingame` は、まだマージしていない3つのプルリクエストを main に合わせたものです。
3つは衝突しないので、マージの順番は自由です。

- #7：装備のデザイン（`phase-3`）
- #8：武器の持ち方（`gear/weapon-fix`）
- #6：街の11施設（`map/phase1-guild`）

このブランチの自動ビルドの jar には、3つと下の道具がすべて入っています。

## ワールド（ワールドタイプ「コネリアの街（AMEMARU）」）

- 【11月23日に決定】新しいワールドを開くと、はじめから街が建っています。ワールドを作る画面では、ワールドタイプがはじめから
  「コネリアの街（AMEMARU）」になっています（ほかの種類にも変えられます）。このワールドタイプのワールドを初めて開いたとき、
  だれかが入る前に街を建て（中央広場の真ん中が (0, 64, 0)。数秒かかります）、はじめの場所（死んだときに戻る所）を大結晶の前に
  します。前から遊んでいるワールドと、ほかのワールドタイプには建てません（`/amemaru admin city build` で建てられます）。
  一度決めたら、街を壊しても勝手に建て直しません。止めるときは、ワールドを作る前に `defaultconfigs/amemaru-server.toml`（ワールドごとの設定のもと）の `autoBuildCity` を false にします。
- 名前は「コネリアの確かめ用（平地）」から「コネリアの街（AMEMARU）」に変えました（中のID `amemaru:conelia_check` はそのまま）。
- 地面は y 64 の草です（上から草1段・土3段・石124段・岩盤。石は y 60 から y −63 まで）。街の道の高さと同じなので、街を建てると地面になじみます。街でいちばん深い所（釣り堀の池と水門の湖の底）は道の9段下（y 55）なので、地層を変える必要はありません。このワールドタイプでは「カスタマイズ」は押せません。
- ふつうの「スーパーフラット」で作るときは、「カスタマイズ」→「プリセット」の欄に `minecraft:bedrock,124*minecraft:stone,3*minecraft:dirt,minecraft:grass_block;minecraft:the_void` を入れて「プリセットを使用」を押すと、同じ地面になります。地層を変えないままでも、`city build` は道の13段下（y 51）から地面を作ってから建てるので、街は欠けません（まわりより高い台の上に建ちます）。
- 敵も動物も、自然には湧きません（バイオームは `the_void`）。雨も降らず、木や草もありません。敵はコマンドかスポーンエッグで出します。
- 必要なファイルは `data/amemaru/worldgen/world_preset/conelia_check.json` と、一覧に出すための `data/minecraft/tags/worldgen/world_preset/normal.json` です。
- このModを入れた人のワールドタイプの一覧に、だれでも出ます（11月23日から、はじめに選ばれているワールドタイプです）。

## 建物を直す（直した所を書き出して、設計データに取り込む）

使い心地の悪い所は、ゲームの中で直せます。直した所は、作り直しても消えないように設計データに取り込みます。

前の版の jar で街を建てたワールドでは、新しい jar に入れ替えたあと、直し始める前に一度 `/amemaru admin city build force` で建て直してください。11月21日の版で、個人倉庫の階段の上の床（落ちる砂利）と、商店街の北の醸造台（消える瓶）を直したので、建て直さないと、その2か所が直した所に見えます。もう直し始めていたら、建て直さずにそのまま書き出して送ってください（2か所は取り込むときに外します）。

1. `/amemaru admin city build`（育ったあとの形を直すなら `build grown`）で建てて、クリエイティブで直します。
2. `/amemaru admin city export` で書き出します。直した構造物と、直したマスの数が出ます。
3. ワールドのフォルダの `generated/amemaru/city/edits/` を、フォルダごと（zip にして）送ってください。
   ワールドのフォルダは、ワールドの選択画面でワールドを選び「編集」→「ワールドフォルダーを開く」で開けます。
4. 送ってもらった直しを `tools/mapgen/import_edits.py` で取り込み、構造物ファイルを作り直して、街全体を確かめます（`check_city.py`）。
   次の版のModから、直した形で入ります。

- 書き出したあとは、このワールドの `city build` が、Modに入っている形に直しを重ねて建てます（建て直しても直しは残ります。Modを新しくしても重なります）。
- 書き出していない直しがあると、`city build` は建て直さずに止まり、どこに直しがあるかを知らせます（直した所が消えないように）。直しを捨てて建て直すなら、最後に `force` を付けます。
- 書き出しは何回でもできます。前に書き出した直しに足していきます。直して元に戻した所は、直しから外れます。
- 書き出した直しをやめるには、`generated/amemaru/city/edits/` からその構造物のファイルを消して、`city build` します。
- 自然に変わる所は、直しに数えません：草が土になる・扉や門が開いている・灯りが点く／消える・氷が溶ける・水が流れる・サトウキビや竹やつるが伸びる・作物が育つ・銅が錆びる・雨で大釜に水がたまる・柵や階段の形がまわりに合わせて変わる、など。
- 額縁と防具立ての向きは、−180〜180 にそろえて比べます（構造物を置くとき、ゲームは向き 180・270 を −540・−450 にして置くため。そろえないと、置いただけの北・東向きの額縁と防具立てが「直した所」に見えます）。
- 書き出したときと、建て直しが止まったときは、ゲームのログ（`logs/latest.log`）に `[amemaru][city]` で、直した所の見本（構造物ごとに5か所ずつ、建てた形と今の形）が出ます。
- 額縁と防具立ては、壊して置き直してから中身を入れてください（もとの物は動かせない守りが付いています）。書き出すと、守り（壊れない・額縁は固定・防具立ては出し入れできない）が付き直ります。
- 落ちたアイテム・動物・乗り物などの「もの」は書き出しません。
- 道・広場・城壁・家・木などの街並みは、街並みの区画（`town/t<i>_<j>`。48×48）として書き出せます（施設の名前は「街並み」）。城壁の外の野原は、どの構造物にも入らないので書き出せません。変わった所があれば、数と場所の例を知らせます（言葉で教えてください）。
- はじめの形と育ったあとの形が重なる所（料理屋・露店の8区画など）は、育ったあとの形で直すと、育ったあとに重ねる形の方に入ります。

| ワールドのフォルダの中 | 中身 |
| --- | --- |
| `generated/amemaru/city/edits/<構造物>.json` | 書き出した直し（Modに入っている形との違い。送ってもらうもの） |
| `generated/amemaru/city/built/<構造物>.nbt` | 最後に建てた形の控え（直した所を見分けるもと。送らなくてよい） |

## CIで撮る写真（11月21日に足した）

建物の見本の写真の後に、街を空（道の高さ y 200）に建てて、次の写真を撮ります。

- 上から・斜めから：`city_top_n`・`city_top_s`・`city_aerial_se`・`city_aerial_nw`
- 各施設の前：`city_plaza`・`city_guild`・`city_storage`・`city_weapon`・`city_armor`・`city_accessory`・`city_market`・`city_free_market`・`city_church`・`city_fishing`・`city_lake`・`city_casino`・`city_tower`
- 夜：`city_top_n_night`・`city_top_s_night`・`city_plaza_night`・`city_market_night`・`city_church_night`・`city_tower_night`
- 育ったあとの形：`city_grown_top_n`・`city_grown_top_s`・`city_grown_monument`・`city_grown_forge`・`city_grown_highlow`・`city_grown_fishrace`・`city_grown_restaurant`・`city_grown_stalls`・`city_grown_frozen_pond`・`city_grown_lake`
- 街並み（Phase 5）：`city_houses`・`city_gate_south`・`city_warehouses`・`city_wall`、夜の `city_houses_night`・`city_gate_south_night`
- Phase 5 の遊びの流れ（NPC・オープニング・会話・塔の門・1階・ボス）：`phase5_*`（`docs/phase5.md` の「自動の確認」）

写真が33枚増えたので、クライアントの確かめの時間の上限を45分にしました（ジョブは55分）。
はじめの形の写真のあとに、直しの書き出しを通しで確かめます（ログで見る）：直しがなければ「新しい直しはありませんでした」。ギルドの上の空に金のブロックを置くと、書き出す前の建て直しは止まり、書き出すと建て直しても残り（`city_edit_kept`）、空気に戻して書き出すと直しのファイルが消えます。建て直しが止まったままだと、ログに `CI: city build did not run` が出ます。
同じ通しの確かめを、自動テスト（`CityEditsGameTests`。街をテストの場所の130上に建てる）でも行います。建てた直後・書き出した直後・直しを重ねて建て直した直後に「直した所」が1つもないこと（置き方の違いを直しに数えない）を確かめるので、ビルドのジョブで分かります。
CIのコマンドはサーバーとして動くので、移る人を `@p` で渡します（`city tp <場所> @p`）。遠くへ移ったあとは、まわりの形を作り直すのを待ってから撮ります（上からと斜め、100ブロックより遠くへ移るときは10〜12秒、ほかは5〜7秒）。
空に建てているので、城壁の外の遠くは空の色に写ります（描く距離12チャンクの霧の外は描かれない）。

## Phase 5 を確かめる（初めてのログインから1階のボスまで）

1. 確かめ用のワールドで `/amemaru admin city build` を打ち、街並みと施設とNPCを建てます。
2. `/amemaru admin map build floor 1` で、塔のディメンションに1階を建てます（しばらくかかります。終わると「建てました」）。11月22日に1階を作り直したので、前に建てたワールドでも、もう一度建ててください。
3. 初めてのログインを試すには、`/amemaru admin story opening reset @s` のあと入り直すか、`/amemaru admin story opening start @s` で始めます。暗い画面 → 大結晶の声 → 目覚め → リリアが駆け寄る → 会話（名前を答えると名簿に書かれる）→ 職業の画面、の順に進むことを見ます。
4. 右上の手引きに沿って、北門の外の塔の入口へ行き、転移の円に立ちます（門番のバルドに話しても同じ）。行く階の画面で「1階　始まりの草原」を選びます。
5. 3本の石柱を起動し（`/amemaru admin floor tp 1 pillar1` などで近くへ移れます）、広間の門の光の幕を通ってヴェルドホーンを倒します（クリエイティブやスペクテイターでは戦いに入らないので、アドベンチャーかサバイバルで）。倒すと出口の円が開き、倒した人の画面で「始まりの草原　踏破」の場面が流れます。初撃破の知らせは、ほかの人にはすぐ、倒した人には場面が終わってから出ます。円に2秒立つと塔の門へ戻ります。
5-1. 1階の中身（11月22日）：
   - 西の丘：ふもとの看板から丘を巻く道を上り、台地の「群れの長」（大きなツノモフ）を倒すまでは、石柱に触れても手がかりが出るだけ。倒すと「1本目の石柱の核が目を覚ました」と出て、起動できる。東の崖の洞と、台地の西の見張り台の跡に宝箱。
   - 北西の林：林の欠け牙の狼が「光のかけら」を落とす（35%）。3つ持って石柱に触れると、かけらを使って起動できる。2つでは起動しない。
