# 11月25日の修正（ボス戦の見直し・近接職の守り・武器・音の床）

11月25日にいただいた修正点8つを、すべて直しました。ボス戦は「間を遅く」「固有のギミック」「曲と演出」で作り直し、
「みんなで受ける一撃」はレイドのボスだけにしました。【補完】は、ご指示にない細かい所をこちらで決めたものです。

## いただいた修正点と、直したこと

## ボスの間（予兆・待ち時間・息つぎ）

予兆（技の印が出てから打つまで）は、どの技も1秒以上にしました。技が終わったあとは、1.4秒のあいだ次の技を出しません（打ち返す好機。
人数が多い・怒っているときは少し短く、0.6倍まで）【補完】。ボスの動き（アニメーション）は前の予兆に合わせて作ってあるので、
新しい予兆の長さに合わせてゆっくり流します（例：角の薙ぎ払いは 0.8秒で作った動きを 1.3秒で）。

| ボス | 技（予兆 前→後・待ち時間 前→後） |
| --- | --- |
| 1階 ヴェルドホーン | 薙ぎ払い 0.8→1.3秒・3.5→4.5秒／角の突き上げ 0.6→1.0・5→6.5／後ろ蹴り 0.7→1.1・6→7.5／突進 1.0→1.3・9→11／踏みつけ 1.2→1.7・12→14／大跳躍 1.1→1.4・11→13／根の牙 1.0→1.3・13→16 |
| 2階 オールドウォード | 薙ぎ払い 1.2→1.7・4→5.5／地割れ 1.5→1.9・6→7.5／根の檻 1.8→2.2・9→11 |
| 3階 ハイドラム | 水の大砲 1.6→2.0・7→9／薙ぎ払い 1.1→1.6・4.5→6／渦 1.8→2.2・10→12 |
| 4階 カンターレ | 嘆きの波 1.2→1.7・5→6.5／光の柱 1.8→2.2・9→11 |
| 5階 古代守護者 | 薙ぎ払い 1.2→1.7・5→6.5／光線 1.6→2.0・8→10／叩きつけ 1.4→1.9・9→11／接続判定 3.0→3.5 |

数は `data/amemaru/amemaru/enemies/<ボス>.json` の `skills`（`windup` が予兆、`anim_windup` が動きを作ったときの予兆、`cooldown` が待ち時間）。

## 曲（ボスごとのオリジナル曲）【補完】

どれも `tools/audio/boss_music.py` の楽譜と `tools/audio/synth.py` の計算で作ったオリジナル曲です（既存の曲・録音は使っていません）。
くり返し流しても切れ目がないように作り（曲の終わりからはみ出した余韻を頭に重ねる）、Ogg Vorbis（44.1kHz・ステレオ・約100kbps）で
`assets/amemaru/sounds/music/boss_<ボス>.ogg` に置き、sounds.json に `music.boss.<ボス>` として足しています。

| ボス | 題 | 調・速さ | 長さ | 楽器 |
| --- | --- | --- | --- | --- |
| 1階 ヴェルドホーン | 草原を裂く角 | ニ短調・148 | 52秒 | 太鼓・駆けるベース・弦の刻み・金管の旋律 |
| 2階 オールドウォード | 古樹は目を覚ます | ホ短調（ドリア）・112 | 69秒 | 木の太鼓と拍子木・カリンバ・チェロ・森の合唱・笛 |
| 3階 ハイドラム | 大水門の機関 | ハ短調・136 | 56秒 | 脈打つベース・金属の打撃・水の雫・こだまするシンセ |
| 4階 カンターレ | 祈りの残響 | イ短調（フリギア）・3拍子・138 | 63秒 | 合唱・鐘・オルガン・枠太鼓・ティンパニ |
| 5階 古代守護者 | 祭壇の守護者 | 嬰ハ短調・156 | 62秒 | 弦の刻み・金管・合唱・太鼓・ティンパニ・鐘 |

- 流れるのは、ボスのHPの帯が出ている人（戦いの参加者）だけ。いつもの曲は止まり、戦いが終わると2.5秒ほどでゆっくり消える
- 追いこんだ（ボスのHPが30%以下か、怒った）ときは、少し速く高くなる（1.04倍）
- 大きさは Minecraft の「音楽」の音量に従う。設定 `amemaru-client.toml` の `boss.music = false` で止められる
- 作り直すとき：`python3 tools/audio/boss_music.py`（1曲だけなら `python3 tools/audio/boss_music.py veldhorn`。`--wav <フォルダ>` で確かめ用の WAV も）

## 演出【補完】

| いつ | 演出 |
| --- | --- |
| 戦いのはじまり | 画面の上下に黒い帯と、ボスの名前・階の名前（3秒あまり）。低い雷鳴と、画面の揺れ |
| 段階が変わった | ボスから光の波と光の柱（ボスの色）、画面が白く光って揺れる。「― 第2段階 ―」 |
| 追いこんだ（HP30%以下・怒った） | 「追いこんだ ― ここが正念場」と、ボスのまわりの赤い気配 |
| ギミックの構え（大地の咆哮・大放水・残響の色・切断判定） | 画面のふちが赤く脈打つ。残り3秒からは濃く速くなり、1秒ごとに時を刻む音 |
| 自分のHPが30%以下 | 心臓の音と、画面のふちの赤い脈（15%以下で速く） |
| 大きく打たれた（最大HPの15%以上） | 画面が揺れ、ふちが赤く光る |

設定 `boss.effects = false` で止められます。画面の揺れは、前からある `skills.screenShake` にも従います。
確かめ用に、管理者のコマンド `/amemaru admin boss hp <階> <%>` でボスのHPを変えられます（段階が変わる演出・追いこんだときの曲）。

## 近接職の守り【補完】

| 職業 | 変えたこと |
| --- | --- |
| ナイト | 「不屈の再起」（守護の流派・Lv21・5段目の列）：HPが3割を切ると、すぐに最大HPの20%（段階ごとに+2.5%）が戻り、そのあと5秒かけて同じだけ戻る。気も20たまる。90秒に1回 |
| ローグ | 職業の伸び：防御 −15%→−5%・HP −10%→±0。「影吸い」（影の流派・Lv5）：与えたダメージの6%（段階ごとに+1%）だけHPが戻る（1回で最大HPの3%まで） |
| モンク | 職業の伸び：防御 +5%→+15%・HP +10%→+15%。「金剛身」（剛の流派・Lv5）：受けるダメージ −6%（段階ごとに −1%。5段で −10%）。気が50以上の間は、その2倍（5段で −20%） |

前のワールドで、ツリーからなくなった節（守りのパッシブを置いた所にあった小さな節など）を取っていた人は、ログインのときにその節のポイントが戻ります（「スキルツリーの形が少し変わったので、なくなった節のNポイントを戻しました」）。
