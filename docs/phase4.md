# Phase 4：パーティ・ダウンと蘇生・教会での復活・デスペナルティ

Phase 0-B 13章の「Phase 4で作るもの」（パーティ、ダウンと蘇生、教会での復活、デスペナルティ）を作りました。確認の目安は「**2人でパーティを組み、ダウンした仲間をしゃがんで起こせる**」です。

作ったものの中心は次のとおりです。

- **パーティ**（6人まで）：誘う・参加する・断る・抜ける・外す・リーダーを渡す。**パーティの画面（Uキー）**、チャットの［参加する］［断る］、`/amemaru party` のどれでも組めます。**左上のパーティのHUD**に、メンバーのHPとダウンの残りが出ます（HPはパーティのメンバーにだけ送る。Phase 0-B 5章）。
- **ダウン**：HPが0になると、バニラの死亡の代わりに**30秒のダウン**になります。伏せた姿になり、動けず、攻撃・スキル・アイテムを使えません。ダメージを受けず、魔物にも狙われません。
- **蘇生**：ダウンした人のそば（2.5ブロック）で**3秒しゃがみ続ける**と起こせます（ヒーラーは1.5秒）。起き上がるとHPは最大の30%です。
- **教会での復活**：30秒たつと、結びの教会の**呼び戻しの円**へ戻ります（セレナの「呼び戻しの儀」。Phase 0-A 7章・13章）。HPとMPは全快です。
- **デスペナルティ**：呼び戻しの儀の代価として、**手持ちの所持金の5%**を失います。経験値とアイテムは失いません。戻ってから**60秒は「衰弱」**（ステータス−10%）です（Phase 0-A 20章・24章）。
- **所持金（ノット）**を持てるようにしました（ステータス画面に出ます）。お金を手に入れる・使う仕組み（店・フリマなど）はPhase 6です。
- **パーティの経験値**：近く（32ブロック以内）のメンバーで均等に分け、人数のボーナス（合計が「1＋0.2×（人数−1）」倍）。ドロップは一人ずつ抽選（Phase 0-A 19章・24章）。

## 3. 遊び方

### パーティを組む

1. **Uキー**でパーティの画面を開きます。「誘える人」に、サーバーにいる人が出ます。［誘う］を押します。
2. 誘われた人のチャットに「〇〇からパーティに誘われました ［参加する］［断る］」と出ます。押すか、Uキーの画面の［参加する］で入ります。
3. 左上に、ほかのメンバーの名前・レベル・HPが出ます（リーダーは★）。
4. 抜けるときは、Uキーの画面の［抜ける］。リーダーは［外す］［リーダーに］も使えます。

コマンドでも同じことができます（だれでも使えます）。

| コマンド | 内容 |
| --- | --- |
| `/amemaru party` | パーティの様子と、届いている誘い |
| `/amemaru party invite <人>` | 誘う |
| `/amemaru party accept [人]`・`decline [人]` | 参加する・断る（人を省くと、いちばん新しい誘い） |
| `/amemaru party leave` | 抜ける |
| `/amemaru party kick <名前>`・`leader <名前>` | 外す・リーダーを渡す（リーダーだけ） |

### ダウンと蘇生

- HPが0になると「ダウン」。画面のふちが暗い赤になり、真ん中に教会へ戻るまでの秒数が出ます。伏せた姿になり、頭の上の名前に「ダウン 25」と出ます。
- そばにいる人の照準の下に「しゃがむと、〇〇を起こせます」と出ます。**しゃがみ続けると**、照準の下に起こした量のバーが出て、3秒で起き上がります。
- 起こされている人の画面には「〇〇が手を取っています」とバーが出ます。

### 教会での復活

- 30秒たつと、教会の呼び戻しの円へ戻ります。画面に「呼び戻しの儀」と出て、鐘が鳴ります。
- チャットに「呼び戻しの儀の代価として、所持金の5%（〇〇ノット）を大結晶に捧げました」。
- 右上に「衰弱」の効果が60秒出ます（ステータスが10%下がる）。

## 4. 管理者のコマンド（OP・権限レベル2以上）

| コマンド | 内容 |
| --- | --- |
| `/amemaru admin down <人>` | ダウンにする（確かめ用） |
| `/amemaru admin down <人> revive` | すぐ起こす |
| `/amemaru admin down <人> church` | すぐ教会へ戻す（代価と衰弱もかかる） |
| `/amemaru admin church` | 教会での復活の場所を見る（どこから決めたかも出る） |
| `/amemaru admin church set [位置] [向き]` | 決める（省くと自分の場所と向き） |
| `/amemaru admin church clear` | 決めた場所を消す（確かめ用の街の教会か、スポーン地点に戻る） |
| `/amemaru admin church tp [人]` | そこへ移る |
| `/amemaru admin money <人>` | 所持金を見る |
| `/amemaru admin money <人> set\|give\|take <額>` | 所持金を決める・渡す・取る |
| `/amemaru admin party list` | すべてのパーティ |

本番の街（Phase 5の縦切り版のコネリア）を置いたら、`/amemaru admin church set` で教会の呼び戻しの円を決めてください。決めていなければ、確かめ用の街（`/amemaru admin city build`）の教会、それもなければスポーン地点に戻ります。

## 5. 設定（`serverconfig/amemaru-server.toml`）

| 区分 | 項目 | 初期値 |
| --- | --- | --- |
| `[down]` | `downSeconds`（ダウンの秒数） | 30 |
| | `reviveSeconds`・`healerReviveSeconds`（起こす秒数） | 3.0・1.5 |
| | `reviveRange`（起こせる距離） | 2.5 |
| | `reviveHpPercent`（起き上がったときのHP%） | 30 |
| | `reviveInvulnerableSeconds`（起き上がってすぐの無敵） | 2.0 |
| | `deathMoneyPercent`（失う所持金%） | 5 |
| | `weaknessSeconds`・`weaknessPercent`（衰弱） | 60・10 |
| | `churchScatter`（戻る場所のばらし方の半径） | 3.0 |
| `[party]` | `maxMembers`（人数の上限） | 6 |
| | `expShareRange`（経験値とドロップを受け取る距離） | 32 |
| | `expBonusPerMember`（1人増えるごとの経験値のボーナス） | 0.2 |
| | `inviteSeconds`（誘いの期限） | 60 |

## 6. 自動の確認

- 自動テスト（GameTest）に7つ足しました（合わせて72）：パーティを組む・リーダーを渡す・抜ける・外す・解散、6人まで、パーティの保存と読み直し、経験値の分け方、ダウンと蘇生（HP30%・起こした回数・無敵）、教会へ戻る（所持金5%・衰弱・経験値は減らない）、所持金とダウンの保存。
- CIの写真（街の写真の後）：`phase4_party_hud`（見本のパーティ：HPが減った人・ダウンした人・いない人・届いた誘い）、`phase4_party_screen`、`phase4_revive_hint`・`phase4_reviving`（名前の付いた防具立てをダウンに見せた見本）、`phase4_down`・`phase4_down_third`（本当にダウンにする）、`phase4_church`（育ったあとの街の教会へ戻る）。
- 2人でしか確かめられないこと（ほかの人がしゃがんで起こす・パーティのHUDに本当の仲間が出る・経験値の分け方）は、LANの2人の確かめでします（Phase 1〜3 の分と合わせた手順書）。
