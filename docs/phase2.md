# Phase 2：職業選択とスキルシステム（ナイト・ウィザード）

Phase 0-B 15章の「Phase 2でやること」（ナイトとウィザード、スキルのキー、専用ゲージ、プレイヤーのモーション）を作りました。確認の目安は「**2つの職業でスキルが使え、クールダウンとMPが働く**」です。

あわせて、仕様のS2（職業・見習い装備・スキル・上位職と転職の決まり）、S3（スキルツリーの画面・やり直しのアイテム）、S4（スキルのキー・狙い方・クールダウン・MP・詠唱・演出・頭上の数字）、S14（独自のデザインの画面）のうち、ナイトとウィザードに関わる部分を入れています。

**11月17日の変更（スキルの拡張）**：「スキルが単調で、戦闘に深みが出ない」「スキルの演出にこだわりたい」とのご指示を受けて、次のようにしました。

- 各職業のスキルを **アクティブ12（流派ごとに6）・パッシブ6（流派ごとに3）・奥義2（流派ごとに1つ。どちらか1つを選ぶ）** に増やしました（仕様S2の「アクティブ4〜6個」から、ご指示で増やしています。設計はPhase 0-A 19章に書きました）。スキル枠は6つなので、どれを持って出るかで戦い方が変わります。
- 敵に重なる状態（**凍え→凍結→砕く・感電・星痕・防御崩し**）で、スキル同士がつながるようにしました。操作にも、**溜め（長押し）・受け流し（タイミング）・跳躍・引き寄せ・円陣・障壁・貫通**を足しました（3章）。
- 演出を作り直しました。このModのパーティクル6種と、**魔法陣・波紋・斬撃の弧・光の帯・稲妻・流れ星・氷の棘・光の柱・障壁のドーム**などの形で、スキルごとに組み立てています。敵の頭の上の状態の印、凍結した敵を包む氷なども見えます（3章「演出」）。
- スキルのキーは設計どおり **R・G・V・Z・X・C**、ウィザードの流派の名前は「**星灯（ほしあかり）**」に決まりました（上位職は「星詠み」のまま）。
- **奥義は2つから1つを選ぶ**ようにしました（同じ日のご指示）。ナイトは今までのタンク用の「不落の城」（守護）と、攻撃に特化した「**天断ち**」（剛剣）。ウィザードは「星落とし」（星灯）と、敵の群れをまとめて凍らせる「**氷華の檻**」（氷結）【提案】。どちらか1つを覚えると、もう一方は覚えられません。選び直すには、白紙の誓約書でスキルをやり直します【提案】。

## 3. できること

### 職業を選ぶ（誓約の結晶）

- 冒険者ギルドに置く「**誓約の結晶**」に右クリックすると、職業の登録の画面が開きます（結晶から8ブロック以内で選ぶ）。今はクリエイティブのタブ「AMEMARU: LOST CONNECTION」から置きます（マップはPhase 5）。壊れません。
- 画面には職業ごとのカードがあり、紋章・役割・武器・専用ゲージ・ステータスの伸び方・説明・最初の技・見習い装備が出ます。「この職業にする」→「誓う」で決まります。
- 初めて選ぶと、その職業の**見習い装備**と、**忘れ水**・**白紙の誓約書**（各1つ）を受け取ります。どれも「取引できない」印付きです。見習い装備は職業ごとに1回だけ、やり直しのアイテムは最初の1回だけです。
- **転職**：3日目までは何度でも無料。4日目からは「**転職の証**」が1つ要ります（手に入れ方はPhase 6のクエスト。今は管理者が渡す）。転職すると、レベルとステータスの振り分けはそのまま、スキルは最初からになり、スキルポイントはすべて戻ります。
- **上位職**：11日目から、Lv30以上で昇格できます。初めての昇格は冒険者ギルドの昇格試験（Phase 6）で、今は管理者のコマンドで昇格させます。一度昇格した人は、転職した後も誓約の結晶の画面から昇格し直せます。昇格すると、各スキルの第3段と奥義が覚えられるようになります。

### 溜め（長押し）

- 溜め斬り・灯火の連弾は、**キーを押している間に溜め、離すと放ちます**。溜めている間は足が少し遅くなり、画面の中央の少し下に溜めのバー（橙から白へ）が出ます。溜めきると光と音で知らせ、バーに「最大！」と出ます。
- MPとクールダウンは、放ったときに使います（溜めを始めた時点ではまだ）。溜めきってから1秒たつと、自動で放ちます。溜めている間は、ほかのスキルは使えません。画面を開いたときは、離したことになります。

### スキルを使う

- **キー**：スキル枠1〜6は **R・G・V・Z・X・C**（Phase 0-Aのとおり。11月17日に決定）。「設定」→「操作設定」→「AMEMARU: LOST CONNECTION」で変えられます。`config/amemaru-client.toml` の `control` を `HOTBAR_ALT` にすると、左Altを押している間だけホットバーの1〜6がスキルになります。
- 初めて起動したとき、バニラの「ツールバーの保存・読み込み」のキー（X・C）を1回だけ外します（あとで付け直しても、また外すことはありません）。試作版の初期値（R・Z・X・C・B・Y）のままの人は、初めて起動したときに新しい初期値へ移します（自分で変えたキーはそのまま）。
- **ボイスチャットMod**（Simple Voice Chat）の初期のキーは、V（設定の画面）・G（グループ）が重なります。ボイスチャットの側のキーを、操作設定の「Simple Voice Chat」で変えてください（例：設定の画面を「;」、グループを「'」）。
- **スキル枠のHUD**：ホットバーの左に、六角の枠6つが蜂の巣の形に並びます。アイコン・キー・クールダウン（上から影が引いていき、残りの秒が出る）。MPやゲージが足りないと青く沈み、使えるようになった瞬間に白く光ります。上に専用ゲージ（ナイトの誓気）。
- **使い方**：キーを押すと、見ている先を狙います。単体の技は視線の近くの相手（少しずれていても近いものを選ぶ）、地点の技は見ている地面、味方の技は見ている味方です。サーバーが射程・向き・壁を確かめ、だめなら「スキル失敗（対象なし）」などがアクションバーに出ます。
- **溜め**：溜め斬り・灯火の連弾は、押している間に溜めて離すと放ちます（上の「溜め」）。
- **詠唱**：流星群と星落としは詠唱があります。画面の中央の少し下に詠唱のバーが出て、移動が遅くなります。詠唱中に**同じキーをもう一度押すとやめられます**（MPは減らず、クールダウンも始まりません）。
- **職業の武器**を手に持っていないと使えません（ナイト：見習いの剣・大剣、ウィザード：見習いの杖。configで外せます）。
- 1人が1秒に送れる要求は10回まで（超えた分は捨てて、ログに残す）。

### スキルツリー（Jキー）

- 左上の**流派のつまみ**（例：守護・剛剣・奥義）で、木を切りかえます。木は**4段×3列**で、左の2列がアクティブ、右の列がパッシブ。段の左に、覚えられるレベル（Lv1・5・10・15）が出ます。
- **奥義のつまみ**には、流派ごとの奥義が左右に2つ並びます（「守護の奥義」「剛剣の奥義」のように、下に流派の名前）。**どちらか1つ**を選んで覚えます。覚えた方には「選んだ奥義」と出て、もう一方は暗くなり、ボタンに「もう一方の奥義を選んでいる」と出ます。選び直すには、白紙の誓約書でスキルをやり直します【提案】。上位職を外すと奥義は消えるので、昇格し直したときにも選び直せます。下に上位職の説明が出ます。前提のスキルとは糸でつながり、覚えると糸が光ります。節の下の小さな印が段階（金の印は上位職の段階）。
- 右に選んだスキルの説明。**段階のつまみ（1段・2段・3段）**を押すと、その段階の消費・クールダウンと効果が見られます（初めは「次に覚える段階」）。
- 「習得する（1SP）」「段階を上げる（2SP）」で覚えます。覚えられないときは、ボタンに短い理由（「レベル10から覚えられる」など）、ボタンにマウスを乗せると詳しい理由が出ます。
- **段階とポイント**【補完】：段階は1〜3、ポイントは1段目1・2段目2・3段目3（奥義は1段だけで5）。行ごとのレベル：1行目Lv1、2行目Lv5、3行目Lv10、4行目Lv15、奥義Lv30。最初の技2つの1段目は無料です。スキルポイントはLv50で59。全部を最大にするには113要るので、**どのスキルを伸ばすかを選ぶ**ことになります。
- 下にスキル枠6つ（右下の小さな文字がキー。HUDと同じ）。アクティブスキルを選んでから枠を左クリックで入れ、右クリックで空にします。覚えたアクティブスキルは、空いている枠に自動で入ります。
- 画面の高さは、GUIの大きさで240（854×480の窓のGUIの大きさ2、1280×720の窓の3）に収まるようにしています。
- ステータス画面（K）の左下の「スキルツリー」からも開けます。

### 連携（Phase 0-A 13章）

- 「**起点**」のスキルが敵に当たった後、4秒以内に**別の人**の「**追撃**」が当たると「**連携！**」（追撃のダメージ+30%）。3人以上でつなぐと「**三連携**」（+50%）。つなぐたびに4秒を数え直します。関わった人の画面に大きな文字、周りの人の画面には敵の頭上に文字が出ます。
- 「**支援**」のスキル（盾結び・魔力の糸）を受けた味方は、4秒以内に使う次のスキルの効果が+20%になります（星落としは詠唱も半分）。
- 同じ人の起点と追撃、時間切れは連携になりません。

### ダメージと頭上の数字

- スキルのダメージは、使った人のステータスから計算し、相手の防御で減らします（6章）。すべてサーバーで計算し、クライアントからは数値を受け取りません。
- 近接攻撃（左クリック）も、攻撃のステータス × 攻撃のたまり具合で、独自のダメージになります。
- 魔物（Phase 3でこのModの敵を作るまでは、バニラのゾンビなど）から受ける攻撃は、バニラのダメージ × 8 を防御で減らし、挑発の極意・城壁の構え・不落の城・誓いの円陣・鉄壁で減らし、盾結びで肩代わりし、光の帳の障壁で吸い、不屈の誓いでHPが1残るようにします。受け流しの構えの間の正面からの攻撃と、凍結した魔物の攻撃は、攻撃ごと止まります。落下などは、Phase 1と同じく最大HPに対する割合です（障壁は吸います）。
- **プレイヤーどうしの攻撃は無効**です（協力のゲームのため。configで許せます）。
- 頭上の数字：与えたダメージは白、会心は黄色で大きく「!」付き、受けたダメージは赤、MPを受け取ると青、肩代わりは「（肩代わり）」付き、障壁が吸った分は金で「（吸収）」付き。「受け流し！」「凍結！」「砕けた！」も出ます。数字は少し浮かんで消えます（`showDamageNumbers` で消せます）。
- 光の帳の障壁が残っている間は、HPのバーに金色の帯が重なり、数字に「+障壁の量」が出ます。

### 演出

- **パーティクル**：このModのもの6種（やわらかな光・飛び散る火花・氷のかけら・またたく星・昇って消える紋字・舞う雪）。自分で光り、暗い所でも明るく見えます。ゲームの「パーティクル」の設定（すべて・減らす・最小）に従います。
- **形**：地面の魔法陣（詠唱・氷・星・誓い・雷の5種。回りながら広がる）、広がる波紋と光の壁、斬撃の弧（刃先が走り、光の帯が残る）、光の帯（盾結び・魔力の糸・縛鎖の鎖）、稲妻（形が変わり続ける）、空から落ちる流れ星、障壁・円陣・不落の城のドーム、光の柱、地面から突き出す氷の棘、飛んでいく氷の槍、城壁の構えの光の壁。
- **状態の見た目**：凍えの数だけ頭の上に雪の結晶、凍結した敵は氷の塊に包まれ、砕くと氷のかけらが飛び散る。星痕の数だけ頭の上を星が回る。感電した敵のまわりを小さな稲妻が走る。防御崩しはひびの入った盾の印、よろめきは頭のまわりを回る星。プレイヤーの障壁は光の球、誓いの円陣の中は足もとの紋。
- 当たったところに火花が散り、会心は大きく光ります。大きな技（流星群・星落とし・跳躍斬・溜め斬り・雷霆・不落の城など）は、近くにいると画面が少し揺れます（`screenShake` で止められます）。
- 自分の体のまわりの見た目（障壁の球・城壁の光の壁など）は、一人称のときは出しません（目の前をふさがないため）。

### 訓練人形・見習い装備・やり直しのアイテム

- **訓練人形**：アイテムを地面に置くか、`/amemaru admin dummy [防御]` で目の前に置きます。HP 2,000（config）で、頭上に「HP / 最大 防御」が出ます。HPが0になるとすぐに満タンに戻り、5秒攻撃されないと回復します。プレイヤーの攻撃とスキルでだけ傷つき、魔物には狙われません。クリエイティブでしゃがみながら殴ると片付けられます。
- **見習い装備**：見習いの剣（攻撃+6）、見習いの大剣（攻撃+10、両手持ち：持っている間は盾が効かない）、見習いの盾（防御+4。右クリックで構える）、見習いの杖（魔力+8、MP+20）。手に持っている間だけステータスに足されます。
- **忘れ水**：ステータスの振り分けをすべて戻す。**白紙の誓約書**：スキルの習得をすべて戻す（最初の技は1段目で残る）。どちらも右クリックで確認の文が出て、3秒以内にもう一度で使います。

### プレイヤーのモーション

スキルを使うと、腕や体が動きます（例：突進斬りは振りかぶって踏み込み、旋風断は一回転、流星群の詠唱は両手を空へ、溜め斬りは剣を肩の後ろへ引いて溜め、跳躍斬は剣を振りかぶって飛び、着地で叩きつける）。三人称でほかの人からも見えます。一人称では、右手（武器）の動きだけが見えます（左手の盾などは目の前をふさぐため、一人称では出しません）。今のモーション31本は仮のものです（8章）。

### 手で確かめること

jar の入れ方は [README](../README.md) にあります。**クライアントには playerAnimator の jar も入れます**。ワールドは、チートを許可して新しく作ってください。

1. **準備**：`/amemaru admin level set @s 10`。クリエイティブのインベントリの「AMEMARU: LOST CONNECTION」のタブから「誓約の結晶」と「訓練人形」を取り、結晶を置く。
2. **職業の登録**：結晶を右クリックする。上に「大結晶に誓い、職業を選んでください。3日目までは何度でも無料で変えられます」。ナイトの「この職業にする」→「誓う」。
   - チャットに「大結晶に誓いを立て、「ナイト」の接続技能を授かりました」と、Jキーの案内が出て、音が鳴る。
   - 持ち物に、見習いの剣・見習いの盾・見習いの大剣・忘れ水・白紙の誓約書（どれも「取引できない」）。
   - ホットバーの左に六角の枠が6つ。Rに呼び声、Gに突進斬り、ほかは空。その上に「誓気 0」のゲージ。
3. **ステータス**：Kを押す。見出しが「ステータス ― ナイト」。何も持たないとHP 672・MP 171・攻撃 28・魔力 22・防御 18。剣を手に、盾をもう片方の手に持つと、攻撃 34・防御 23 になる。大剣に持ちかえると攻撃 38・防御 18（盾が効かない）。
4. **スキルツリー**：Jを押す（ステータス画面の「スキルツリー」からも開ける）。右上に「スキルポイント 11」。
   - 呼び声を選ぶと、つまみが「2段（次の段階）」になっていて、「MP 12・CD 11秒」と効果が出る。「1段」を押すと今の段階が見られる。
   - 城壁の構えを選ぶと、ボタンが「先に「盾結び」を覚える」で押せない。マウスを乗せると詳しい理由が出る。
   - 盾結び → 城壁の構えの順に「習得する」。盾結びはVに、城壁の構えはZに自動で入る。ポイントは9になる。
   - 左上のつまみで「剛剣」「奥義」に切りかえると、その流派の木と、奥義と上位職の説明が出る。
   - 呼び声を2段に上げる（2ポイント）。3段目は「上位職になると覚えられる」。
5. **スキルを使う**：剣と盾を持ち、`/amemaru admin dummy` で目の前に訓練人形を置く。人形の頭上に「2000 / 2000 防御 0」。
   - Rを押す：足もとに誓いの魔法陣、周りに金の波紋と光の壁が広がり、MPが12減る。枠に影がかかり「12」から数が減る。人形から自分へ赤い光の糸が伸び、頭上に赤い光、誓気が5増える。
   - 人形の方を向いてGを押す：前へ突進して斬り、人形の頭上に50前後の白い数字（ときどき黄色の会心）と火花。人形のHPが減り、頭のまわりを星が回る（よろめき）。
   - クールダウン中にもう一度押すと、アクションバーに「突進斬りは、あと○秒で使えます」。
   - 剣をしまってRを押すと「ナイトの武器（片手剣と盾・両手剣）を手に持ってください」。
6. **誓気と旋風断**：`/amemaru admin skill learn @s knight/whirlwind 1` で旋風断を覚える（Xに入る）。`/amemaru admin skill gauge @s 60` で誓気を60にして、人形の近くでXを押す。誓気が30減り、斬撃の光の輪が金色になって、ダメージが大きくなる（攻撃34なら、およそ71。誓気が30未満なら銀色で、およそ48）。8秒たつと誓気は0に戻る。
7. **城壁の構え**：サバイバルにして（`/gamemode survival`）、難易度を「ふつう」、夜にして（`/time set night`。昼だとゾンビが燃える）、ゾンビを呼ぶ（`/summon zombie ~ ~ ~4`）。
   - 何もしないで殴られると、HPのバーが減り、頭上に赤い数字（ゾンビのバニラのダメージ3なら、およそ20）。誓気がたまる。
   - Zを押す（城壁の構え）。体の前に青い光の壁（三人称で見える）、右上に盾の印、移動が遅くなる。正面から殴られると数字がおよそ半分、背中から殴られると減らない。誓気が倍の速さでたまる。
8. **不屈の誓い**：`/amemaru admin skill learn @s knight/unyielding_vow 1`、`/amemaru admin skill gauge @s 60` の後、Cを押す（誓気が50減る。金の光の柱が立つ）。`/amemaru admin debug vitals @s 5 50` でHPを少なくしてゾンビに殴られても、10秒の間はHPが1で止まる。
9. **ウィザードへの転職**：結晶を右クリックし、上に「今日は1日目：3日目までは、何度でも無料で変えられます」。ウィザードを選ぶ。見習いの杖を受け取り、スキルは灯火弾（R）と氷結陣（G）だけになる。スキルポイントは11に戻る。杖を持つと、HP 504・MP 315・魔力 43・防御 12。
10. **ウィザードのスキル**：
    - Rを押す：光る弾が尾を引いて飛び、人形に当たると数字（およそ56）。人形の頭上に金の星が1つ回る（星痕）。
    - 人形の足もとを見てGを押す：地面に氷の魔法陣が広がり、6秒残る（雪が舞い、ふちに氷の棘）。人形の頭上に雪の結晶が1つずつ増えていき（凍え）、4つで止まる。
    - 流星群を覚えて（スキルツリーで習得）、人形を見てVを押す：両手を空にかかげるモーション、足もとに魔法陣、狙った地点に星の魔法陣、画面の中央の下に「流星群」の詠唱のバー。移動が遅くなる。2秒後に流れ星が次々に落ち、波紋と爆発、数字（およそ112）。
    - 詠唱中にもう一度Vを押すと、詠唱をやめる（MPは減らない、クールダウンも始まらない。魔法陣が消える）。
11. **進行日と転職の証**：`/amemaru admin day set 4` にしてから結晶を右クリックすると、「転職には「転職の証」が1個要ります（持っている数：0）」と赤い字で出て、選べない。`/give @s amemaru:job_change_token` の後なら選べ、証が1つ減る。`/amemaru admin day set 1` で戻す。
12. **上位職**：`/amemaru admin job promote @s true`。「上位職「星詠み」に昇格しました」。スキルツリーで第3段と奥義（星落とし。Lv30から）が覚えられるようになる。`/amemaru admin level set @s 30` の後、星落としを覚えて使うと、4秒の詠唱の後に大きな星が落ち、画面が揺れる。
13. **やり直し**：白紙の誓約書を右クリック →「もう一度使うと、スキルの習得を戻します（○ポイント）」→ 3秒以内にもう一度で、最初の技だけになる。忘れ水も同じ手順で、ステータスの振り分けが戻る。
14. **保存**：ワールドを出て入り直す。職業・習得・スキル枠・クールダウン（使った直後に出入りすると残りが続いている）がそのまま。`/kill` で死んで復活しても同じ。
15. **LANの2人（後回し）**：Phase 1と同じく、Phase 4（パーティ）の前にまとめて確かめます。確かめること：
    - ナイトが味方を見て盾結び（V）→ 2人の間に金の光の糸が8秒つながる。味方がゾンビに殴られると、ダメージの30%がナイトの頭上に「（肩代わり）」で出て、ナイトの誓気がたまる。
    - ウィザードが味方を見て光の帳 → 味方が光の球に包まれ、HPのバーに金の帯。殴られると「（吸収）」が出て、吸いきると球が砕ける。
    - ナイトの誓いの円陣の中にいる味方は、殴られたときの数字が小さくなる。ナイトが挑発の極意を覚えていると、挑発された敵に味方が殴られても数字が小さくなる。
    - ウィザードが味方を見て魔力の糸 → 味方の頭上に「+40 MP」。
    - ナイトの突進斬り（起点）の後、4秒以内にウィザードの雷鎖か流星群（追撃）を当てる →「連携！」の大きな文字とダメージ+30%。2人とも同じ人だと連携にならない。
    - 盾結びを受けた味方が4秒以内に使ったスキルが +20%（「連携支援」）。
    - 相手のモーションと演出（溜め・障壁の球・城壁の光の壁）が見える。プレイヤーどうしで殴ってもダメージが入らない。
16. **スキルの拡張（ナイト）**：ナイトに戻し（無料の間）、`/amemaru admin level set @s 15`。スキルツリーで、守護の縛鎖・受け流し・誓いの円陣、剛剣の溜め斬り・誓気解放・跳躍斬を覚え、枠に入れる（ポイントが足りなければ `/amemaru admin skill learn` で）。訓練人形を3体置く。
17. **縛鎖**：離れた人形を見て使う。鎖が伸びて人形が手前（2ブロック）まで引き寄せられ、頭上に赤い光（挑発）。
18. **溜め斬り**：キーを押したままにする。剣を肩の後ろへ引くモーション、足もとの陣が広がり、光の筋が体に集まる。画面の中央の下の溜めのバーが橙から白へ。1.5秒で光と音、「最大！」。離すと前を大きく薙ぐ光の弧と波紋、人形の頭上にひびの入った盾（防御崩し）と回る星（よろめき）。途中で離すと弱く、印も付かない。溜めきって1秒待つと自動で放つ。
19. **受け流し**：サバイバル・夜にしてゾンビを呼ぶ。ゾンビが腕を振る直前に受け流しを使う。体の前が白く光り、殴られてもHPが減らず、「受け流し！」の大きな文字と、ゾンビへの反撃（数字とよろめき）、誓気+15。クールダウンが半分になる。背中から殴られると受け流せない。
20. **誓いの円陣**：足もとに青い魔法陣と光のドーム、ふちに光の壁が6秒。中でゾンビに殴られると数字が小さくなり（−15%）、ゾンビは自分を狙い続ける。
21. **誓気解放**：`/amemaru admin skill gauge @s 100` の後、人形の目の前で使う。金の太い光が人形を貫き、大きな数字（攻撃の5倍ほど）。誓気が0になり、自分のHPが少し戻る（HPを減らしておくと分かりやすい）。
22. **跳躍斬**：10ブロックほど先の地面を見て使う。大きく跳び、着地で剣を叩きつけるモーション、橙の波紋と地面のかけら、画面が揺れる。周りの人形によろめき。高い所から跳んでも落下のダメージを受けない。
23. **スキルの拡張（ウィザード）**：ウィザードに戻し、灯火の連弾・光の帳・星爆・氷柱・凍てつく波動・雷霆を覚えて枠に入れる。人形を3体置く。
    - 灯火の連弾：押したままにすると、体のまわりを回る灯火が1つから5つへ増える。離すと扇に5発。人形の頭上の星（星痕）が増える。
    - 星爆：星痕のある人形に向けて使う。人形が金の星の光で弾け、星痕が消える。星痕が多いほど数字が大きい。星痕のある敵がいないと「スキル失敗（星痕のある敵がいない）」でMPは減らない。
    - 氷結陣で凍えを3〜4つ重ねてから凍てつく波動：氷の棘が輪に突き出し、人形が氷の塊に包まれる（凍結・「凍結！」）。続けて氷柱：氷の槍が飛び、凍結した人形が氷のかけらを散らして砕ける（「砕けた！」と大きな数字）。
    - 雷霆：狙った地点に雷の魔法陣、0.4秒後に空から稲妻、人形のまわりに小さな稲妻（感電）。続けて雷鎖を感電した人形に使うと、太い紫の稲妻が5回跳ぶ。
    - 光の帳：味方がいないと自分が光の球に包まれる（三人称で見える）。HPのバーに金の帯と「+量」。
24. **状態の見た目だけを確かめる**：`/amemaru admin debug status @e[type=amemaru:training_dummy] chill 4`（brand 3・shock 8・armor_break 6・freeze 3 なども）。
25. **奥義を選ぶ**：`/amemaru admin level set @s 30`、`/amemaru admin job promote @s true`。スキルツリーの「奥義」のつまみに、「守護の奥義」（不落の城）と「剛剣の奥義」（天断ち）が左右に並ぶ。前提（城壁の構え・溜め斬り）を覚えると、どちらも「習得する（5SP）」が押せる。天断ちを覚えると「選んだ奥義」と出て、不落の城は暗くなり、ボタンに「もう一方の奥義を選んでいる」。白紙の誓約書を使うと、どちらも選べる状態に戻る。
26. **天断ち**：人形を3体、前に並べて使う。1秒の構えの間、頭上に光の大剣が上から形づくられ、地面に断つ向きの印（向きを変えると印も回る）。構えが終わると大剣が前の地面に突き立ち、切り口が14ブロック先まで走って光の柱が順に噴き上がる。線の上の人形すべてに大きな数字、防御崩し（頭の上にひびの入った盾・防御 20→15）。断った人形1体につき誓気+10。
27. **氷華の檻**（ウィザードに替え、上位職にして覚える）：人形の足もとを狙って使う。2秒の詠唱の間、狙った所に氷の陣と冷気の渦、半ばで小さな氷のつぼみ。詠唱が終わると杖から冷気の帯が伸び、氷の花が一斉に咲く（真ん中の大輪・花びらの輪・ふちの氷柱の檻）。人形はすぐ凍結し（「凍結！」）、花が残る8秒の間、凍えが重なり続ける。続けて氷柱を撃つと砕ける。

## 7. 世界観・物語の追加【補完】

物語の向き（ストーリー）を変えるものではありません。気になるところがあれば直します。

- **誓約の結晶**：冒険者ギルドの奥にある、大結晶のかけら。手を当てて誓いを立てると、大結晶を通して仲間の糸とつながり、職業の「接続技能」を授かる。職業を変えるときも、ここで誓い直す。
- **転職の証**：大結晶に誓いを結び直すための、ギルドの印。お試しの3日間の後は、これがないと誓い直せない。
- **見習い装備**：誓いを立てた冒険者に、ギルドが貸し出す最初の武具。名前が刻まれていて、ほかの人には渡せない（取引できない）。
- **忘れ水**：結晶の泉の水。飲むと、体に覚えさせた力の配り方（ステータスの振り分け）を忘れる。**白紙の誓約書**：結んだ技の糸をほどき、最初の誓いだけを残す紙。
- **訓練人形**：ギルドの訓練場の、麻袋とわらの人形。胸の結晶が、受けた技の強さを数字で映す。
- **誓気**（ナイト）：仲間をかばったときに、糸を通って戻ってくる仲間の思い。これがある間、ナイトは倒れない誓いを立てられる。
- **星灯（ほしあかり）**（ウィザードの流派）：灯火と星の光を糸に灯す魔法。星詠みへの道の始まり。**星痕**は、灯火が敵に残す小さな星の印で、星詠みの呼びかけで一斉に弾ける。
- **結びの鎖**（縛鎖）：盾の縁に結ばれた、誓気でできた鎖。仲間を狙う敵を、自分の前へ引き戻す。
- **誓いの円陣**：誓いの盾を地に立てると、大結晶の光が円を描く。円の中の仲間は守られ、円の中の敵はナイトから目を離せない。
- **光の帳**：星の光を薄い布のように織った守り。受けた攻撃の力を吸い、吸いきるとガラスのように砕ける。
- **天断ち**（ナイトの剛剣の奥義）：仲間と結んだ誓いの糸を空へ束ねると、糸は光の大剣の形になる。誓盾の騎士は、守るための誓いを、ただ一度だけ斬るための誓いに変えて振り下ろす。断ったものの重さは誓気となって戻ってくる。
- **氷華の檻**（ウィザードの氷結の奥義）：凍えの糸を地の下に張りめぐらせ、一度に花を咲かせる術。花びらは敵の足を、ふちの氷柱は逃げ道をふさぐ。星詠みのうち、星を落とすより「止める」ことを選んだ者の奥義。
- 奥義はどちらも大結晶との誓いの深さで開くため、**一人が結べる奥義の糸は1本だけ**、という決まりにしました（2つから1つを選ぶ理由）。選び直すには、白紙の誓約書で糸をほどく。
- 上位職の名前（誓盾の騎士・星詠み）はPhase 0-Aのとおりです。奥義は、Phase 0-Aの不落の城・星落としに、天断ち・氷華の檻を足しました（19章）。
