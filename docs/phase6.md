# Phase 6：経済とまわりの仕組み（その1：街と経済）

Phase 0-B 13章の「Phase 6で作るもの」（残りの職業、ギルド、クエスト、店、経済、倉庫、フリマ、主要NPC、古代記録、厳選、称号。確認の目安は「取引・倉庫・厳選が一通り動く」）を、11月22日のご指示（改善案と追加の機能）と合わせて、4つに分けて作ります。この文書は、その1番目「**街と経済**」の分です。

| 順 | 中身 | 状態 |
| --- | --- | --- |
| 1 街と経済 | ノットの受け渡し・商店街の店・個人倉庫・フリーマーケット・東と南の門を閉じる・塔への道の塀 | **この文書** |
| 2 職業とスキル | 残りの職業（ヒーラー・アーチャー・ローグ・モンク）と演出、全職業のスキルとパッシブを増やす、モンクのコンボ | `docs/phase6_jobs.md` |
| 3 ギルドとクエスト | ギルド・クエスト・主要NPC・古代記録・称号（寄付で露店の区画を増やす・最初の取引の称号・対面の取引のコネクション） | `docs/phase6_guild.md` |
| 4 厳選と決闘 | アクセサリーの厳選・強化・分解・依頼台・決闘（決闘場・観戦・耐久が減らない）・工房の作業台を MOD の作業台に | `docs/phase6_refine.md` |

カジノ（ルーレットなど）は Phase 7 で、11月22日のご指示のとおり「建物の所で右クリック → 画面で掛け金を決める → 始まる」の形で作ります。

作ったものの中心は次のとおりです。

- **ノットの受け渡し**（11月22日に決定）：ステータスの画面の「渡す」か、しゃがんで相手を右クリックで、渡す画面が開きます。相手を選び、額を決めて、確かめてから渡します。
- **通貨の記録**（Phase 0-A 20章）：ノットの出し入れをすべて、発行（世界に増える）・回収（世界から消える）・移動（人から人へ）に分けて、進行日ごとに記録します。管理者は `/amemaru admin economy` で、世界にあるノットの合計と、日ごとの発行・回収・移動を見られます。
- **商店街の店**（Phase 0-A 7章）：13軒（雑貨屋＋暮らしの店12軒）のカウンターの呼び鈴を右クリックすると、「買う・売る」の画面が開きます。雑貨屋（マルタ・ポム）は回復薬と暮らしの品を売り、塔の素材を買い取ります。ほかの12軒は暮らしの品を売り、自分の店の品を買い戻します（塔の素材の買い取りは雑貨屋だけ。11月20日に決定）。料理屋は寄付で開くので、まだ店を開きません。
- **回復薬（小）・マナ水（小）**：右クリックで、すぐにHP（最大の25%）・MP（最大の30%）が戻ります。
- **個人倉庫**（Phase 0-A 20章）：倉庫の受付棟のカウンター（契約・拡張の呼び鈴と、受け取り口の包み）と、地下の小部屋の封印箱で開きます。契約500ノット（27枠）、拡張は 5,000／20,000／60,000／150,000 で5ページ（135枠）まで。名前でさがす・並べ替え・受け取り箱（市場で買った品などが届く）。
- **フリーマーケット**（Phase 0-A 20章）：2日目に開きます。出品はすべて1つの台帳に載り、「市場の手帳」（ギルドの受付のリリアがくれる）で街のどこからでも「取引所」を開けます（さがす・出品する・出品中・売上と履歴・露店）。フリーマーケットの市場監督フィン・ロッソの小屋を右クリックすると取引所が開き、露店の区画を借りられます。借りた露店は、屋根の上に店名、台の上に出品した品が浮かんで見え、露店を右クリックした人はその露店の品だけを見て、売り手の手数料が半分で買えます。
- **東門と南門を閉じる**（11月22日に決定）：外へ続く道の先に作る場所がないので、門の口の外の面にダークオークの門扉をはめました（門の建物と塔は残す）。外へ続いていた土の道もなくしました。
- **塔への道の塀**（11月22日に決定）：北門を出た塔前広場と塔の入口は城壁の外なので、両わきと裏に塀を立てて、野原へ出られないようにしました。

### フリーマーケット

| 項目 | 決めたこと |
| --- | --- |
| 開く日 | 2日目（`openDay`）。それより前は、取引所を開いても「2日目に開きます」 |

| 店名 | 12文字まで（`stallNameMax`）。飾りの記号（§）は消す。NGワード（`ngWords`）は＊で伏せる。管理者は隠せる |
| 露店の見た目 | 屋根の上に店名と「区画 N・出品 n 点」、台の上に新しい出品から最大3つの品を小さく回して浮かべる。どちらも、見る人の画面で描く（世界のブロックは変えないので、街の直しの書き出しに入らない） |
| 露店の画面 | 借りられている区画のブロックを右クリックで、その露店の品だけ。空き区画は「市場監督の小屋で借りられます」 |

| 最初の取引 | 売り手と買い手を控え、その3の限定称号「市場の開拓者」を2人に渡す（いない人には次に入ったときに） |
| 対面の取引のコネクション | コネクション（CP）の仕組みができたら足す（露店の来客の数は数えている） |

## 3. ゲームの中での使い方

- **ノットを渡す**：［K］でステータスの画面を開き、所持金の横の「渡す」。または、しゃがんで相手を右クリック。
- **店**：商店街の店に入り、カウンターの真ん中の小さな呼び鈴を右クリック。
- **回復薬**：雑貨屋で買い、手に持って右クリック。
- **倉庫**：倉庫の受付棟のカウンターの呼び鈴（契約・拡張）を右クリックして契約 → 受付棟か地下の小部屋の封印箱で開く。
- **フリーマーケット**（2日目から）：
  - ギルドの受付のリリアに話しかけ、「市場の手帳がほしい」→ 手帳を右クリックで取引所。
  - 「出品する」：左の持ち物から品をクリック → 数と1個の値段（はじめは相場）→「出品する」。
  - 「さがす」：名前・分類・並びで絞り、品をクリック →「買う」→ 確かめて「買う」。品は倉庫の受け取り箱に届く。
  - 「売上と履歴」：「受け取る」で売上を所持金へ。
