# Phase 5：縦切り版（コネリア・塔の1階・ボス・NPCとの会話・召喚から始まるオープニング・進行日と階の解放）

Phase 0-B 13章の「Phase 5で作るもの」（縦切り版：コネリア、1階、ボス1体、NPCとの会話、召喚から始まるオープニング、進行日と階層の解放（管理者）、マップ（コネリアの一部と1階））を作りました。確認の目安は「**初めてのログインから1階のボスまで、通して遊べる**」です。

11月21日のご指示も入れています。

- **階層ごとのマップは結構な広さで**：1階「始まりの草原」は **384×384**（構造物の区画 48×48 を 64 個）です。
- **ボスはボス部屋として**：1階の北の真ん中に、円い「草原の主の広間」（半径30。列柱の回廊と外の壁）を作り、南の門を「封印の光の幕」でふさいでいます。3本の石柱を起動した人だけが通れ、戦いが始まると幕が閉じます。
- **コネリアに民間の家や装飾用のオブジェクトを**：11の施設のまわりを、家50軒・資材倉庫3棟・城壁と3つの門・角の塔4つ・結界の柱8本・中央広場の大結晶・灯り・案内板・小広場と井戸・裏庭の木と花の畑で埋めました（街並み）。
- **民間の家は入れないので内装は作らない**：家の扉は手で開かず（鉄の扉と同じ決まり）、中は空洞です（暗くならないよう、見えない灯りを1つ置く）。建築の文書の「ほかの家も入れる部屋を1〜2つはそろえる」は、このご指示で入れないことにしました。
- **オープニングはプレイヤー一人ひとりの画面で、ラグなどで入るのが遅れても弊害がないように**：その人のまわりが読み込めてから、その人の画面だけで、その人の速さで流します（下の「オープニング」）。

作ったものの中心は次のとおりです。

- **召喚から始まるオープニング**：初めてログインした人は、大結晶のそばで目覚めます。暗い画面に大結晶の声「……み、つけ……た」→ 光が戻り、大結晶を見上げる → リリアが駆け寄る → リリアとの会話（名前を尋ねられ、冒険者名簿に書かれる）→ 職業を選ぶ画面（Phase 0-A 8章・11章の1日目）。
- **NPC 5人**：リリア（冒険者ギルドの受付。職業の登録）・ガルド（ギルドのマスター）・セレナ（結びの教会の司祭）・ドラン（武器工房の親方）・バルド（塔の門番）。右クリックで話せます。会話は日・オープニングの進み・職業で変わります（会話11）。
- **会話の画面**：名前と肩書き、表情の変わる顔、吹き出し、選択肢（数字キーかクリック）、これまでの会話のログ（L）。
- **はじめの手引き**（画面の右上）：名簿 → 職業 → 塔の門 → 1階 → 石柱 → ボス、の6段。
- **進行日と階の解放**：N日目にN階が開きます（`progression/days.json`）。管理者は日を進める・階をすぐ開く・カウントダウンで開く・閉じる・予告を出す、ができます。塔の入口の「塔の灯り」と札が、開いた階と次の予告に合わせて変わります。
- **塔の門**：北門の外の塔の入口の「転移の円」に立つと（門番バルドに話しても）、行く階を選ぶ画面が出ます。開いた階だけ選べます。
- **塔のディメンション** `amemaru:tower`：N階は x = N × 4096 のあたりに建てます（`/amemaru admin map build floor 1`）。
- **1階「始まりの草原」**：丘で囲んだ草原・小川と石橋・古代の道と道標・西の丘と東の遺跡と北西の林の3本の石柱・道標の石板・草原の主の広間。雑魚はツノモフ・石くれ兵（道を巡回）・結晶蜂・欠け牙の狼で、人のいる所の近くだけに湧きます。
- **ボス「草原の主ヴェルドホーン」**：なぎ払い・突進（通り道が地面に光の線で出る）・踏みつけ・角笛（HP50%でツノモフを呼ぶ）。部屋に入った人数でHPが増えます（1人増えるごとに+60%）。誰かが倒れると、ほかの人に起こし方を出します（蘇生のチュートリアル）。倒すと出口の円が開き、2分後にまた現れます。サーバーで最初に倒したパーティは、全員に知らせて記録します（初撃破。戦っている人がいないまま倒れたとき（コマンドで消したなど）は、初撃破にしません）。レアのお守り「草原の角笛」（8%。外れが続くと上がる）。
- **戻る**：1階の入口の「戻りの円」か、ボスを倒したあとの出口の円に2秒立つと、塔の門へ戻ります。
- **結晶の加護**（管理者）：その階のボスに与えるダメージを +5% ずつ、最大 +20%（Phase 0-A 11章）。
- **記憶の再生**：中央広場の「記憶の石」を右クリックすると、自分が見た演出と、サーバーで起きた演出を、自分の画面だけで見返せます（物語の処理はしない）。

### 11月22日の改善で決めたこと

**不具合：ボス戦でダウンするとボスが増える（直しました）**

- わけ：塔の敵とボスは「保存しない」（`shouldBeSaved` が false）にしていました。バニラは、保存しない「もの」を区画を降ろすときに捨てずに隠しておき、区画がまた読み込まれると戻します。そのため、ボス戦でダウンして教会へ戻る（部屋の区画が降りる）→ また来る、で古いボスが戻り、部屋が新しいボスを出して2体になっていました。
- 直し：「保存はするが、中身を書かない」（`save`・`saveAsPassenger` が false）にして、区画を降ろすと消えるようにしました。さらに、部屋が持っていないボス（古いボス）は見つけたらすぐ消し、部屋がボスを出すときは、まわり80ブロックの同じ部屋のボスを先に消します。自動テスト `transientEnemiesAndStaleBoss`。

**NPCのモデル【補完】**

- 街の5人（リリア・ガルド・セレナ・ドラン・バルド）を、凹凸のある立体の GeckoLib のモデルにしました。モデル・絵・動きは `tools/artgen/make_npc_models.py` で作ります（絵は2倍の細かさの 256×256）。

## 3. 遊び方

### オープニング

1. 初めてログインすると、画面が暗いまま「……」と出ます（まわりを読み込んでいる間）。
2. 大結晶の声 → 光が戻り、大結晶を見上げます → リリアが駆け寄ってきます。
3. リリアとの会話。名前を尋ねられたら、選択肢を選びます。名簿に名前が書かれると、オープニングは終わりです。
4. 最後まで読むと、職業を選ぶ画面が開きます。選んだら、はじめの手引き（右上）に沿って進みます。

### NPCと会話

- NPCを右クリックすると話せます。会話の画面は、クリックか Space・Enter で次へ、1〜4 のキーかクリックで選びます。L でこれまでの会話を見返せます。Esc で閉じます。
- 会話がまだないNPCは、名前だけの短いあいさつをします。

### 塔へ

1. 中央広場から北の塔の道を進み、北門を出ると塔前広場と塔の入口です。
2. 入口の広間の「転移の円」に立つと（門番のバルドに話しても）、行く階を選ぶ画面が出ます。開いている階だけ選べます。
3. 1階の入口（南の円い台）に着きます。古代の道を北へ進むと、草原の主の広間です。

### 1階

- 3本の石柱（西の丘・東の遺跡・北西の林）の前の台にある「古代の石柱の核」を右クリックすると起動します。3本そろうと、広間の南の門の光の幕を通れます。
- 門の前の広場の「道標の石板・一」は、近づくか右クリックで読めます。
- 広間に入り、ヴェルドホーンに近づくと戦いが始まります。技の前は、当たる所が地面に赤く出ます（前の扇・前の帯・後ろの扇・通り道の線・まわりの円・降りる所の円・足もとの円）。誰かが倒れたら、しゃがんで起こします（Phase 4）。
- 自分が倒れたら、起こしてもらうのを待つか、［H］を3秒押し続けてリタイアし、教会へ戻ります（30秒たつと自動で戻ります）。
- 倒すと、広間の南の出口の円が開きます。円に2秒立つと塔の門へ戻ります。入口の台の戻りの円からも戻れます。

### 記憶の再生

- 中央広場の「記憶の石」を右クリックすると、見返せる演出の一覧が出ます（2分の間に選ぶ）。

## 7. マップ（街並みと1階）

- 街並み：`python3 tools/mapgen/build_city.py`（`town/t<i>_<j>.nbt` 31区画）。施設の書くマスを避けて作り、施設より先に置きます。暗くて湧ける所は、見えない灯り（`minecraft:light`）で埋めます。`python3 tools/mapgen/check_city.py` で、街並みを入れた街全体を確かめます（城壁の中の地面・道・建物の中・広場に、暗くて湧ける所は0。道の真ん中の歩く高さに物はない。中央広場を囲む最初の1列は棟18まで。中央広場から行き帰りできない所は増えていない）。
- 1階：`python3 tools/mapgen/build_floor1.py`（`map/floor1/p<i>_<j>.nbt` 64区画と `floors/floor1.json`）。ゲームの中では `/amemaru admin map build floor 1` で建てます。
- くわしくは `docs/map_style.md` の「街並み」「塔の1階」と、`tools/mapgen/README.md`。
