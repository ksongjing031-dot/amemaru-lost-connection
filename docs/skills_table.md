# スキルの一覧（全職業）

`tools/datagen/build_jobs.py` が書き出す表です（数値はデータパックの JSON と同じ。段は Lv1・5・10・15・21・26、奥義は上位職・Lv60）。
【新】は11月22日・11月24日のご指示（スキルとパッシブを増やす）で足したもの、それ以外は Phase 0-A 19章の設計のとおりです。
連携は、起点・追撃・支援（Phase 0-A 13章）。モンクの【起】【継】【極】は連撃（Phase 6 その2）。
MPは、ゲームの中で使う値。近接職（ナイト・ローグ・モンク）は、覚えられるレベルが高いスキルほど消費MPを増やす（11月23日。職業の `skill_mp_per_level`、1レベルにつき +5%。数えるのは Lv30 まで）。
11月24日から、スキルとステータスはスキルツリー（`skill_trees/<職業>.json`）で一緒に取ります。すべては取れないので、ビルドによって使えるスキルが変わります。段階は最大5段（第5段は上位職から）、段階ごとのポイントは 1・1・2・2・3。
11月26日から、ウィザード・アーチャー・ヒーラーの攻撃のスキルは、放ったあと少しの間、足がほぼ止まります（硬直。職業の `attack_lock`。ウィザード 0.4〜1.2秒・アーチャー 0.25〜0.6秒・ヒーラーは攻撃の鈴だけ。移動の技と、仲間を支える技にはつきません）。スキルごとの秒は [`docs/phase8_1126.md`](phase8_1126.md) の「遠距離職の硬直」。

11月27日から、どの職業にも「覚醒」があります（ご指示「どの役職もどこかのタイミングで強くなるタイミングを（パワースパイク）」【補完】）。そのレベルになると、スキルポイントを使わずに自動で効きます。職業の `awakenings`。くわしくは [`docs/phase8_1127.md`](phase8_1127.md) の「覚醒」。
