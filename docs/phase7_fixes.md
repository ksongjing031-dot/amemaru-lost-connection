# Phase 7 のあとの直し（11月23日）

11月23日にいただいた6つの改善点のうち、Phase 7 までに作った物の直し3つを、ここで行いました。残りの3つ
（ダンジョンは一層上がるたびに広く・複雑に・難しく、後半はかなりの時間がかかってもよい、少し進んでからは職業ごとの
固有防具と武器）は、Phase 8 で作ります（[`docs/phase8.md`](phase8.md)）。

| ご指示 | 直したこと |
| --- | --- |
| ジゼルの見た目をもっとしっかりとした見た目のイメージです | 大人びた、きちんとした支配人の姿に描き直した（下の1） |
| 仕立て屋の机もほかの店と同じ机の形にする | 「布と仕立て」のカウンターを、ほかの12軒と同じ1段低い天板にした（下の2） |
| 色々な店があるがどこで使うかわからないものが多いので実用的なものを置く | 使い道のない品を外し、どの品にも使い道を付けて、店の画面と説明文に出した（下の3） |

## 1. ジゼルの見た目

11月23日の決定（重要なNPCでも、立体モデルは要らず、人の形のスキンと顔の絵で十分）のとおり、スキンを描き直しました
（`tools/artgen/make_facility_npcs.py` の `gisele()`）【補完】。

- 黒い仕立ての上着に、紫の胴着と白い襟飾り（紫の石のブローチ）、二列の金ボタン、腰の金の飾り帯。肩と袖口に金の縁、黒い長い手袋
- たてのひだのある紫の長いスカートに金のすその縁、金の留め金の黒い靴
- 黒髪は高くまとめて金の櫛で留め、前髪は右へ流す（前の小さな帽子はやめた）
- 顔は、細い眉と切れ長の目（紫の瞳）、鼻すじの影、閉じた赤い唇、左の目もとのほくろ。笑い顔は、目を細めて口もとだけほころぶ

## 2. 布と仕立ての机

商店街のカウンターは、11月21日のゲームの中の直しで12軒が1段低い形（ダークオークの上付きの半ブロックの天板。高さ1）に
なりましたが、「布と仕立て」だけは直しがなく、もとの形（丸太の上にハーフの天板。高さ1.5）のままでした。

- `tools/mapgen/build_market.py` の `counter()`（もとの形）を、ほかの12軒と同じ形にし、呼び鈴は天板の上のマスに置く
  （`amemaru:shop_counter[slab=false]`）。直しのファイルは変えていない
- 寄付で開く料理屋のカウンター（`market_restaurant_open`）も同じ形になる
- 前の版の jar で街を建てたワールドでは、`/amemaru admin city build` で建て直すと、この形になる

## 3. 店の品を実用的なものに

このModでは満腹度がいつも満ちていて、パンや肉は食べられず、羊毛・種・方位磁石・時計などは、どこにも使い道がありませんでした。
次のように直しました【補完】。

- どこにも使い道のない品（羊毛・糸・羽根・革・ウサギの皮・リード・ガラス瓶・鎖・鉄塊・ハサミ・方位磁石・時計・
  ランタン・たいまつ・ろうそく・ハニカム・種・骨粉・カカオ・カボチャ・ケーキ・ウサギシチュー・本と羽根ペン）を外した
- **食べ物で、すぐに少しHPかMPが戻る**ようにした（右クリック。食べる間の動きは待たない。回復薬と同じ）。食べ物どうしで
  20秒のクールダウン（回復薬とは別）。数値は `data/minecraft/amemaru/consumables/`
- 回復・帰還・修理・灯りの品を足した（下の表）。見た目だけの服を、布と仕立てと革と鞄で売る
- **どの品にも「使い道」を付け、店の画面の2行目と、持ち物の説明文の「使い道：」の行に出す**（言語ファイルの
  `itemuse.<名前空間>.<名前>`。`tools/datagen/build_shops.py` の USES から書き出す。使い道のない品を店に並べると、
  書き出しが止まる）

  パンで最大HPの10%が戻り、食べ物どうしにだけクールダウン／携帯修理具で耐久が30%戻る／灯りの小瓶で灯りが置かれる・

## 確かめ方

1. **ジゼル**：カジノの大広間のジゼルに話しかけ、会話の画面の立ち絵が、黒い上着と紫の胴着の、髪を高くまとめた姿であること。
   「遊び方を聞く」などで笑ったときの顔も
2. **布と仕立ての机**：`/amemaru admin city build` で建て直してから、商店街の北の東の角の「布と仕立て」に入り、カウンターが
   ほかの店と同じ1段低い天板で、呼び鈴が天板の上にあること
3. **店の品**：どの店でも、品の名前の下に使い道（緑がかった字）が出ること。持ち物の説明文にも「使い道：」の行が出ること
4. **食べ物**：HPを減らして（敵に当たるなど）パンを右クリックすると、すぐにHPが少し戻り、20秒はほかの食べ物も食べられないこと
5. **新しい品**：塔の中で帰還の羽根を3秒押し続けると塔の門へ帰ること。携帯修理具で装備の耐久が戻ること。夜に手提げランタンを
   持つと、まわりが明るくなること。灯りの小瓶でその場が明るくなり、90秒で消えること。仕立ての服を着ても守りが変わらないこと
