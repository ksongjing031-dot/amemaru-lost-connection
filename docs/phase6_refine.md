# Phase 6：経済とまわりの仕組み（その4：厳選と決闘）

Phase 6 の4つの分け方（`docs/phase6.md` の表）の4番目「**厳選と決闘**」の分です。Phase 0-B 13章の「厳選」（確認の目安の「取引・倉庫・厳選が一通り動く」の厳選）と、11月22日に決めた**決闘**（決闘場・観戦・耐久が減らない）を作りました。その3で「その4で」と約束した**厳選の回数を称号に数える**（宝石研ぎ・結晶細工師・輝きの探求者、誰かのための槌）も入っています。

作ったものの中心は次のとおりです。

- **厳選**（Phase 0-A 21章「厳選の操作とコスト」）：装飾工房の作業台の画面に「厳選」のタブ。サブの**数値だけ振り直す**・**種類ごと振り直す**・残したいサブを**固定**する。振り直すほど費用が上がり、日が変わると上がった分が半分に戻ります。結果のうち、前と変わった行が光ります。
- **強化**：＋12 まで、失敗なし。1段ごとにメインが +5%。＋3・＋6・＋9・＋12 で、サブが4つ未満なら新しいサブが一つ加わり、4つあればランダムな一つが「1回分」伸びます。
- **分解**：いらないアクセサリーを素材に戻す。★と強化の段が高いほど多く戻り、★4以上は「澄んだ残響」も出ます。2回押して決めます。
- **依頼台**（21章「装飾師による依頼の厳選」）：持ち主がアクセサリーと素材・ノット・手数料を預けて依頼を出し、装飾師のプレイヤーが受けて、持ち主の素材で厳選します。結果はそのたび持ち主に届き、目標に届くか、持ち主が「ここで止める」を押すか、回数の上限で終わります。品物はサーバーが預かるので、持ち逃げはできません。
- **決闘**（11月22日に決定）：ほかのプレイヤーに申し込み、受けると1対1で戦う。街の中では戦わず（街の中はPvP不可【確定】）、**決闘場**へ移って戦う。ほかのプレイヤーは**観戦**できる。決闘の間は、武器や防具などの**耐久は減らない**。倒れる一撃を受けると、倒れずに負けになります。
- **厳選の素材**（21章「厳選素材」の名前のとおり）：研磨粉・留め糸・揺らぎの結晶・澄んだ残響（残響の欠片は前から）。
- 街の3つの工房に置いていた**鍛冶台（MOD の作業台の代わり）を、MOD の作業台に置き替え**ました（`docs/map_style.md` で「地図を組むときに置き替える」としていた所）。装飾工房のカウンターの作業台で、厳選も依頼台も使えます。

## 2. このPhaseで決めた細かいこと（【補完】・【提案】）

設計書に書いていない所は、次のように決めました。変えたいときは教えてください。費用と分解の表は `data/amemaru/amemaru/accessory_rules/default.json` の `refine` で、倍率や日数はサーバーの設定（`amemaru-server.toml` の `[refine]`・`[duel]`）で変えられます。

### 厳選（【補完】）

| 項目 | 決めたこと |
| --- | --- |
| ノットの章の倍率 | 表のノットは第3章の目安なので、**アクセサリーの章**で倍率をかける：第1章 ×0.4・第2章 ×0.7・第3章 ×1.0・第4章 ×1.3（第1章の数値だけの振り直しは 800 ノット） |
| 振り直すほど高くなる分 | 上乗せはノットだけにかけ、素材の数は変えない。上乗せはアクセサリーに残る（倉庫やフリマを通しても同じ）。日が変わるたびに半分（31日たてば 0） |
| 固定の倍率 | ノットだけにかける。留め糸は固定の数で 1・2・4 本 |
| 固定できる数 | サブの数−1 まで（多くて3つ）。全部は固定できない |
| config の倍率（`refine.costMultiplier`） | 素材とノットの両方にかける（素材は切り上げ） |
| 熟練度の値引き | 装飾師（生産職を装飾師にしている人）なら、自分の厳選・強化でも、依頼の厳選でもノットが安くなる（熟練度1ごとに−2%、最大−20%）。素材は減らない。結果の確率は変わらない |
| 振り直しの結果 | 前と変わった行を光らせる。固定したサブには〔固定〕、強化で伸びたサブには「×2」などの回数を出す |
| 作り直し | 表の「作り直し」は、前からある「作る」のタブ（装飾師だけ）。厳選・強化・分解は、生産職にかかわらず誰でもできる（21章の役割の表の「制作は装飾師のみ」から） |

### 強化・分解（【補完】）

| 項目 | 決めたこと |
| --- | --- |
| 強化の費用 | 次の段の数だけ研磨粉（＋5にするなら5つ）と、500×段の数のノットに章の倍率（振り直すほど高くなる分はかけない） |
| メイン +5% | メインの値（表示と強さ）に「1段ごとに +5%」をかける。割合の％の能力は 0.1 刻み、ほかは整数に丸める |
| ＋3・6・9・12 で増えるサブ | メインと今あるサブと違う種類から、その章の抽選表で選ぶ。値は1回分 |
| 分解で戻る物 | 残響の欠片（1＋★の数＋強化2段ごとに1）・研磨粉（強化に使った数の半分）・澄んだ残響（★4は1つ、★5は2つ、完璧ならもう1つ） |
| 分解の確かめ | 2回押す（4秒のうちに）。台の上の品が消えて、素材が持ち物に入る |

### 依頼台（【補完】）

| 項目 | 決めたこと |
| --- | --- |
| 開き方 | 装飾工房の作業台の「依頼」のタブの「依頼台を開く」。工房の画面を閉じてから開くので、台の上の品は持ち物に戻る |
| やり方 | 数値だけ振り直す・種類ごと振り直す・強化の3つ |
| 目標 | なし（回数を使い切るまで）・品質（★○以上）・完璧・ある能力のサブが割合○%以上（50〜100%）・強化（＋○まで） |
| 預ける物 | 品と、回数の上限まで続けたときの素材とノット（振り直すほど高くなる分も入れて、値引きの前）と、手数料。余った分は終わったときに戻す |
| 回数の上限 | 1〜50（設定の `commissionMaxAttempts`） |
| 出せる数・受けられる数 | 1人が出せるのは3つまで（`commissionMaxOpen`）。装飾師が同時に受けられるのは3つまで |
| 受ける人 | 装飾師（生産職を装飾師にしている人）で、装飾工房の作業台の近くにいる人。自分の依頼は受けられない |
| 厳選の仕方 | 1回ずつか、5回まとめて。目標に届いたら、そこで止まる |
| 終わり方 | 目標に届く・回数を使い切る・持ち主が止める・受付中のまま3日たつ（`commissionExpireDays`）。受けた装飾師が手放すと、受付中に戻る |
| 手数料 | 装飾師へ。ただし1回も厳選しないで終わったとき（受付中の取り下げなど）は持ち主に戻す |
| いない人への受け渡し | 次に入ったとき（か、依頼台を開いたとき）に渡す。持ち物に入らない物は受け取り箱へ |
| 装飾師に残る物 | 厳選の回数（宝石研ぎなど）・依頼実績（誰かのための槌）・縁帳の「依頼」 |
| 冒険日誌 | 依頼で初めて「完璧」が出たとき（サーバーで最初の1回） |

### 決闘（【補完】）

| 項目 | 決めたこと |
| --- | --- |
| 申し込み方 | パーティの画面の「決闘」から決闘の画面を開き、ログインしている人に申し込む（`/amemaru duel challenge <人>` でも）。申し込みは60秒で消える（`challengeSeconds`） |
| 申し込める所 | 街の世界（地上）にいるとき。オープニングや物語のイベントの最中、倒れているときはできない |
| 決闘場 | 塔の空間の、どの階とも離れた所（x −6000、z −6000 から東へ64ずつ）に、同じ形の決闘場を4つ（`arenas`）。19×19の戦う場（見えない壁と天井）と、まわりの3段の観客席。初めて使うときに建てる |
| 始まり | 二人は東と西の印へ移り、体力と魔力が満ち、強化・弱化が消える。3・2・1・始め！ |
| 時間 | 3分（`seconds`）。時間切れのときは、HPの割合が多い方の勝ち（同じなら引き分け） |
| 勝ち負け | 倒れる一撃を受けると、体力1で止まって負け（倒れた状態にも、死にもならない）。降参・戦う場から出る・ログアウトも負け |
| 決闘の間 | 相手にだけ攻撃とスキルが届く。ほかの人（観客も）とは、互いに届かない。仲間への回復・強化も届かない。武器と防具の耐久は減らない。回復薬などは使えない（`allowPotions`） |
| 終わったあと | 4秒後に、もとの場所に戻る。体力と魔力も決闘の前に戻り、強化・弱化は消える |
| 観戦 | 告知の［観戦する］か、決闘の画面から。北か南の観客席へ移る。「やめる」で、もとの場所へ戻る |
| 告知 | 決闘が始まると、サーバー全体に「決闘場で、○○と○○の決闘が始まる！［観戦する］」（`announce`） |
| 残る物 | 戦績（勝ち・負け・引き分け。決闘の画面に出る）と、縁帳の「決闘」 |
| バニラの pvp | サーバーの `server.properties` の `pvp` が false だと、プレイヤーどうしの攻撃をバニラが止めてしまうので、決闘があるあいだだけ入れ、なくなったら戻す。ほかの人どうしの攻撃は、このModの `allowPvp`（初期値 false）で止まったまま |

## 3. ゲームの中での使い方

- **厳選・強化・分解**：装飾工房のカウンターの作業台（右クリック）→ タブを選び、持ち物のアクセサリーをシフトを押してクリックで台に置く。固定は、サブの行の右の錠をクリック。
- **依頼を出す**：作業台の「依頼」のタブ →「依頼台を開く」→「依頼を出す」のタブ。品・やり方・固定・目標・回数・手数料を決めて「依頼を出す」。出した依頼は「自分の依頼」のタブで見られ、「ここで止める」で止められる。
- **依頼を受ける**（装飾師）：依頼台の「受付中」のタブで選んで「受ける」→「受けた依頼」のタブで「1回厳選する」「5回まとめて」。
- **決闘**：パーティの画面（U）の「決闘」→ 相手の名前の横の「申し込む」。申し込まれた人は、決闘の画面の「受ける」か、チャットの［受ける］。
- コマンド：`/amemaru duel`（決闘の画面）・`/amemaru duel challenge|accept|decline <人>`・`/amemaru duel watch <番号>`・`/amemaru duel leave`（降参・観戦をやめる）・`/amemaru commission stop <番号>`。

## 4. 管理者のコマンド（`/amemaru admin …`）

| コマンド | 働き |
| --- | --- |
| `duel list`・`duel stop <番号>` | 今の決闘（止めると引き分け） |
| `duel arena [番号] [above]` | 決闘場へ行く（above で上から見る）。まだ建っていなければ建てる |
| `commission list`・`commission cancel <番号>` | 依頼の一覧（預かっているノットの合計も）・依頼を取り下げる（品と預かり分は持ち主へ） |

config（`amemaru-server.toml`）：
- `[refine]`：`costMultiplier`（厳選・強化の費用の倍率。素材とノットの両方）・`commissionExpireDays`（受付中の依頼が消えるまでの日数）・`commissionMaxAttempts`（依頼の回数の上限）・`commissionMaxOpen`（1人が出せる依頼の数）
- `[duel]`：`enabled`・`seconds`（決闘の時間）・`challengeSeconds`（申し込みが消えるまで）・`arenas`（決闘場の数）・`announce`（始まりの告知）・`allowPotions`（決闘の間に回復薬などを使えるか）

## 6. 自動の確認

GameTest に `RefineDuelGameTests` の7つを足しました。テストの中の仮のプレイヤー（FakePlayer）はサーバーの一覧にいないので、依頼の受け渡しは「いない人には次に入ったときに渡す」の道を確かめ、決闘はテスト用の一覧で相手を見つけます。

| テスト | 確かめること |
| --- | --- |
| `refineDefinitionsLoad` | `refine` の表のとおりの費用・固定・上乗せ・強化・分解・値引き。素材の品がある |
| `refineRerollAndLocks` | 第1章の費用（800・1,600 ノット）と値引き・固定（3つまで。費用 ×1.5〜×4 と留め糸）・数値だけの振り直し（種類と固定した行は変わらない）・種類ごとの振り直し（固定は変わらない・重ならない）・振り直すほど高くなる分（3回で +30%、日が変わると半分、+200% で止まる） |
| `refinePaysAndCounts` | 素材とノットを払う・厳選の回数を数える・品に +10% が残る・素材やノットが足りなければできない |
| `refineEnhanceMilestones` | 強化の費用（研磨粉×段・500×段×章）・失敗なし・メイン +5% ずつ・＋3 でサブが増える・4つあれば ＋12 でどれかが1回分伸びる |
| `refineDismantleYield` | 分解で戻る素材（★・強化・完璧） |
| `commissionFlow` | 預ける（品・素材・ノット・手数料）・自分の依頼は受けられない・装飾師が受けて回数の上限で終わる・値引きの分が持ち主に戻る・手数料・依頼実績と縁帳・受付中の取り下げで全部戻る |
| `duelRules` | 申し込み・受ける・相手どうしだけ攻撃が届く・ほかの人とは届かない（回復・強化も）・バニラの pvp が決闘のあいだだけ入る・耐久が減らない・倒れる一撃で勝ち負け（HPが1残る）・もとのHPに戻る・戦績。仮のプレイヤーは `hurt` で傷を受けないので、攻撃を止める決まりと倒れる一撃の決着をそのまま確かめる |
