## ひとり確認モード【補完】

何人かで同時に動かす仕掛けを、ひとりでも動かせるようにする、管理者だけの切りかえです。仕掛けの決まり（何を・どの順に・どこで）は
変えず、「何秒のうちに」と「何人で」だけをゆるめます。サーバーを止めると切れます（保存しないので、ふだんの遊びに残りません）。
入れたとき・入っている間にログインしたときは、全員のチャットに知らせが出ます。

| 階 | 仕掛け | ふだん | ひとり確認モード |
| --- | --- | --- | --- |
| 2階 | 迷いの森のこだま | 4秒で返る | 10秒で返る（鳴らしてから離れる間がある） |
| 3階 | 水門のハンドル（2つ） | 3秒のうちに両方 | 120秒のうちに両方 |
| 3階 | ボスの部屋の排水のハンドル | 3秒のうちに両方 | 30秒のうちに両方 |
| 5階 | 接続判定・切断判定 | ひとりなら判定しない（切断判定は2人以上で出る） | ひとりでも判定する。練習用の人形を仲間に数える |
| 8階 | 入江の鐘・湖の鐘 | 90秒・240秒 | 2倍 |
| 8階 | 薄氷 | 2人で割れる | 人形をそばに置けば、ひとりでも割れる |
| 8階 | 静寂の帳の鳴り石 | 3秒のうちに2つ（帳は20秒） | 30秒のうちに2つ（帳は40秒） |

「仲間の代わりの人形」は、前からある練習用の人形（`/amemaru admin dummy`）です。そばに置いた人形を、モードの間だけ人数に数えます
（人形はダメージを受けません）。レイドのボスの「みんなで受ける一撃」も、円の中の人形を人数に数えます（1〜8階のボスは使いません）。

| コマンド | すること |
| --- | --- |
| `/amemaru admin solo on` ・ `off` ・（何もつけない） | 入れる・切る・今の様子 |
| `/amemaru admin solo reset <階>` | その階の仕掛け（迷いの森・水門・壁画・氷像・光の迷路・鐘・祭壇の警戒・割れた薄氷）を朝の形に戻し、自分の石柱・名のある魔物・合言葉の印・宝箱も戻し、ボスを出し直す |
| `/amemaru admin solo ready <階>` | その階のボスの封印の条件を、自分の分まで満たし、ボスの部屋の門の前へ移る |

中では、前からある管理者のコマンド（`floor woods`・`floor floodgate`・`floor murals` など）をそのまま使います。1〜8階の、ボスまでの
仕掛けとボスのギミックを、ひとりで確かめる手順（何をすると、何が起これば正しいか）は [`solo_check.md`](solo_check.md) にあります。

## ボス戦の曲が鳴らない

### わかったこと

- 曲を選んで流すところ（ボスのHPの帯が出ている間・戦っているボス・曲の登録とファイル）は、CIの記録でも動いていました
  （`[amemaru-ci] boss fx (f1): boss=veldhorn track=veldhorn`）。ただ、CIの機械には音の出口がなく（「Failed to open OpenAL device」）、
  本当に鳴っているかは確かめられていませんでした
- ボスの曲は Minecraft の「音楽」の音量に従っていたので、**「音楽」を0にしている人には鳴りません**（Minecraft のいつもの曲を止めるため、
  「音楽」を0にしている人は多い）。いちばんありそうな原因です
- もう1つ、曲が鳴らなかったとき（音を鳴らす口が足りない・音の読み直しの直後など）の**かけ直しが動いていませんでした**。曲が鳴った
  あとの時間で「止められた」を見ていたので、はじめの1回が鳴らないと、戦いが終わるまでかけ直しませんでした

### 直したこと【補完】

| 直したこと | くわしく |
| --- | --- |
| 「音楽」の音量から切り離す | ボスの曲は、主音量と、このModの設定「ボス戦の曲の大きさ」（`config/amemaru-client.toml` の `boss.musicVolume`。0.0〜1.0、初期値 0.8）に従う。「音楽」を0にしていても鳴る。いつもの曲は、前と同じく止まる |
| かけ直し | 曲をかけて2秒たっても鳴っていなければ、かけ直す（主音量か曲の大きさが0のときは、かけ直さない）。3回続けて鳴らないと、ログに「Boss music … does not start」と書く |
| ログ | 戦いの曲をかけたとき、ログに「[amemaru] Boss music: <ボス> (boss music volume N%, master volume N%)」と書く（鳴らないときに、どこまで動いたかが分かる） |
| 見た目と音の設定の画面 | Mod の一覧でこのModを選び「設定」を押すと開く。HUDの大きさ・数字・画面の揺れ・スキルの操作・装備の光の粒・ボス戦の曲（入・切）・曲の大きさ・ボス戦の演出を変えられる（変えるとすぐ保存） |
| 曲を試しに聞く | 同じ画面のボタン。押すたびに、1〜8階のボスの曲を順に10秒ずつ流す（戦わなくても、タイトル画面からでも鳴る）。聞こえなければ、Minecraft の主音量か、音の出口（パソコンの音の設定）を見る |

### CIで、鳴った音を録って確かめる

CIのクライアントは、OpenAL Soft の「wave」（鳴った音を、そのまま WAV ファイルに書く。1チャンネル・11025Hz）で音を出すようにしました
（`.github/workflows/build.yml` の「音をファイルに録る設定」）。ゲームは、音のしくみが動きはじめた時刻と、ボス戦の段取りの時刻を
ログに書きます。ジョブの終わりに `tools/ci/boss_audio.py` が、ボス戦ごとに、段取りの時刻から少しあとの6秒の録音が、Mod の jar の中の
そのボスの曲のどこかと波の形が似ているか（正規化した相互相関）を調べ、ほかのボスの曲とも比べます（追いこんだあとの、少し速い曲とも）。

- 結果は、ジョブのログと、ジョブのまとめ（Summary）の「ボス戦の曲（CIで録った音）」の表に出ます
- 1〜8階のボス戦と、設定の画面の「曲を試しに聞く」（2階の曲）を確かめます。1階では、追いこんだあと（HP25%）の少し速い曲も
  確かめます（追いこんだ合図の雷の音が消え、速さが落ち着く5.5秒あとから聞く。そのあいだ CI はほかの音を出さずに13秒待つ）
- ボス戦の前後20秒の録音を、Artifacts の `boss-audio-<番号>` に保存します（聞いて確かめられます）

## 自動テスト

- `SoloModeGameTests`：モードを切っている間は、時間がふだんのまま・人形を数えない。入れると時間が延び、人形のそばで薄氷にひびが入り、
  ひとりで4秒あけて水門の2つのハンドルを回すと開き、帳の間に5秒あけて違う鳴り石を鳴らすと破れる。切ると、ふだんに戻る
- CIのクライアント：ボス戦の曲が、録った音に入っていること（上）。設定の画面の写真 `phase8_settings`
