# Phase 6：経済とまわりの仕組み（その3：ギルドとクエスト・主要NPC・古代記録・称号）

Phase 6 の4つの分け方（`docs/phase6.md` の表）の3番目「**ギルドとクエスト・主要NPC・古代記録・称号**」の分です。Phase 0-B 13章の「ギルド、クエスト、主要NPC、古代記録、称号」と、その1で「その3で」と約束した分（**寄付で露店の区画を増やす・最初の取引の称号・対面の取引のコネクション**）を作りました。

作ったものの中心は次のとおりです。

- **称号**（Phase 0-A 22章）：表の称号をすべて（通常46・レア3・隠し7・限定7 ＝ **63**）。持っている称号から一つ選び、**頭の上・チャット・Tabの一覧の名前の前に「【称号】」**で出します（表示しない、もできる）。色は通常が白（段階の最上位は金）・レアが青・隠しが紫・限定が赤金（ゆっくり光る）・ユニークが虹色（色が変わり続ける）。手に入れると右上に知らせの札が出て、限定とユニークはサーバー全体に告知します。誰がどの称号をいつ取ったかを記録します。隠し称号は、手に入れるまで一覧で「？？？」です。
- **ユニーク称号**（運営専用）：管理者がゲームの中のコマンドで、その場で名前・色（虹色も）・説明・「1人限定か、何人にも配れるか」を決めて作り、与えます（22章【確定】）。
- **古代記録と記録帳**（14章）：1〜19階の **30** の記録（9章の各階の「古代記録」）。階で石板や文書を見つけると、記録帳に「未解読」で残ります。**エルネスト**に渡すと「解読済み」になり、本文（ページをめくる）と彼のひと言が読めます。分類（歴史・リンク・ロスト・NULL・人々・？？？）と、階ごとの収集率。今あるのは1階だけなので、1階の石板「道標の石板・一」を読むと記録に残ります（2〜19階の記録は、Phase 8 で階を作るときに置きます）。
- **親密度**（14章）：リリア・ガルド・ドラン・セレナ・エルネスト・ノアの6人。1日1回の会話（+10）・贈り物（しゃがんで品を持って右クリック。好きな物ほど上がる、1日1回）・個人的な依頼・物語。段階は 顔見知り → 知り合い → 信頼 → 親友 → かけがえのない人。段階2で個人的な依頼①、3で過去の話・依頼②・小さな贈り物、4で特別な会話・**ゆかりの小物**（見た目だけ）、5で称号。
- **クエスト**：**街めぐり**（職業を登録すると自動で受ける。工房・商店街・教会・倉庫・釣り堀を回る。Phase 0-A 11章の1日目）・**デイリー**（毎日、7つの中から3つが掲示板に出る。1日3回まで）・**ギルドの依頼**・**上位クエスト**（5日目から）・**昇格クエスト**（11日目・Lv30から。終えると上位職）・**個人的な依頼**（親密度2・3。12）。受けたクエストは右上に出ます（3つまで。掲示板で出さない、もできる。目標が6つ以上あるときは、まだの目標を4つまで出し、残りを「…ほか 1（済み 2）」のように1行にまとめる）。
- **ギルドの窓口**（7章「クエスト掲示板、パーティ募集、称号の授与、冒険日誌」）：リリアの「ギルドの窓口を見たい」か、ギルドの1階の**依頼の掲示板の右クリック**（北の面はクエスト、南の面はパーティ募集）で開きます。タブは **クエスト・パーティ募集・称号・冒険日誌・縁**。
- **パーティ募集**：一言・階・レベルの目安を書いて掲示板に出す（30分で消える）。ほかの人の募集に申し込む。自分の募集への申し込みを「入れる」と、そのままパーティに入ります。
- **冒険日誌**（14章）：サーバーで起きた出来事の年表（初撃破・限定称号・露店の区画が増えた など）。
- **縁帳**（15章【提案】）：組んだ人・取引した人（フリマ・露店・人から人への受け渡し）・起こした人・起こしてくれた人と、相手ごとに「一緒にしたこと」。その1で約束した「対面の取引のコネクション」は、ここに残します（コネクション量そのものは Phase 7）。
- **露店の区画を増やす寄付**（7章。11月20日に決定）：市場監督フィン・ロッソの小屋の「露店」のタブの「区画を増やす寄付」から。目標に届いた**次の朝に 12 → 20 区画**に増えます。
- **限定称号「市場の開拓者」**：フリーマーケットの最初の取引の売り手と買い手。その1より前の版で、もう最初の取引が済んでいたワールドでは、サーバーを起こしたあとに渡します（いない人には、次に入ったときに）。1階の初撃破の「最初の一歩」も同じです。
- **ノア**と**エルネスト**（8章）：凹凸のある立体のモデルと表情、会話。ノアは2日目から塔前広場の石柱の陰に現れ（4日目から話す）、エルネストは3日目からギルドの2階の資料室にいて、初めて会うと記録帳をくれます。

## 2. このPhaseで決めた細かいこと（【補完】・【提案】）

設計書に書いていない所は、次のように決めました。変えたいときは教えてください。称号・古代記録・クエストは `tools/datagen/build_guild.py` が書き出すデータパック（`data/amemaru/amemaru/titles/`・`records/`・`quests/`）で、親密度の好み・贈り物はNPCの定義（`npcs/`）で変えられます。

| 項目 | 決めたこと |
| --- | --- |

## 3. ゲームの中での使い方

- ギルドの受付のリリアに「ギルドの窓口を見たい」、または1階の依頼の掲示板を右クリック → クエストを受ける・報告する・パーティ募集。
- NPCに**しゃがんで品を持って右クリック**すると贈り物（1日1回）。ふつうに右クリックで会話（1日1回、親密度+10）。
- 記録帳は右クリックで開く。左で階を選び、解読した記録をクリックで読む。
- ステータス（K）の画面の右上の「称号」→ 持っている称号をクリックすると、名前の前に出る（もう一度クリックで外す）。
- 縁帳は、ギルドの窓口の「縁」のタブの「縁帳を開く」。

## 4. 管理者のコマンド（`/amemaru admin …`）

| コマンド | 働き |
| --- | --- |
| `title grant|revoke <人> <称号>`・`title list <人>`・`title show <人> <称号|none>`・`title owners <称号>` | 称号を与える・取り消す・一覧・表示を変える・持っている人 |
| `title unique create <色|rainbow> <single|multi> <名前> [説明]` | ユニーク称号をその場で作る（名前は "" で囲む。例：`title unique create rainbow single "名場面メーカー" 配信の名場面を作った人`）。`title unique give <人> <称号>`・`list`・`remove` |
| `title limited list`・`title limited reset <称号>` | 限定称号を取った人。試すときに、取った人の記録を消す |
| `record find <人> <記録>`・`record decipher <人>`・`record book <人>`・`record forget <人> <記録|all>` | 古代記録 |
| `bond set|add <人> <NPC> <点>`・`bond show <人>` | 親密度 |
| `quest start|complete <人> <クエスト>`・`quest reset <人> <クエスト|all>`・`quest list <人>`・`quest open <人> <タブ>` | クエスト（complete は目標を果たしていなくても終えて、報酬を渡す） |
| `donation`・`donation add <額>`・`donation reset`・`donation expand <true|false>` | 露店の区画の寄付 |
| `chronicle` | 冒険日誌（新しい順に10件） |

config（`amemaru-server.toml` の `[guild]`）：`participants`（参加人数。寄付の目標と「組んだ人数」の称号の基準）・`stallDonationGoal`（25人のときの寄付の目標）・`showTitles`（名前の前に称号を出すか）。

## 6. 自動の確認

GameTest に `GuildGameTests` の8つを足しました。テストの中の仮のプレイヤー（FakePlayer）はサーバーの一覧にいないので、「いない人には次に入ったときに渡す」の道（預かり）を、そのまま確かめています。

| テスト | 確かめること |
| --- | --- |
| `guildDefinitionsLoad` | 称号63・古代記録30・クエスト28・会話が問題なく読める。6人の親密度とゆかりの小物、ノアとエルネストの現れる日。限定の色・段階の最上位の金 |
| `guildTitles` | 数の条件・表示（名前の前に【】）・持っていない称号は表示できない・取り消し・できごと・隠し称号「ゼロからの一歩」・組んだ人数の条件の増減・ユニーク称号（虹色・1人限定） |
| `guildLimitedTitles` | フリマの最初の取引の2人だけが「市場の開拓者」。いない人には預かり、入ったときに渡す（取引の数と縁帳も）。2回目の取引では変わらない |
| `guildRecords` | 見つけると未解読（2回目は増えない）・収集率・解読と記録帳・記録帳の中身（見つけていない記録の本文は送らない）・受ける前に見つけた記録をクエストに数える |
| `guildBonds` | 会話で+10（1日1回）・段階・段階3と4のごほうび（一度だけ）・段階5の称号・affinity_min は話しているNPCについて見る |
| `guildQuests` | 街めぐりを自動で受ける（あきらめられない）・話す目標・受ける前に起動した石柱で報告・一度きり・デイリー3つから1つを報告・個人的な依頼は親密度2から |
| `guildPartyBoardAndConnections` | 募集を出す・申し込む（1回）・断る・取り下げる。縁帳（起こした・取引・組んだ） |
| `guildStallDonation` | 払える分だけ・目標に届いたら締め切る・届いた次の朝に区画が増える |

CI の写真（その3の分）：ノア（塔前広場）と会話、エルネスト（資料室）と会話、記録帳（一覧と、解読した記録を読むところ）、称号の知らせの札、称号の一覧、ギルドの窓口（クエスト・パーティ募集・冒険日誌・縁）、右上のクエストの一覧、露店の区画の寄付。
