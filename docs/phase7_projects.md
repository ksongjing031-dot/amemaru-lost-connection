# Phase 7：街を育てる（その4：寄付と共同事業）

Phase 7 は Phase 0-B 13章の「**釣り、カジノ（右クリックでGUIを開いて使う）、寄付と共同事業、コネクション量と輝き段階**」（動作確認の目安「**CPがたまり、輝き段階と施設が変わる**」）です。4つに分けて作りました。

| 分け方 | 中身 |
| --- | --- |
| その1 | コネクション量（CP）と大結晶の輝き段階。交流の常設の仕組み（[`phase7_connection.md`](phase7_connection.md)） |
| その2 | 釣り（[`phase7_fishing.md`](phase7_fishing.md)） |
| その3 | カジノ（[`phase7_casino.md`](phase7_casino.md)） |
| **その4（この文書）** | 寄付と共同事業（寄付台・7つの共同事業・完成した次の朝に施設が変わる）と、③で開くペトラ・ポムの料理屋（料理による一時強化） |

その4で作ったものの中心は次のとおりです。

- **寄付台**（Phase 0-A 7章「寄付した人の名前は寄付台の銘板に刻まれ」）：中央広場の南東の縁の**寄付の台座**（白い石の台。上に光の粒）を右クリックすると、寄付台の画面が開きます。左に7つの共同事業、右に選んだ共同事業の「完成すると」・寄付の帯・必要な大結晶の輝き段階・受付の日・寄付のボタン（100・1,000・10,000・残りすべて）・**銘板**（寄付した人の名前と額）。
- **7つの共同事業**（7章の表）：

  | 順 | 共同事業 | 寄付目標（25人基準） | 輝き段階 | 受付の日 | 完成すると |
  | --- | --- | --- | --- | --- | --- |
  | ① | 釣り堀の拡張「湖畔の釣り場」 | 25,000 | 3 | 4日目 | 湖畔の釣り場ができ、湖の魚と湖の主が釣れる。釣り大会の会場が湖まで広がる |
  | ② | カジノの新ゲーム「ハイ＆ロー」 | 40,000 | 4 | 7日目 | カジノの南の側廊のカードの卓が開く |
  | ③ | 料理屋の開店 | 60,000 | 5 | 9日目 | ペトラ・ポムの料理屋が開き、料理による一時強化 |
  | ④ | 倉庫の出張窓口 | 75,000 | 6 | 11日目 | 5・10・15階の休憩所で倉庫が使える（休憩所は Phase 8） |
  | ⑤ | 広場の舞台 | 75,000 | 6 | 13日目 | 祭り・表彰の会場（祭りは Phase 8） |
  | ⑥ | カジノの新ゲーム「魚レース」 | 100,000 | 7 | 15日目 | カジノ2階の宴の間に、魚を走らせる走路ができる |
  | ⑦ | 大結晶の強化（最終） | 250,000 | 9 | 18日目 | 最終決戦の「結晶の加護」が一段上がる（最終決戦は Phase 9） |

- **完成のしかた**（7章「寄付（お金）と大結晶の輝き段階（コネクション量）の両方がそろうと完成」）：寄付目標は**25人基準 × 人数補正**（13章と同じ。直近3日の平均アクティブ人数 ÷ 25、0.4〜2.0倍）。寄付が目標に届いても輝き段階が足りなければ「輝き段階を待っています」。両方がそろうと全員に「次の朝に完成します」と知らせ、**次の朝（ゲームの時刻の6時）**に施設が変わります（11月20日に決定）。
- **施設が変わる**：物語の印（`amemaru:project/<名前>`）が付き、①②③⑥は**育ったあとの形が街に重なります**（湖畔の釣り場・カードの卓・開いた料理屋・魚レースの走路）。全員の画面の真ん中に「○○ 完成」と出て、冒険日誌に残ります。重ねた形は、街を建て直しても重なります。
- **施設への寄付のCP**（13章「100ノットごとに1、1日50」）。寄付したノットは世界から消えます（20章の回収先）。
- **ペトラ・ポムの料理屋**（③のあと。7章「魚や素材から、戦闘用の料理（一時的な強化）を作る。釣りが戦闘を支える導線」・8章「料理人ペトラ・ポム：20代。マルタの娘。魚料理が得意。「〜ですね」。ポッカ爺から魚を仕入れる」）：中央広場の西の角の料理屋にペトラが現れ、話しかけると料理屋の画面。釣った魚と商店街で買える野菜などと代金で、6つの料理を作ってもらえます。**食べると20分のあいだ強くなります**（効くのは一皿だけ。新しく食べると入れかわり、倒れると消える）。

## 2. このPhaseで決めた細かいこと（【補完】）

設計書に書いていない所は、次のように決めました。変えたいときは教えてください。共同事業は `data/amemaru/amemaru/projects/`、料理は `restaurant/default.json` で変えられます。

### 寄付台と寄付

- 寄付台は、中央広場の南東の縁の「寄付の台座」（Phase 5 で台座だけ置いてあった所。白い石の台）。台座のどこを右クリックしても開きます。台の上に光の粒（近くの人だけ）。
- 寄付できるのは、受付の日（進行日）から、寄付が目標に届くまで。1回は100万ノットまで、目標までの残りの額まで（多く出しすぎない）。
- 目標は人数補正で毎日変わります。目標が上がって、届いていた寄付が足りなくなったら、また受け付けます。
- 銘板は、額の多い順に8人まで画面に出します（記録は全員。スタッフロールは Phase 9）。

### 完成と施設が変わる時

- 寄付と輝き段階の両方がそろった時に「完成」。施設が変わるのは、その**次の朝（ゲームの時刻の6時を回ったとき。`/time set day` で朝にしたときも）**。昼と夜が回らないワールドのために、**管理者が次の進行日へ進めたとき**にも変わります。
- 輝き段階が上がった・寄付があった・日が変わったときに、そろったかを確かめます。
- 育ったあとの形を重ねるのは、街を建ててあるワールドだけ（街を建てる前に完成したら、街を建てたときに重ねる）。
- ④倉庫の出張窓口と⑤広場の舞台は、印だけ先に付けます（5・10・15階の休憩所と祭りは Phase 8 で作り、この印を見る）。⑦は、最終決戦の「結晶の加護」（`ConnectionService.finalBlessing`）を1つ上げます。

### 料理屋の料理

| 料理 | 材料 | 代金 | 食べると（20分） |
| --- | --- | --- | --- |
| 川魚の塩焼き | ★1以上の魚 3 | 20 | 攻撃 +5% |
| 魚と根菜のスープ | ★1以上の魚 2・じゃがいも・にんじん | 30 | HP +6% |
| 魚の香草焼き | ★2以上の魚 2・ビートルート | 40 | 魔力 +5% |
| 魚の甘辛煮 | ★2以上の魚 2・砂糖 | 40 | 防御 +6% |
| 魚のはちみつ焼き | ★3以上の魚 1・はちみつ入りの瓶 | 60 | 会心 +3 |
| 湖の大物のごちそう | ★3以上の魚 2・パン・りんご | 80 | ロスト耐性 +5 |

- 野菜・砂糖・はちみつ・パン・りんごは、商店街の八百屋・茶と香辛料の店・薬屋・パン屋・雑貨屋で買えます。
- 魚は「★がその数以上」の魚から、★の低い・安い魚を先に使い、大物は最後。**記憶魚と湖の主は使いません**。
- 強化は1つだけ。新しく食べると入れかわり、倒れると消えます（ログアウトしても時間は進む）。料理には、作ったときの強化が書かれます（説明に出る）。

## 3. 管理者のコマンド

| コマンド | すること |
| --- | --- |
| `project` | 7つの共同事業の状態（寄付・目標・輝き段階・受付の日・寄付した人） |
| `project open <人> [共同事業]` | 寄付台の画面を開く（距離を見ない） |
| `project add <共同事業> <額>` | 寄付があったことにする（ノットは減らない） |
| `project complete <共同事業>` | 完成にする（足りない寄付を足し、輝き段階が足りなくても完成。次の朝に施設が変わる） |
| `project build <共同事業>` | 今すぐ施設を変える（印と、育ったあとの形） |
| `project reset <共同事業>` | 初めに戻す（寄付と印を消す。重ねた形は、街を建て直すと消える） |
| `project restaurant <人>` | 料理屋の画面を開く（③の前でも開く） |

共同事業の名前は `amemaru:lakeside`・`highlow`・`restaurant`・`storage_branch`・`stage`・`fishrace`・`crystal`。

## 4. 確かめ方

### 1人で

1. `/amemaru admin day set 4` のあと、中央広場の南東の白い石の台を右クリックすると寄付台の画面が開き、①湖畔の釣り場が「寄付を受付中」、②より後が「受付前（○日目から）」であること。
2. 「1,000」で寄付すると、ノットが減り、帯が伸び、銘板に自分の名前が出ること。画面の下に「コネクション +10（街：施設への寄付）」。
3. `/amemaru admin connection stage 2` のまま「残りすべて」で目標に届くと「輝き段階3を待っています」と出て、`/amemaru admin connection stage 3` で「次の朝に完成します」と出ること。時が進んで朝（ゲームの時刻の6時）を回るか、`/time set day` で朝にすると、画面の真ん中に「湖畔の釣り場 完成」と出て、城壁の南西の水門の外の湖に湖畔の釣り場が重なること。湖で釣ると湖の魚がかかること。
4. `/amemaru admin project build amemaru:highlow` で、カジノの南の側廊のカードの卓が緑の布になり、ハイ＆ローが遊べること。`amemaru:fishrace` で、カジノ2階に魚レースの走路ができること。
5. `/amemaru admin project build amemaru:restaurant` で、中央広場の西の角の料理屋の板が外れて開き、ペトラが立っていること。話しかけて「料理を作ってほしい」で料理屋の画面が開き、材料をそろえて「作ってもらう」と料理がもらえること。食べると「攻撃 +5%（20分）」と出て、ステータス（K）の攻撃が上がること。別の料理を食べると入れかわること。
6. `/amemaru admin city build` で街を建て直しても、完成した共同事業の形が残っていること。

### 2人以上で

1. 2人で同じ共同事業に寄付すると、銘板に2人の名前と額が並ぶこと。
