# スキルに重ねる音（11月24日）

> スキルのサウンドがすごく寂しいのでもっとつけてください

スキルの定義の音（`sound`・`cast_sound`・`impact_sound`）は1つずつしか鳴らず、多くのスキルは放ったときの1つだけでした。
そこで、その上に**技の種類ごとの音を重ねて**鳴らすようにしました【補完】。

| とき | 鳴らす所 | 例（天断ち） |
| --- | --- | --- |
| cast：詠唱・溜めを始めたとき | 自分 | ビーコンのうなり → 激流の渦 |
| release：放ったとき | 自分 | 雷の落ちる音・大きな薙ぎ・激流・衝撃波 |
| impact：当たったとき（1回の届きにつき1度。当たる相手がいなければ鳴らない） | 当たった所 | 爆ぜる音・金床の響き |

- アクティブスキル138すべてに、放ったときの音（2〜6つ）。当てる技には当たったときの音、詠唱・溜めのある14の技には始まりの音
- 音の型は約70（剣・重い一撃・盾・構え・鎖・鬨の声・誓い・城・炎・氷・雷・星・流星・光・障壁・瞬転・鈴・癒し・大きな癒し・
  呼び戻し・加護・聖域・雨・裁き・矢・連射・重い矢・閃光・風・集中・刃・連撃・毒・霧・煙・影・糸・投げ・千の刃・拳・連打・蹴り・
  気・気炎・流水・轟拳・昇龍・投げ・渦・百裂 など）。音はどれも Minecraft 1.20.1 にある音
- スキルの定義の音と同じ音は、同じときには重ねない（遅れて鳴らす連打の音は重ねる）。1つのときに重ねるのは6つまで。少しずつ遅らせ（tick）、高さを少しゆらす
- あわせて、ローグの「絡め糸」の音が 1.20.1 にない音（block.cobweb.place）を指していて鳴っていなかったのを直した（羊毛の音）

## ファイル

| ファイル | 役割 |
| --- | --- |
| `data/amemaru/amemaru/skill_sounds/<職業>.json` | スキルごとの重ねる音（`tools/datagen/build_skill_sounds.py` が書き出す。手で直さない） |
| `tools/datagen/build_skill_sounds.py` | 音の型（MOTIFS）と、スキル → 音の型（SKILLS）。`--check 音の名前の一覧` で、ない音を探す |
| `job/def/SkillSounds.java` | 読み込み・鳴らす（ない音・ないスキルは、定義の問題として出る） |
| `job/SkillExecutor.java`・`SkillService.java` | 放ったとき・当たったとき・詠唱と溜めの始まりに鳴らす |

## 直し方

音を変えたいときは、`build_skill_sounds.py` の MOTIFS（音の型の中の音・大きさ・高さ・遅れ）か SKILLS（スキルに使う音の型）を
直して `python3 tools/datagen/build_skill_sounds.py` を動かします。うるさいときは大きさ（volume）を下げます。
