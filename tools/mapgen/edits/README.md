# ゲームの中で直した所（取り込んだもの）

`/amemaru admin city export` で書き出した直しを、`python3 -I tools/mapgen/import_edits.py <フォルダ>` で取り込むと、
ここに `<構造物>.json` ができます。`build_*.py` が構造物ファイルを書くとき、ここの直しを重ねます（`mapgen/edits.py`）。
形は `docs/ingame_check.md` の「建物を直す」と `mapgen/edits.py` を見てください。

## 取り込んだ記録

### 11月21日（ゲームの中の直し・1回目）

10の構造物（ギルド・個人倉庫・武器工房・防具工房・装飾工房・商店街の北と南・結びの教会・カジノ・塔の入口）、合わせてマス 1,359・「もの」のマス 2。
商店街の階段をはしごに・装飾工房と防具工房の階段の付け替え・跳ね上げ戸の手すり・天井の梁を上付きの半ブロックに（頭をぶつけない）、など。

送ってもらった直しのうち、ブロックを置き直したときに中身が抜けた所だけ、次のように直して取り込んだ【補完】。

- カジノの樽4つ（構造物の (21〜24, 6, 5)）：置き直して鍵が外れていた（向きも形も同じ）。取り込まず、鍵のかかった樽のまま。
- 商店街の北の醸造台（(6, 3, 28)。1段上げて置き直したもの）：中身が空で瓶が消えていた。もとの見せ物と同じく、水の瓶2本と鍵を入れた。

取り込んだあとの街全体の確かめ（`check_city.py`）で、次の1か所を直した【補完】。

- カジノの2階の奥の細い通路（構造物の z 24、x 31〜36）：直しで出入口が3つともふさがれ、閉じた空き間になって、暗くて魔物が湧く所が6つ
  できていた。`build_casino.py` の `fill_closed_passage()` で、直しがそう閉じているときだけ、壁と同じ石レンガで埋める（見た目は変わらない）。

`check_city.py` は、はしごで上り下りできる所と、開いた跳ね上げ戸（マスの端の薄い板。板の側へは越えられない）を、歩ける所に入れるようにした。

### 11月22日（Phase 6：個人倉庫の窓口）

個人倉庫の1階のカウンターは、11月21日の直しで1段低くなり、窓口の口（構造物の (27, 11, 12) と (31, 11, 12)）が空気になっている。
ここに、右クリックで倉庫の画面が開く「契約・拡張」の呼び鈴と「受け取り口」の包み（`amemaru:storage_access`。天板の上の小さな物で、
口はふさがない）を置くため、この2マスの直しを、その2つのブロックに書き換えた【補完】。地下の小部屋の呼び出しの封印箱は、
直しがないので `build_storage.py` が置く。


### 11月22日（Phase 6：商店街の店の呼び鈴）

商店街の北と南のカウンターも、11月21日の直しで1段低くなり（天板は y 2 の上付きの半ブロック）、店の人の前の天板の上のマス（y 3）が
空気になっている。ここに右クリックで店の画面が開く呼び鈴（`amemaru:shop_counter[slab=false]`。中身の `shop` がどの店か）を置くため、
北の6マス（パン屋・八百屋・薬屋・雑貨屋・道具屋・ろうそくと灯り）と南の6マス（肉と燻製・本と地図・革と鞄・花と種・金物屋・茶と香辛料）の
直しを、その呼び鈴に書き換えた【補完】。直しのない「布と仕立て」は、`build_market.py` が天板ごと（`slab=true`）置く。料理屋は寄付で
開くまで置かない。
